# 癌痛概述与发病机制

癌痛概述与发病机制

类别：癌痛

## 一、概述
癌痛是恶性肿瘤患者最常见且最具破坏性的伴随症状之一，流行病学数据显示约50%的初诊患者及70%~90%的晚期患者曾经历中重度疼痛。疼痛不仅源于肿瘤本身的局部浸润、远处转移或治疗相关损伤，还常与患者合并的基础疾病、营养不良及心理社会应激交织，形成复杂的混合型疼痛（躯体痛、内脏痛、神经病理性痛及心理性痛并存）。癌痛具有隐匿性、进行性加重及多灶性特征，若未及时干预，将直接导致睡眠剥夺、食欲减退、免疫功能抑制及活动能力下降，显著降低患者生活质量（QoL）并缩短生存期。现代疼痛医学强调癌痛并非“疾病的必然结局”，而是可防、可控、可治的临床综合征。通过早期识别、精准分型与多模式干预，绝大多数患者可实现疼痛评分≤3分（轻度）及功能状态的稳定，从而保障抗肿瘤治疗的顺利实施与终末期尊严。

## 二、病理生理机制
癌痛的病理生理网络极为复杂，核心机制涵盖外周敏化、中枢敏化及神经可塑性改变。
1. **伤害感受性疼痛机制**：肿瘤细胞分泌前列腺素E2（PGE2）、缓激肽、组胺及活性氧等致痛介质，直接刺激游离神经末梢；肿瘤压迫或浸润骨膜、筋膜、胸腹膜及实质脏器，激活机械性与化学性伤害感受器，引发典型的躯体痛或内脏痛（常表现为定位模糊、牵涉痛及伴随自主神经症状）。
2. **神经病理性疼痛机制**：肿瘤直接侵犯神经丛（如臂丛、腰骶丛、腹腔神经丛）、椎管或颅神经，或化疗药物（紫杉醇、奥沙利铂、铂类）导致周围神经髓鞘脱失与轴突变性。机制涉及电压门控钠通道（Nav1.7/1.8）上调、钙通道α2δ亚基表达增加、小胶质细胞与星形胶质细胞活化，以及降钙素基因相关肽（CGRP）和P物质的异常释放，临床表现为烧灼样、电击样、针刺样痛及痛觉过敏/超敏。
3. **中枢敏化与慢性化**：持续无保护性伤害性输入导致脊髓背角神经元NMDA受体磷酸化，谷氨酸能传递增强，抑制性中间神经元（GABA能/甘氨酸能）功能衰退，形成“记忆性”痛觉放大。慢性癌痛常伴随下丘脑-垂体-肾上腺（HPA）轴失调与交感神经张力升高，进一步维持疼痛循环。
4. **阿片诱导的痛觉超敏（OIH）与耐受**：长期大剂量阿片类药物激活脊髓及脑干下行易化通路，促进脑内啡肽前体裂解为强效致痛肽（如强啡肽），并增强NMDA受体介导的钙内流，导致患者对伤害性与非伤害性刺激均产生痛觉增强。OIH需与肿瘤进展严格鉴别：疾病进展表现为疼痛部位固定、强度进行性加重且对原剂量反应下降；OIH则表现为疼痛范围扩散、性质改变（如出现非疼痛区触痛）、阿片增量后疼痛反而加剧。处理OIH的核心在于阿片轮换（尤其转向高亲和力NMDA拮抗作用的氢吗啡酮或美沙酮）、降低阿片剂量并强化非阿片辅助用药。

## 三、临床评估与筛查
癌痛评估必须遵循“全面、动态、多维”原则，摒弃单一强度评分的局限。
1. **疼痛强度与特征量化**：常规采用数字评分法（NRS 0-10分）或视觉模拟评分法（VAS）。1-3分为轻度，4-6分为中度，7-10分为重度。需详细记录疼痛部位（绘制疼痛图谱）、性质（钝痛、刺痛、烧灼痛等）、发作规律（持续性背景痛、发作性爆发痛、夜间痛）、加重/缓解因素及放射范围。
2. **爆发痛专项评估**：明确爆发痛类型（诱发性/情境性、自发性/突发性、末梢性/破痛痛）。记录每日发作频率、持续时间、诱因（如体位改变、咳嗽、排便）、缓解方式及既往抢救药物使用反应。爆发痛频率＞4次/日提示背景镇痛不足，需调整基础阿片剂量。
3. **阿片暴露史与药代动力学评估**：详细记录既往阿片种类、等效每日吗啡剂量（MEDD）、给药途径、起效与达峰时间、不良反应谱及耐受情况。评估肝肾功能（Child-Pugh分级、eGFR）以指导药物选择（如肾功能不全避免可待因/吗啡，转向氢吗啡酮或芬太尼透皮贴）。
4. **共病与心理社会筛查**：常规使用PHQ-9（抑郁）、GAD-7（焦虑）、Pain Catastrophizing Scale（疼痛灾难化）量表筛查心理共病。癌痛与抑郁/焦虑呈双向恶性循环，需同步干预。
5. **针对性体格检查与辅助检查**：对疑似神经压迫、骨转移、病理性骨折或肠梗阻者，立即安排相应影像学（MRI脊髓/神经根、全身骨显像/PET-CT、腹部CT平扫+增强）及实验室检查（血钙、碱性磷酸酶、CEA/CA19-9等肿瘤标志物、电解质、肝肾功能）。

## 四、专家诊疗思路（按类别）
癌痛管理绝非简单的“阶梯递药”，而是基于机制分型的个体化精准治疗。我的核心原则是“充分镇痛、最小副作用、功能优先、全程管理”。
1. **中重度癌痛滴定策略**：阿片类仍是基石，但滴定需遵循“小步快跑、动态评估”原则。阿片未耐受者推荐从吗啡即释片5-7.5 mg q4h PRN起步，或羟考酮即释2.5-5 mg。每24-48小时根据NRS评分变化与不良反应，将总剂量上调30%-100%。切忌因恐惧“成瘾”（癌痛患者生理依赖属正常药理现象，病理性成瘾率＜1%）而长期欠量镇痛。肝肾功能不全者需按说明书调整剂量或延长给药间隔。
2. **爆发痛与背景痛协同管理**：爆发痛必须单独处方并教育患者掌握“按需使用”原则。单次抢救剂量通常为24小时背景剂量的10%-20%（或日剂量的1/6-1/10）。即释制剂给药后1小时复评，静脉给药后15-30分钟复评。若连续3天爆发痛频率＞4次，提示背景剂量需上调15%-25%。
3. **阿片诱导的痛觉超敏（OIH）与快速耐受处理**：当出现剂量递增但疼痛反加重、痛阈降低或疼痛范围扩散时，高度怀疑OIH。此时不应盲目加量，而应实施阿片轮换（如吗啡→氢吗啡酮或芬太尼），或引入NMDA受体拮抗剂（氯胺酮静脉泵注、美沙酮）。同时强化非阿片辅助药物与介入治疗。
4. **骨转移痛与局部并发症干预**：骨痛常伴局部炎症与微骨折。常规联合双膦酸盐（唑来膦酸）或地舒单抗抑制破骨细胞活性；局限顽固性骨痛首选姑息性外照射放疗（8Gy/1次或20Gy/5次）；椎体压缩骨折可行椎体成形术（PVP/PKP）；腹腔神经丛毁损术可显著缓解胰腺癌/上腹部恶性肿瘤的顽固性内脏痛。
5. **终末期与姑息治疗整合**：疾病终末期应以患者舒适与意愿为核心，尊重预先医疗指示（Advance Directives）。采用皮下持续输注或患者自控镇痛（PCA）维持无痛睡眠，积极处理谵妄、喉鸣、呼吸困难等终末期症状，提供家属哀伤辅导与灵性关怀。

## 五、处理原则（药物与干预）
全面评估疼痛机制指导选药，打破“唯阿片论”或“唯阶梯论”的僵化思维，实施多模式镇痛（Multimodal Analgesia）。
- **WHO 三阶梯原则的现代诠释**：三阶梯仍是基础框架，但现代指南强调“按需跨越阶梯”。轻度疼痛可单用非阿片或弱阿片；中重度疼痛应直接启用强阿片，而非机械从第一阶梯开始。
- **阿片类是控制中重度癌痛基石**：吗啡、羟考酮、氢吗啡酮、芬太尼、美沙酮为一线选择。美沙酮与丁丙诺啡因具有NMDA拮抗作用，特别适合OIH或难治性神经病理性癌痛。
- **需同时处理爆发痛与背景痛**：背景痛控制是预防爆发痛的前提；爆发痛管理是维持生活质量的保障。两者剂量需动态匹配。
- **共病（抑郁、便秘、睡眠障碍）需同步管理**：疼痛、情绪与睡眠互为因果，需联合抗抑郁/抗焦虑药物（如度洛西汀、文拉法辛、米氮平）及睡眠卫生干预。

### 通用处理框架与用药要点（按类别）
1. **基础用药与滴定规范**：遵循NCCN与CSCO癌痛指南。阿片未耐受者起始：吗啡即释5-7.5 mg q3-4h PRN（或5-15 mg起始），羟考酮即释2.5-5 mg、氢吗啡酮2 mg、氢可酮5 mg/对乙酰氨基酚325 mg。滴定按疗效与耐受增量约30%-100%；爆发痛单次rescue约为24小时总量的10%-20%（或约日剂量1/6-1/10），即释间隔≥1小时复评、静脉≥15分钟复评。
2. **辅助镇痛药物（Adjuvants）精准应用**：
   - **神经病理性痛**：钙通道α2δ配体（普瑞巴林600-900 mg/d，加巴喷丁900-3600 mg/d）一线；SNRI类（度洛西汀60-120 mg/d）兼顾抑郁；三环类（阿米替林10-25 mg qn）注意抗胆碱能副作用。
   - **炎症/骨痛**：NSAIDs（塞来昔布、依托考昔）联合COX-2抑制剂减少胃肠道风险；糖皮质激素（地塞米松2-8 mg/d）用于神经压迫、脑转移或食欲减退，短期使用。
   - **难治性痛/OIH**：低剂量氯胺酮（0.1-0.5 mg/kg/h 静脉泵注）或美沙酮（起始1-2 mg bid-tid，缓慢滴定）。
3. **阿片相关性便秘（OIC）预防与管理**：自起始即预防性使用缓泻剂（刺激性泻药如比沙可啶/番泻叶 + 渗透性/软化剂如聚乙二醇/乳果糖）。常规泻药无效时升级至外周阿片受体拮抗剂（PAMORAs）：甲基纳曲酮（皮下）、纳洛格韦（口服）、莫沙必利（促动力）。
4. **介入与微创治疗指征**：药物难治性、副作用无法耐受或特定解剖定位疼痛者，尽早转介疼痛科。包括：神经阻滞（腹腔丛、肋间、臂丛、硬膜外）、射频热凝/脉冲射频、鞘内药物输注系统（IDDS，吗啡/布比卡因/齐考诺肽）、肿瘤消融（RFA/MWA）、椎体成形术。
5. **安全警示与药物相互作用**：避免哌替啶（代谢产物去甲哌替啶致癫痫）与丙氧芬；避免在阿片依赖者使用部分激动/混合激动-拮抗剂（布托啡诺、纳布啡）以免诱发戒断；高危者（MEDD>50 mg、联用苯二氮䓬或OUD/过量史）备纳洛酮并宣教；骨转移予双膦酸盐/地舒单抗，放疗用于局限骨痛。

## 六、非药物与康复
癌痛管理必须超越生物医学模式，整合心理社会支持与康复医学，实现身心同治。
1. **心理行为干预**：认知行为疗法（CBT）可显著降低疼痛灾难化思维，改善应对策略；正念减压疗法（MBSR）与接纳承诺疗法（ACT）有助于患者与疼痛共存，减少回避行为；放松训练（渐进性肌肉放松、腹式呼吸、引导性想象）可降低交感张力，缓解肌肉紧张性疼痛。
2. **物理与康复疗法**：在肿瘤负荷允许下，制定个体化低强度运动处方（如太极、瑜伽、抗阻训练），维持肌肉量与关节活动度，预防废用综合征。经皮神经电刺激（TENS）、热敷/冷敷、按摩疗法对躯体痛与肌肉痉挛有辅助缓解作用。
3. **中医与补充替代医学**：针灸（尤其针对化疗周围神经病变与癌性疼痛）具有循证医学支持；推拿与中药外敷需由专业医师操作，避免肿瘤局部刺激。
4. **营养与代谢支持**：癌痛常伴癌性恶液质。提供高蛋白、高热量、富含ω-3脂肪酸的抗炎饮食；纠正电解质紊乱与维生素D缺乏；必要时使用甲地孕酮改善食欲，或胰酶/益生菌调节肠道微生态。
5. **多学科协作（MDT）与姑息整合**：疼痛科、肿瘤内科、放疗科、心理科、营养科、康复科及社工团队早期介入。将症状控制与生活质量目标统一，制定个体化治疗路径图，避免碎片化医疗。

## 七、随访与监测要点
建立结构化、数据驱动的随访体系，是保障癌痛长期安全控制的核心。
1. **疼痛动态趋势监测**：每次随访记录NRS/VAS评分变化，绘制疼痛曲线。评估背景痛控制率（NRS≤3分且稳定≥24小时）与爆发痛频率变化。使用疼痛日记（线上/纸质）追踪发作规律与诱因。
2. **功能状态与生活质量评估**：定期评估ECOG评分或KPS评分，关注日常活动能力（ADL）、睡眠结构（PSQI量表）、行走距离及社交参与度。功能改善是镇痛有效的金标准之一。
3. **不良反应系统监测**：建立阿片不良反应筛查清单。重点监测：镇静过度（Ramsay评分）、呼吸抑制（SpO2、呼吸频率）、便秘（Bristol粪便分型）、恶心呕吐、尿潴留、皮肤瘙痒、认知障碍及内分泌影响（性腺功能减退、骨密度下降）。肝肾功能、电解质、血常规按用药周期复查。
4. **药物依从性与方案优化**：核查用药记录，识别漏服、重复用药或自行增减剂量行为。根据随访数据动态调整背景剂量、抢救剂量及辅助药物种类。对依从性差者简化方案（如改用长效制剂或透皮贴）。
5. **心理与灵性需求追踪**：每1-3个月复评PHQ-9/GAD-7，识别抑郁焦虑复发或自杀风险。关注患者对疾病预后的认知、未竟事宜及灵性困扰，及时转介心理医师或宗教/社工支持。

## 八、预警与转诊指征
癌痛患者出现以下“红旗征象”时，提示潜在急症或治疗失败，需立即干预或多学科转诊。
1. **神经压迫急症**：新发或进行性加重的腰背痛伴下肢无力、感觉平面、大小便失禁或鞍区麻木，高度警惕恶性脊髓压迫症（MSCC）。需24小时内行脊柱MRI，紧急大剂量糖皮质激素冲击，并转放疗/神经外科评估减压或放疗。
2. **病理性骨折与骨危象**：轻微外力后突发剧痛、畸形或活动受限，提示病理性骨折。需制动、镇痛并转骨科/介入科评估内固定或成形术。
3. **内脏急症与代谢危象**：突发板状腹、停止排气排便伴呕吐，警惕肿瘤相关性肠梗阻；意识模糊、多尿、肌无力伴高钙血症（血钙>3.0 mmol/L），需紧急补液、降钙素/双膦酸盐及肿瘤科会诊。
4. **镇痛治疗失败与药物风险**：规范滴定后NRS仍≥7分或爆发痛＞6次/日；出现严重OIH、难治性OIC、呼吸频率持续<8次/分、深度镇静或疑似阿片过量；肝肾功能进行性恶化无法耐受现有药物。
5. **心理社会危机**：PHQ-9评分≥15分伴自杀意念、严重谵妄、家属照护崩溃或拒绝继续抗肿瘤治疗。需转精神心理科、安宁疗护团队或社工介入。

## 九、患者教育与自我管理
赋能患者与家属是癌痛长期管理的基石，教育需具体、可操作且反复强化。
1. **规范用药与爆发痛应对**：强调“按时服药维持血药浓度，按需用药处理爆发痛”原则。教会患者识别爆发痛先兆，掌握抢救药物剂量、起效时间与复评节点。严禁因“怕上瘾”而自行减停基础阿片。
2. **便秘预防与生活方式干预**：从用药首日即启动肠道管理。每日饮水1.5-2L（心肾功能允许下），增加膳食纤维（燕麦、蔬菜、奇亚籽），建立定时排便习惯。指导正确使用开塞露或手动抠便（仅作为最后手段）。
3. **药物安全与家庭管理**：阿片类药物必须存放于儿童无法触及的专用药盒；剩余/过期药品通过社区回收点或药房无害化处理，严禁冲入下水道或赠予他人。家中常备纳洛酮鼻喷剂，家属需熟练掌握“唤醒-给药-呼救”三步急救法。
4. **危险信号识别与应急响应**：明确告知呼吸频率<8-10次/分、呼之不应、口唇发绀为阿片过量征象，立即拨打急救电话并舌下/鼻用纳洛酮。出现新发神经症状、剧烈呕吐、黑便或发热需立即就医。
5. **认知重塑与心理支持**：破除“癌痛=绝症=硬扛”的错误观念，强调规范镇痛可延长生存期。鼓励患者参与疼痛日记记录，与医生建立伙伴关系。提供患者支持团体、热线及线上随访平台（如PainSmart系统）接入指引，确保院外管理不断链。家属需学习照护技巧与情绪疏导，避免照护者耗竭。

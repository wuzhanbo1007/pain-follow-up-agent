# painDETECT 量表

类别：评估工具

## 一、概述
painDETECT（Pain Detectability）量表是一种基于患者主观描述的自评筛查工具，专门用于在慢性疼痛人群中快速识别潜在的神经病理性疼痛（Neuropathic Pain, NP）成分。该量表由德国神经病理性疼痛研究网络开发，核心结构包含9个自评问题，聚焦于疼痛的定性特征、时间模式、分布特点及伴随症状。其设计初衷是弥补传统强度量表（如NRS/VAS）在鉴别疼痛机制方面的不足，通过量化疼痛的“性质”与“演变规律”，为临床初步分型提供客观依据。painDETECT不用于确诊，而是作为高效的分诊与筛查工具，特别适用于基层医疗机构、疼痛门诊初筛及长期随访数据库的标准化数据采集。其信效度已在多项国际多中心研究中得到验证，具有良好的跨文化适用性与临床可操作性。

## 二、病理生理机制
神经病理性疼痛的本质是感觉神经系统（外周或中枢）在结构或功能上受到损伤或疾病直接导致的疼痛。painDETECT所捕捉的临床症状与以下病理生理机制高度对应：
1. **外周敏化与异位放电**：损伤的神经纤维出现电压门控钠/钙通道异常表达，导致自发性异位放电，临床表现为电击样、刺痛或过电感，对应量表中“突发、尖锐”的疼痛描述。
2. **中枢敏化与脊髓背角神经元可塑性**：伤害性信号传入增加引发“wind-up”现象，NMDA受体激活及胶质细胞（星形胶质细胞、小胶质细胞）活化，导致痛觉过敏（Allodynia）和痛觉超敏（Hyperalgesia），对应量表中“触碰即痛”或“轻微刺激引发剧痛”的描述。
3. **下行抑制通路功能减退**：中脑导水管周围灰质（PAG）及延髓头端腹内侧区（RVM）的5-羟色胺/去甲肾上腺素能下行抑制功能受损，导致疼痛调制能力下降，常伴随持续性烧灼痛、温度觉异常及情绪共病。
4. **神经纤维类型选择性损伤**：Aβ纤维（粗大髓鞘纤维）损伤导致机械性痛觉过敏，而C纤维（细无髓纤维）损伤则主导烧灼痛与温度觉异常。painDETECT通过多维度症状采集，间接映射上述神经生物学改变，将主观体验转化为可量化的机制指标，从而指导靶向治疗。

## 三、临床评估与筛查
在临床实践中，评估工具的选择应严格遵循“机制导向、维度互补、动态追踪”原则：
- **强度评估**：NRS（0-10分）或VAS（0-100mm）用于量化疼痛严重程度，是疗效判定的基础指标。
- **机制筛查**：painDETECT（得分≥19分提示高度可能为NP，13-18分为可疑，<13分为可能为伤害感受性疼痛）、DN4（神经病理疼痛诊断量表）及ID Pain量表互为补充。painDETECT更侧重患者主观症状描述，DN4结合体格检查，ID Pain侧重干扰与情绪维度。
- **功能与共病评估**：BPI（简明疼痛量表）评估疼痛对日常活动、情绪、睡眠的干扰程度；PHQ-9/GAD-7筛查抑郁/焦虑共病；PSQI评估睡眠质量；SF-36/EQ-5D衡量生活质量。
- **实施规范**：评估应在基线、治疗干预后2-4周及每次随访时复测。需向患者明确说明“无对错之分”，确保环境安静、隐私保护。临床医生应结合量表结果、神经系统查体（如两点辨别觉、针刺觉、温度觉、振动觉）及必要的电生理/影像学检查进行综合判断。需警惕量表的适用边界：不适用于急性创伤性疼痛、重度认知障碍患者或无法完成自评者。

## 四、专家诊疗思路（按类别）
疼痛是高度主观的体验，脱离机制评估的“盲目镇痛”往往导致治疗失败或药物滥用。我的临床路径如下：
1. **初诊分层**：常规以NRS量化强度，但绝不孤立看待。立即辅以painDETECT筛查机制，若得分≥19，高度怀疑NP，优先排查糖尿病周围神经病变、带状疱疹后神经痛、脊柱术后失败综合征等继发因素。
2. **多维整合**：结合BPI判断功能受损程度，PHQ-9/GAD-7排查情绪共病。若疼痛干扰评分高且情绪阳性，提示需启动“生物-心理-社会”综合干预，而非单纯加用镇痛药。
3. **纵向追踪**：随访核心在于“趋势分析”。单次评分下降可能受安慰剂效应或急性期波动影响，连续2-3次随访显示NRS下降≥2分或painDETECT机制分降低，才具有临床意义。
4. **决策驱动**：工具的价值在于指导行动。机制分阳性→启用加巴喷丁类/SNRI；共病阳性→联合心理干预或抗抑郁药；干扰重度→考虑介入治疗或康复转介。严禁“为评分而评分”，所有数据必须转化为可执行的随访计划与个体化目标。

## 五、处理原则（药物与干预）
基于painDETECT筛查结果及疼痛机制分型，治疗应遵循阶梯化、个体化原则：
- **一线药物治疗**：针对NP成分，首选加巴喷丁或普瑞巴林（钙通道α2-δ配体），通过抑制中枢敏化与减少谷氨酸释放起效；或选用SNRI（度洛西汀、文拉法辛）增强下行抑制通路；三环类抗抑郁药（阿米替林）亦为经典选择。起始低剂量，缓慢滴定，关注头晕、嗜睡、水肿等不良反应。
- **二线与辅助用药**：局部疼痛可首选利多卡因贴剂或辣椒素高浓度贴剂；难治性NP可谨慎短期使用曲马多或弱阿片类药物，但需严格评估成瘾风险与耐受性。
- **介入治疗**：对于药物反应不佳或不耐受者，可评估神经阻滞（如交感神经阻滞、硬膜外注射）、脉冲射频调节或脊髓电刺激（SCS）、周围神经电刺激（PNS）。painDETECT高分患者对神经调节类干预的响应率通常更高。
- **用药监测**：治疗初期每2-4周复评painDETECT与NRS，评估机制分变化；稳定期每3个月复测。若3个月内机制分无下降且功能未改善，需重新评估诊断或调整方案。

## 六、非药物与康复
非药物干预是慢性疼痛管理的基石，尤其对于中枢敏化主导的NP：
- **认知行为疗法（CBT）与疼痛神经科学教育（PNE）**：纠正“疼痛等于组织损伤”的错误认知，降低疼痛灾难化思维与恐惧-回避行为。
- **运动康复与节律管理**：基于分级运动疗法，从低强度有氧运动（如步行、游泳）逐步过渡至抗阻训练，改善肌肉萎缩与本体感觉。引入“Pacing”策略，帮助患者识别活动阈值，避免“爆发-崩溃”循环。
- **物理治疗**：经皮神经电刺激（TENS）、热疗、冷疗、手法治疗可辅助缓解外周敏化。需根据painDETECT提示的疼痛性质（如烧灼痛忌热敷，冷痛可热敷）个体化选择。
- **心理社会支持**：针对PHQ-9/GAD-7阳性者，整合正念减压（MBSR）、接纳承诺疗法（ACT）及家庭支持计划，打破疼痛-失眠-抑郁的恶性循环。评估结果直接用于设定康复目标（如“疼痛干扰评分下降30%”而非“完全无痛”）。

## 七、随访与监测要点
随访的核心是动态监测治疗反应与功能恢复，而非单纯追求数字下降：
- **监测频率**：急性加重期或调整药物期每2-4周随访；稳定维持期每3-6个月随访。数据库应自动标记连续3次随访的NRS与painDETECT趋势线。
- **疗效判定标准**：国际疼痛学会（IASP）推荐“疼痛缓解≥30%”为临床有意义改善。结合painDETECT机制分下降、BPI干扰评分降低、PSQI睡眠改善及SF-36生活质量提升进行多维判定。
- **安全性监测**：定期评估肝肾功能、血常规、心电图（尤其使用TCAs或SNRI时）；监测药物相互作用及跌倒风险（老年患者）。
- **目标调整**：若连续2次随访机制分未降且功能停滞，需启动多学科会诊（MDT），考虑升级干预或重新评估共病。随访记录应转化为结构化电子病历，确保趋势可比性。

## 八、预警与转诊指征
painDETECT仅为筛查工具，以下情况需立即预警并启动转诊：
- **红旗征象（Red Flags）**：疼痛进行性加重伴不明原因体重下降、发热、夜间痛醒；出现进行性神经功能缺损（肌力下降、大小便障碍、感觉平面）；提示脊髓压迫、肿瘤转移、感染或炎症性疾病，需紧急影像学检查。
- **治疗抵抗**：规范使用2种以上一线药物足量足疗程（≥8周）后，painDETECT机制分仍≥19且NRS≥6分，功能严重受损，建议转诊至疼痛专科中心评估介入或神经调控治疗。
- **精神心理危机**：PHQ-9评分≥15分或出现自杀意念，需紧急转诊精神心理科。
- **诊断不明**：症状与量表结果不符，或怀疑罕见神经病（如遗传性感觉神经病、副肿瘤综合征），需转诊神经内科或遗传代谢科。
转诊时应附完整随访数据链（基线至当前评分趋势、用药记录、查体摘要），避免重复评估。

## 九、患者教育与自我管理
赋能患者是慢性疼痛长期管理的核心：
- **量表与日记使用**：教会患者正确填写painDETECT与疼痛日记，强调“如实记录”优于“追求高分”。解释分数含义：高分不代表“病情更重”，仅提示神经病理性成分比例高，需针对性治疗。
- **疼痛神经科学教育**：普及“疼痛是输出信号而非输入信号”的概念，降低对影像学异常（如椎间盘突出、骨刺）的过度焦虑，建立“疼痛≠损伤”的认知。
- **自我管理策略**：指导患者识别诱发因素（如寒冷、压力、过度活动），制定个性化应对预案；鼓励设定SMART目标（具体、可衡量、可实现、相关、有时限），如“本周步行时间增加10分钟”。
- **依从性维护**：解释药物起效机制（如加巴喷丁需累积剂量），管理预期，避免自行停药。提供标准化教育手册与数字化随访平台，鼓励家属参与支持。定期回顾日记与量表趋势，强化正向反馈，提升长期治疗依从性与生活质量。

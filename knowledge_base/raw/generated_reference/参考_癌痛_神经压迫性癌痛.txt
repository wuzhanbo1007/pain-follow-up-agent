# 神经压迫性癌痛

神经压迫性癌痛

类别：癌痛

## 一、概述
肿瘤直接浸润、包绕或机械性压迫周围神经丛、神经根、脑脊膜及中枢神经系统所引发的神经病理性癌痛，是晚期恶性肿瘤患者最常见的致残性症状之一。此类疼痛不仅表现为典型的神经病理性特征（如自发性疼痛、痛觉超敏、感觉异常），常与伤害感受性疼痛（躯体痛、内脏痛）混合存在，形成复杂的混合型癌痛。神经压迫性癌痛的发生与肿瘤进展、治疗相关神经毒性及继发性并发症密切相关，若未及时干预，将导致患者运动功能障碍、自主神经紊乱、严重睡眠剥夺及心理崩溃，显著降低生活质量并缩短生存期。临床管理需遵循“精准分型、多模式镇痛、全程化管理”原则，整合药物、介入、康复与心理支持，以实现疼痛控制与功能保留的双重目标。

## 二、病理生理机制
神经压迫性癌痛的病理生理机制极为复杂，涉及外周敏化、中枢敏化及下行调制通路失衡的多重级联反应。
1. **外周机制**：肿瘤细胞分泌的炎症介质（如前列腺素E2、白介素-1β、肿瘤坏死因子-α、神经生长因子NGF）直接刺激受压神经根或神经丛，导致电压门控钠通道（Nav1.7/1.8）与TRPV1通道异常上调，降低神经纤维兴奋阈值。机械性压迫引起轴突运输障碍、髓鞘脱失及局部缺血，进一步诱发异位放电。
2. **中枢机制**：持续伤害性输入导致脊髓背角神经元突触可塑性改变，NMDA受体激活引发钙内流，促进P物质、谷氨酸释放，形成“Wind-up”现象。小胶质细胞与星形胶质细胞被激活，释放促炎细胞因子（IL-6, TNF-α）和BDNF，阻断GABA能抑制性传递，导致中枢敏化。下行疼痛调制系统（中脑导水管周围灰质-延髓头端腹内侧区-脊髓背角）发生功能逆转，去甲肾上腺素与5-羟色胺能抑制通路减弱，而促痛通路增强。
3. **阿片诱导的痛觉超敏（OIH）**：长期大剂量阿片类药物使用可激活脊髓胶质细胞与KOR受体，上调CGRP与P物质，导致痛阈降低、痛区扩散。OIH需与肿瘤进展引起的疼痛加剧严格鉴别，前者常表现为对阿片剂量增加不敏感甚至疼痛恶化，处理核心在于阿片轮换、减量及联合NMDA受体拮抗剂（如氯胺酮、美沙酮）。
4. **脑脊膜/硬膜外压迫**：肿瘤突破硬脊膜或脑膜转移时，引发化学性脑膜炎与蛛网膜粘连，导致脑脊液循环受阻与颅内压波动，疼痛常呈体位性、咳嗽/Valsalva动作加重，并伴随脑神经受累症状。

## 三、临床评估与筛查
规范的临床评估是制定个体化镇痛方案的基石，需采用多维度、动态化评估策略。
1. **疼痛特征量化**：以数字评分法（NRS）或视觉模拟评分法（VAS）量化背景痛强度（1–3分轻度、4–6分中度、7–10分重度）。详细记录疼痛性质（灼烧样、电击样、刀割样、麻木伴刺痛）、解剖分布（皮节/神经干走行）、发作规律（持续性基础痛叠加阵发性爆发痛）。明确加重/缓解因素（体位改变、活动、夜间加重提示神经受压或骨转移）。
2. **神经病理性疼痛特异性量表**：常规使用DN4（Douleur Neuropathique 4 Questions）或LANSS量表筛查神经病理性成分。DN4≥4分高度提示神经病理性疼痛。
3. **爆发痛评估**：记录爆发痛诱因（如体位变动、咳嗽）、频率（每日次数）、持续时间、严重程度及补救药物起效时间与持续时长。爆发痛频率>4次/日提示背景镇痛不足。
4. **神经系统查体**：重点评估感觉减退/过敏区、肌力下降、腱反射亢进或消失、病理征（Babinski征）、括约肌功能。区分上/下运动神经元损害。
5. **影像与电生理**：增强MRI（全脊柱/颅脑）是评估神经压迫、硬膜外转移的金标准；CT/PET-CT用于肿瘤负荷评估。肌电图（EMG）与神经传导速度（NCS）可定位压迫节段并鉴别化疗性周围神经病变（CIPN）。
6. **共病与心理筛查**：常规使用PHQ-9（抑郁）、GAD-7（焦虑）、PROMIS睡眠障碍量表评估心理共病。抑郁焦虑可显著放大疼痛感知（痛觉放大综合征），需同步干预。
7. **用药史与耐受评估**：详细记录既往阿片暴露史、最大耐受剂量（MEDD）、转换比例、不良反应谱（便秘、嗜睡、恶心、瘙痒、呼吸抑制风险）。评估肝肾功能、电解质（警惕高钙血症致痛）及药物相互作用。

## 四、专家诊疗思路（按类别）
癌痛是肿瘤患者最常见的伴随症状之一，约50%初诊患者及70%晚期患者全程受累。我的核心诊疗原则是“充分镇痛、最小副作用、保障生活质量与功能尊严”。神经压迫性癌痛因常伴神经结构损伤，单用阿片类药物往往疗效有限，必须采用多模式镇痛策略。
1. **阿片类药物的精准滴定**：中重度癌痛以阿片类药物为基石。阿片未耐受者推荐从吗啡即释片 5–7.5 mg q4h PRN 或羟考酮 5 mg q4h PRN 起步。滴定需遵循“小步快跑、动态评估”原则：根据NRS评分变化与不良反应，每24–48小时调整基础剂量30%–100%。切忌因恐惧“成瘾”或“呼吸抑制”而长期欠量镇痛，癌痛患者的耐受性发展远快于成瘾风险。
2. **爆发痛的独立管理**：爆发痛是治疗难点与生活质量杀手。单次补救剂量（Rescue Dose）应设定为24小时背景阿片总剂量的10%–20%（或约日剂量的1/6–1/10）。即释制剂给药后1小时、静脉给药后15分钟必须复评疼痛与镇静评分。若每日需补救>4次，提示背景剂量不足或存在未控的机械压迫，需上调缓释制剂剂量或升级介入治疗。
3. **阿片轮换与OIH鉴别**：当出现快速耐受、剂量激增但疼痛控制不佳、或出现典型OIH表现（痛区扩散、对阿片不敏感）时，应果断实施阿片轮换。例如从吗啡轮换至氢吗啡酮或芬太尼透皮贴剂，利用不完全交叉耐受性重置痛阈。轮换剂量需按等效剂量表折算并减去25%–50%的安全余量。
4. **骨转移与局部压迫的协同处理**：合并骨转移或椎体压缩时，联合使用双膦酸盐（唑来膦酸）或RANKL抑制剂（地舒单抗）可显著降低骨骼相关事件（SREs）风险。局限性神经根压迫首选姑息性放疗（常规分割4–8 Gy/1–2次），可快速减轻骨膜牵张与局部水肿。
5. **终末期舒缓导向**：疾病终末期，治疗目标应从“延长生存”转向“舒适照护”。尊重患者预先医疗指示（Advance Directives），优先控制难治性疼痛、呼吸困难与谵妄，避免过度有创干预，强化家属沟通与哀伤辅导。

## 五、处理原则（药物与干预）
常需联合神经病理药物；放疗/手术减瘤可缓解；阿片剂量常需较高；糖皮质激素可短期减轻水肿。
### 通用处理框架与用药要点（按类别）
严格遵循WHO三阶梯镇痛原则与NCCN/ESMO成人癌痛临床实践指南，构建阶梯化、个体化、多模式治疗方案。
1. **一线基础镇痛（阿片类）**：中重度癌痛首选强阿片类药物。未耐受者起始剂量：吗啡即释 5–7.5 mg q3–4h PRN（或5–15 mg），羟考酮即释 2.5–5 mg，氢吗啡酮 2 mg，或氢可酮/对乙酰氨基酚 5/325 mg。转为缓释制剂（如吗啡缓释片、羟考酮缓释片、芬太尼透皮贴剂）后，按24小时总阿片用量（背景+补救）等比例换算，每12小时或72小时给药一次。
2. **神经病理痛辅助药物**：针对神经压迫导致的异位放电，必须早期联合使用钙通道α2-δ配体（普瑞巴林 75 mg bid 起始，滴定至300–600 mg/d；或加巴喷丁 300 mg tid 起始，滴定至900–3600 mg/d）或SNRIs（度洛西汀 30–60 mg/d，文拉法辛 75–150 mg/d）。TCAs（阿米替林 10–25 mg qn 起始）对灼痛有效，但需注意抗胆碱能副作用。局部外用5%利多卡因贴剂对局灶性痛觉过敏安全有效。
3. **糖皮质激素与抗炎**：地塞米松（4–8 mg/d 起始，逐渐减量）可快速减轻神经根水肿、硬膜外占位压迫及脑转移引起的颅内高压，改善神经功能。长期使用需监测血糖、血压、骨质疏松及感染风险。
4. **NMDA受体拮抗剂与氯胺酮**：用于难治性OIH或阿片耐药型癌痛。低剂量氯胺酮（0.1–0.5 mg/kg/h 静脉输注或口服）可阻断中枢敏化，但需严密监测解离反应、幻觉及肝肾功能。
5. **干预性疼痛治疗**：
   - **神经阻滞**：硬膜外类固醇注射、选择性神经根阻滞、交感神经阻滞（如下肢 sympathetic block）可快速打断疼痛传导环。
   - **鞘内药物输注系统（IDDS）**：对于口服阿片无效或副作用无法耐受者，植入鞘内泵输注阿片（吗啡/氢吗啡酮）联合局部麻醉药（布比卡因）或佐剂（齐考诺肽、可乐定），可大幅降低全身血药浓度，提高镇痛效能。
   - **姑息性手术**：肿瘤减压术、椎体成形术（PVP/PKP）、神经松解术适用于预期生存期>3个月、一般状况良好（ECOG 0-2）且压迫明确者。
6. **安全性与不良反应管理**：自阿片起始日即预防性使用缓泻剂（刺激性泻药如番泻叶/比沙可啶 + 软化剂如多库酯钠/聚乙二醇），防阿片性肠梗阻（OIC）；恶心呕吐通常3–5天耐受，可短期予甲氧氯普胺；便秘不产生耐受，需终身管理。避免使用哌替啶（代谢产物去甲哌替啶致神经毒性）与丙氧芬。高危患者（MEDD>50 mg 吗啡等效剂量、联用苯二氮䓬类、睡眠呼吸暂停、既往过量史）必须配备纳洛酮鼻喷剂并培训家属，警惕呼吸抑制（RR<8次/分）与过度镇静（RASS评分<-2）。

## 六、非药物与康复
联合心理社会支持、放松训练、康复与营养；终末期重视舒适护理、家属沟通与哀伤支持，尊重患者预先医疗指示。
1. **心理干预与认知行为疗法（CBT）**：癌痛常伴发灾难化思维、恐惧-回避行为及睡眠障碍。CBT可帮助患者重构疼痛认知，学习疼痛应对技巧。正念减压（MBSR）与渐进性肌肉放松训练（PMR）能降低交感神经张力，缓解肌肉痉挛性疼痛。
2. **物理康复与运动疗法**：在疼痛可控前提下，制定个体化康复计划。包括核心肌群稳定性训练、神经滑动技术（Nerve Flossing）改善神经粘连、经皮神经电刺激（TENS）干扰痛觉传导。避免长期卧床导致废用性萎缩与深静脉血栓。
3. **营养与代谢支持**：肿瘤恶液质与慢性疼痛增加能量消耗。推荐高蛋白、高ω-3脂肪酸饮食，补充维生素D与钙剂以预防骨相关事件。必要时使用肠内/肠外营养支持，改善组织修复与药物代谢能力。
4. **补充与替代医学（CAM）**：针灸（尤其针对癌性神经根痛）、按摩疗法、瑜伽及太极可辅助改善疼痛评分与生活质量。需确保操作者具备肿瘤患者护理资质，避开肿瘤转移灶、血小板减少区及感染部位。
5. **多学科团队（MDT）协作**：整合疼痛科、肿瘤内科、放疗科、康复科、临床心理科、营养科及缓和医疗团队。定期召开MDT会议，统一症状控制目标与生活质量预期，实现从“以疾病为中心”向“以患者为中心”的范式转变。

## 七、随访与监测要点
神经功能；疼痛强度；激素相关不良反应；药物代谢与肝肾功能；心理社会状态；治疗依从性。
1. **随访频率与路径**：急性期/滴定期建议每周随访1–2次，稳定期每1–3个月随访一次。终末期或介入术后需缩短随访间隔。建立电子化随访档案，实现数据连续追踪。
2. **核心监测指标**：
   - **疼痛动态**：NRS/VAS评分、爆发痛频率/补救药使用率、疼痛干扰功能评分（BPI）。
   - **神经功能**：肌力（MRC分级）、感觉平面、腱反射、括约肌控制能力。每周复查神经系统查体。
   - **药物安全性**：呼吸频率、镇静评分（RASS/ Ramsay）、便秘程度（Bristol粪便分型）、肝肾功能、电解质（尤其血钙、血钠）、QT间期（使用美沙酮或高剂量阿片时）。
   - **激素与骨代谢**：长期使用糖皮质激素者监测血糖、血压、骨密度（DEXA）；双膦酸盐/地舒单抗使用者监测血钙、肾功能及下颌骨坏死风险（用药前牙科评估）。
3. **疗效评估与方案调整**：若NRS下降≥30%且副作用可耐受，视为有效；若无效或副作用不可耐受，启动阿片轮换或升级介入治疗。记录患者报告结局（PROs），将功能恢复与生活质量纳入疗效评价体系。
4. **药物重整与依从性核查**：每次随访核对实际用药量与处方量，识别漏服、过量或药物滥用风险。评估缓释/即释制剂转换的合理性，优化给药频次。

## 八、预警与转诊指征
脊髓压迫征象需急诊；进行性神经功能缺损；难治性疼痛；阿片中毒/呼吸抑制；高钙危象；病理性骨折风险；心理危机/自杀倾向。
1. **肿瘤相关神经急症（需24小时内急诊/住院）**：
   - **恶性脊髓压迫（MSC）**：突发背痛伴进行性下肢无力、感觉平面、括约肌功能障碍（尿潴留/失禁）。需立即行全脊柱MRI，急诊大剂量地塞米松（10 mg IV 负荷，后16 mg/d分次）及神经外科/放疗科会诊。
   - **马尾综合征**：鞍区麻木、双下肢不对称无力、性功能障碍。需紧急手术减压。
   - **脑膜转移危象**：剧烈头痛、喷射性呕吐、脑神经麻痹、颈强直伴发热。需腰椎穿刺（谨慎评估颅高压风险）及鞘内化疗/放疗。
2. **疼痛与药物管理预警**：
   - 爆发痛频率持续>6次/日，背景镇痛无效。
   - 出现典型OIH表现（痛阈降低、痛区扩散、阿片增量无效）。
   - 阿片中毒迹象：RR<8次/分、SpO2<90%、瞳孔针尖样、深度镇静（RASS ≤ -3）。立即停用阿片，给予纳洛酮，转入ICU。
   - 难治性癌痛（多模式药物+介入仍无法控制NRS>6分），转诊至高级疼痛中心评估鞘内泵或神经毁损术。
3. **全身状况预警**：
   - 肿瘤高钙血症（血钙>3.0 mmol/L）：多尿、脱水、意识模糊、心律失常。需紧急补液、双膦酸盐及降钙素。
   - 病理性骨折风险：承重骨（股骨、脊柱）溶骨性破坏>50%或Mirels评分≥9分，需预防性内固定。
   - 严重心理危机：PHQ-9≥15伴自杀意念，立即转介精神科/危机干预团队。

## 九、患者教育与自我管理
强调按时服药、爆发痛用 rescue；预防便秘从开始用药起（多饮水、纤维、缓泻）；药品妥善保管、剩余/过期回收。
呼吸频率减慢（<8–10 次/分）或意识障碍立即就医/呼救，不得自行加量、停药或联用镇静药；高危者家属学会纳洛酮使用。
1. **用药安全与依从性教育**：
   - **按时服药原则**：缓释阿片必须严格按时（q12h或q24h）服用，维持血药浓度稳定，而非“痛了才吃”。即释制剂仅用于爆发痛补救。
   - **爆发痛应对**：教会患者及家属识别爆发痛先兆，立即服用备用即释阿片，记录时间、剂量及1小时后复评结果。若1小时内未缓解，可再服一次，但24小时内补救次数需上报医生。
   - **便秘预防**：从用药第一天起执行“饮水1.5–2L/d + 膳食纤维 + 刺激性/渗透性泻药”三联方案。若3天无排便或出现腹胀腹痛，立即就医防粪石嵌塞。
2. **风险识别与紧急响应**：
   - 掌握呼吸抑制“三不”原则：不自行加量、不联用酒精/安眠药、不突然停药（防戒断综合征）。
   - 家属必须掌握纳洛酮鼻喷剂使用方法（0.4mg/喷，双侧鼻孔各一喷，必要时每2–3分钟重复），并知晓急救电话拨打时机。
   - 识别脊髓压迫“红旗征”：新发下肢无力、大小便失禁、鞍区麻木，立即急诊。
3. **生活方式与心理调适**：
   - 保持规律作息，避免久坐久站，使用符合人体工学的床垫与坐垫。
   - 学习腹式呼吸、冥想放松技巧，降低交感兴奋度。
   - 加入癌痛患者支持团体，分享应对经验，减少病耻感与孤立感。
4. **药品管理与环保回收**：
   - 阿片类药物必须存放于儿童无法触及的原装锁柜中，严禁分享或转售。
   - 过期、破损或不再需要的药物，须送至医院/药房专用回收点，严禁冲入马桶或混入生活垃圾，防止环境污染与药物滥用。
5. **预先医疗指示（ACP）沟通**：
   - 鼓励患者在意识清醒时与家属及医疗团队讨论终末期治疗意愿（如是否接受气管插管、心肺复苏、有创镇痛）。签署预先医疗指示，确保在疾病晚期仍能维护尊严，实现“无痛、无恐惧、有尊严”的离世目标。

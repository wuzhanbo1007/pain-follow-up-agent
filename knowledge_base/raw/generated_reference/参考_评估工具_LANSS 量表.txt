# LANSS 量表

文档标题：LANSS 量表

类别：评估工具

## 一、概述
问诊+感觉测试筛查 NP。
LANSS（Leeds Assessment of Neuropathic Symptoms and Signs）量表是由澳大利亚学者Bennett等开发的一种标准化神经病理性疼痛（Neuropathic Pain, NP）筛查与评估工具。该量表创新性地结合了主观症状问诊与客观体征检查，共包含15个条目，其中13项为症状自评（每项0-2分），2项为医师查体（轻触觉与针刺觉，每项0-2分），总分范围0-24分。临床普遍采用≥12分作为神经病理性疼痛的阳性截断值，其敏感性与特异性在多项国际多中心研究中均保持在85%-90%以上。在PainSmart慢性疼痛随访体系中，LANSS不仅是门诊初筛的“金标准”之一，更是贯穿疾病全程的动态监测标尺。通过量化刺痛、烧灼感、电击样痛、触诱发痛及感觉减退等核心特征，该工具有效弥补了传统单一强度评分（如NRS）在病因分型上的盲区，为精准分型、靶向用药及疗效追踪提供了可量化的临床依据。

## 二、病理生理机制
评估工具将主观疼痛与功能、情绪、睡眠等维度量化，便于纵向比较与随访决策，弥补仅凭回忆的偏差。不同工具侧重点不同（强度、神经病理成分、干扰、情绪、睡眠），应依据场景组合使用并理解其适用边界与信效度。
神经病理性疼痛的本质是感觉神经系统任何部位（外周或中枢）的损伤或疾病所引发的异常疼痛信号处理。LANSS量表所捕捉的临床特征，直接映射于复杂的神经生物学病理机制：
1. 外周敏化与异位放电：感觉神经元轴突损伤后，电压门控钠通道（如Nav1.7/1.8/1.9）与钙通道（如Cav3.2）表达上调或分布异常，导致静息膜电位去极化，产生自发性异位放电。这直接对应LANSS中的“自发性疼痛”条目（烧灼、刺痛、电击样）。
2. 中枢敏化与突触可塑性：伤害性信号持续传入脊髓背角，引发NMDA受体激活、CCK释放及星形胶质细胞/小胶质细胞活化，导致兴奋性突触后电位（EPSP）放大与抑制性中间神经元功能受损。此机制解释了“痛觉超敏”与“触诱发痛”（轻触即痛）的病理基础，也是LANSS查体部分的核心评估对象。
3. 下行调制通路失衡：中脑导水管周围灰质（PAG）-延髓头端腹内侧区（RVM）下行抑制通路功能减弱，同时下行易化通路亢进，导致内源性镇痛系统失效。这与量表反映的疼痛慢性化、难治性及伴随的睡眠障碍、情绪共病高度相关。
4. 结构重塑与脱髓鞘：轴突变性、Wallerian变性或脱髓鞘改变导致神经纤维异常耦合（ephaptic transmission），产生短路的异常信号传导。LANSS中的“感觉缺失”条目正是对大纤维（Aβ）或小纤维（C/δ）功能受损的客观提示。
通过将这些微观机制转化为可量化的宏观评分，LANSS实现了从“经验性镇痛”向“机制导向治疗”的跨越，使临床决策具备坚实的病理生理学支撑。

## 三、临床评估与筛查
依据评估目的选择工具：强度用 NRS/VAS，神经病理用 ID Pain/DN4/painDETECT，干扰用 BPI，情绪用 PHQ-9/GAD-7，睡眠用 PSQI，生活质量用 SF-36/EQ-5D。定期复测以观察趋势，并将结果转化为可执行的随访计划与目标调整，避免“为评分而评分”。
在PainSmart标准化随访路径中，LANSS并非孤立使用，而是作为多维疼痛评估矩阵的核心枢纽。临床筛查应遵循“初筛-确诊-分型-动态监测”的闭环逻辑：
1. 初筛与分型定位：门诊首诊时，优先使用LANSS或painDETECT进行NP快速筛查。若LANSS≥12分，结合病史（糖尿病、带状疱疹、手术/创伤史、脊柱病变）及查体（轻触觉、针刺觉、冷觉、振动觉、两点辨别觉），可高度提示NP诊断。此时需同步启用NRS/VAS量化主观强度，利用BPI评估疼痛对情绪、睡眠、行走、工作等日常功能的干扰程度。
2. 鉴别诊断与排除：LANSS阳性需与伤害性疼痛（骨关节炎、软组织损伤）、炎性疼痛及心因性疼痛相鉴别。必要时结合神经传导速度（NCV）、肌电图（EMG）、定量感觉测试（QST）及MRI/超声影像学检查，明确损伤节段与性质（大纤维vs小纤维神经病）。
3. 信效度与场景适配：LANSS在糖尿病周围神经病、带状疱疹后神经痛、脊柱术后综合征中验证充分，但在复杂区域疼痛综合征（CRPS）或纤维肌痛中特异性可能下降。临床应结合ID Pain（侧重症状）或DN4（侧重体征）交叉验证，避免单一工具局限。
4. 动态复测与目标转化：评估绝非一次性动作。依据PainSmart系统设定，基线评估后应在干预后2-4周、1-3个月定期复测LANSS总分及各子维度得分。将评分变化转化为可执行的随访计划：如触诱发痛分下降提示外周敏化缓解，可逐步降阶梯用药；若烧灼痛分持续高位，则需强化中枢调节药物或考虑介入治疗。坚决摒弃“唯分数论”，始终将评分回归到“改善功能、提升生活质量”的临床终点。

## 四、专家诊疗思路（按类别）
疼痛是主观的，没有工具就靠猜。我在门诊常规用 NRS 量化强度，但绝不止看一个数字——BPI（简明疼痛量表）能告诉我痛对生活各方面的干扰，PHQ-9/GAD-7 筛查抑郁焦虑共病，PSQI 看睡眠，ID Pain/DN4/painDETECT 专门抓神经病理成分。随访时这些工具要纵向复测，看的是趋势不是单次值。关键是对结果“采取行动”：共病阳性的转心理科，干扰重的积极干预，神经病理阳性的换用对应药物。工具不是给科研凑数的，是用来决定下一步方案的。
基于多年疼痛专科临床实践与PainSmart随访数据积累，我总结出一套“以机制为导向、以工具为导航、以目标为终点”的诊疗决策树：
1. 分数解读与临床映射：LANSS 0-3分基本排除NP；4-11分为“可能NP”，需结合影像学与其他量表综合判断；≥12分高度提示NP。但分数本身不是终点，必须拆解子维度：若“电击样/刺痛”分高，提示小纤维或神经根急性激惹，首选加巴喷丁类或普瑞巴林；若“触诱发痛/轻触痛”分突出，提示Aβ纤维异常敏化或中枢敏化显著，应优先考虑SNRI（度洛西汀）或外用利多卡因/辣椒素；若“感觉减退”分高，提示神经结构损伤较重，药物反应可能有限，需尽早评估神经调控或康复介入。
2. 多维共病整合：疼痛从不孤立存在。NRS仅反映强度，BPI揭示功能剥夺，PHQ-9/GAD-7捕捉情绪共病，PSQI量化睡眠碎片化。当LANSS提示NP且BPI显示“睡眠干扰”≥4分、PHQ-9≥10分时，单一镇痛药往往失效。此时必须启动“身心同治”策略：在优化NP药物的同时，联合SSRI/SNRI抗抑郁治疗、认知行为干预或睡眠卫生指导。共病阳性者务必转介临床心理科或睡眠医学中心，打破“疼痛-失眠-焦虑-疼痛加重”的恶性循环。
3. 趋势驱动与阶梯决策：随访的核心是看斜率而非单点。若连续两次复测LANSS总分下降≥2分且BPI功能分改善，说明当前方案有效，应维持并逐步强化康复；若分数平台期或反弹，且伴随药物不良反应（如头晕、嗜睡、水肿），则需果断调整：更换药物类别、优化给药时间（如普瑞巴林分次服用或睡前顿服）、联合非药物疗法，或升级至介入治疗。工具的价值在于触发临床动作（Actionable Insight），而非堆积数据。
4. 避坑指南：警惕“安慰剂效应”与“报告偏倚”。部分患者因期待好转而主观低报，或因疾病疲惫而高报。医师需结合客观体征（如皮温、出汗异常、肌肉萎缩）、功能测试（步态、握力）及家属访谈进行三角验证。记住：没有工具的评估是盲人摸象，但脱离临床判断的工具是纸上谈兵。

## 五、处理原则（药物与干预）
含触诱发痛测试
临床快速
≥12 提示 NP
需查体配合
### 通用处理框架与用药要点（按类别）
按维度组合使用工具（强度 NRS/VAS、神经病理 ID Pain/DN4、干扰 BPI、情绪 PHQ-9/GAD-7、睡眠 PSQI），并在基线+随访复测以观察趋势。
用结果指导随访频率与目标：高干扰或共病阳性需积极干预与转介，避免仅看单次 NRS。
神经病理性疼痛的治疗必须遵循“机制匹配、阶梯递进、多模态联合”的原则。LANSS评分直接指导治疗靶点选择：
1. 一线药物治疗（中枢敏化与离子通道调节）：
   - 钙通道α2-δ配体：普瑞巴林（起始75mg bid，滴定至150-300mg bid）与加巴喷丁（起始300mg qd，滴定至900-1800mg/d）是NP基石药物。适用于烧灼痛、电击样痛及自发性疼痛突出者。需监测体重增加、周围性水肿及认知副作用，老年患者需按eGFR调整剂量。
   - SNRI类：度洛西汀（起始30mg qd，维持60mg qd）与文拉法辛。通过增强5-HT/NE下行抑制通路，对伴抑郁、焦虑或广泛性疼痛敏化者尤佳。注意血压监测及停药综合征。
   - TCA类：阿米替林/去甲替林（起始10-25mg qn，滴定至50-100mg）。疗效确切但抗胆碱能副作用（口干、便秘、尿潴留、QT间期延长）限制其使用，尤其禁用于青光眼、前列腺肥大及心律失常患者。
2. 二线与局部治疗（外周靶点与敏化阻断）：
   - 外用制剂：5%利多卡因贴剂（针对局部触诱发痛、带状疱疹后神经痛）、8%辣椒素贴剂（耗竭P物质，单次60分钟贴敷可维持3个月疗效）。适用于LANSS触诱发痛分高且疼痛范围局限者，全身副作用极低。
   - 阿片类药物：曲马多、羟考酮缓释片等仅作为三线选择，用于其他治疗失败且无物质滥用史的难治性NP。需严格评估成瘾风险、便秘管理、呼吸抑制监测，并设定明确的停药或转介计划。
3. 介入与神经调控（中重度/难治性NP）：
   - 周围神经阻滞/脉冲射频：针对明确单神经病变（如肋间神经痛、股神经痛、三叉神经痛），可打断异位放电环路。
   - 脊髓电刺激（SCS）与背根神经节电刺激（DRG-SCS）：针对腰椎术后综合征、复杂性区域疼痛综合征（CRPS）、难治性足底神经痛。通过门控理论抑制背角伤害性信号传导，显著降低LANSS总分与NRS评分。
   - 鞘内药物输注系统（IDDS）：植入吗啡/齐考诺肽泵，适用于全身用药无效或不耐受者，可实现靶向给药、大幅降低系统毒性。
4. 联合用药策略：基于PainSmart临床路径，单一机制药物有效率仅约30-50%。推荐“机制互补”联合：如普瑞巴林+度洛西汀（外周+中枢+下行通路），或口服药+外用贴剂。联合需遵循“单药滴定至最大耐受剂量无效后，再加用第二药”的原则，避免盲目叠加。

## 六、非药物与康复
评估本身配合患者教育；结果用于制定个体化目标与随访计划，确保工具使用一致以便趋势比较。
教会患者正确自评，减少因误解导致的焦虑或过度关注。
神经病理性疼痛的康复必须超越“被动镇痛”，转向“主动功能重建”。LANSS评估结果可直接映射至康复处方：
1. 感觉再教育与脱敏训练：针对LANSS提示“触诱发痛”或“感觉过敏”的患者，采用分级触觉刺激（棉签、不同质地布料、温水/冷水交替）进行系统脱敏。通过重复、可控的感觉输入，重塑大脑皮层感觉映射区，降低中枢敏化阈值。
2. 分级运动想象与镜像疗法：适用于肢体NP伴运动恐惧（Kinesiophobia）或轻度功能障碍者。通过观看健康肢体运动视频或进行想象训练，激活镜像神经元系统，抑制痛觉相关脑区（如岛叶、前扣带回）过度活跃，改善疼痛与运动协调性。
3. 物理因子治疗：经皮神经电刺激（TENS）通过高频（>50Hz）激活Aβ纤维门控机制，或低频（<10Hz）促进内源性阿片释放；干扰电、激光治疗、超声波可改善局部微循环、减轻神经水肿。需根据LANSS体征选择参数，避免在感觉缺失区使用以防烫伤。
4. 心理行为干预：认知行为疗法（CBT）帮助患者识别并重构“疼痛=灾难”的非理性信念，打破疼痛-回避循环；接纳与承诺疗法（ACT）强调与疼痛共存并投入价值导向生活；正念减压（MBSR）通过非评判性觉察降低疼痛情绪效价。PainSmart系统内置数字化CBT模块，可配合量表复测进行远程干预。
5. 康复目标设定：摒弃“完全无痛”的不切实际目标，转向“功能恢复”与“生活质量提升”。依据BPI与LANSS趋势，设定SMART目标（如：4周内触诱发痛范围缩小30%，能连续步行15分钟，睡眠中断次数≤1次/夜）。康复是药物疗效的放大器，也是预防慢性化的关键防线。

## 七、随访与监测要点
复测趋势
在PainSmart慢性疼痛管理体系中，随访不是简单的“开药复查”，而是基于数据驱动的动态风险管理过程。LANSS量表的纵向复测是核心监测指标：
1. 标准化复测节点：初始治疗/方案调整后2-4周（评估耐受性与早期疗效）；稳定治疗期每1-3个月（评估长期趋势与功能变化）；干预方案变更或出现新症状时即时复测。每次复测需保持环境、指导语、评分标准一致，确保数据可比性。
2. 多维参数同步追踪：除LANSS总分外，必须同步记录NRS强度变化、BPI功能干扰分、PHQ-9/GAD-7情绪筛查、PSQI睡眠质量及药物不良反应（如头晕、嗜睡、便秘、体重变化）。PainSmart系统通过算法生成“疼痛-功能-情绪-睡眠”四维雷达图，直观呈现治疗响应模式。
3. 疗效判定与方案迭代：有效标准通常定义为NRS下降≥30%或≥50%，且LANSS总分下降≥2分，伴随BPI功能分改善。若连续两次复测无改善或恶化，需启动“治疗失败评估”：核查依从性、排除新发病变、调整药物类别/剂量、联合非药物疗法或升级介入治疗。
4. 数字化远程监测：依托PainSmart移动端，患者可每周完成简版LANSS与NRS自评，系统自动预警分数异常波动（如触诱发痛分骤升提示神经激惹加重，或分数持续高位伴PHQ-9升高提示共病恶化）。医师端实时接收趋势报告，实现“数据预警-主动干预-精准随访”的闭环管理。

## 八、预警与转诊指征
感觉缺失者受限
神经病理性疼痛的病程中，部分信号提示疾病进展、并发症或诊断偏差，需立即启动预警与多学科转诊机制：
1. 神经功能进行性恶化预警：LANSS提示感觉缺失范围扩大、肌力进行性下降、腱反射消失或出现病理征。需紧急转诊神经内科/脊柱外科，排除脊髓压迫、马尾综合征、进行性周围神经病或肿瘤浸润。影像学（MRI/CT）与电生理检查必须优先于镇痛治疗。
2. 全身性与系统性红旗征：伴发热、盗汗、不明原因体重下降、多系统受累（皮疹、关节肿痛、肾功能异常）。警惕感染性神经病（HIV、莱姆病）、副肿瘤综合征、自身免疫性神经病（如血管炎、副蛋白血症）或代谢危象。需转诊风湿免疫科、血液科或感染科进行全身筛查。
3. 精神心理危机预警：PHQ-9≥15分、GAD-7≥15分，或患者流露绝望感、自杀意念、严重睡眠剥夺。疼痛与精神障碍互为因果，此时单纯镇痛无效且危险。必须紧急转介临床心理科/精神科，启动危机干预，必要时联合住院进行药物重整与心理治疗。
4. 难治性疼痛与介入指征：经规范足量足疗程（≥8-12周）一线药物联合治疗，NRS仍≥6分，LANSS总分无下降，BPI功能严重受损，且排除可逆性病因。符合脊髓电刺激（SCS）、DRG调控、鞘内泵植入或周围神经毁损/脉冲射频的适应证。需转诊疼痛介入专科进行多学科评估（MDT）。
5. 特殊人群预警：老年患者出现认知功能下降、跌倒风险增加（可能与药物副作用或感觉缺失有关）；儿童/青少年NP需排查发育性神经疾病或心理社会因素；孕妇NP用药需严格遵循FDA妊娠分级，优先非药物干预。此类情况应转诊相应专科联合管理。

## 九、患者教育与自我管理
教会患者正确使用量表与疼痛日记；理解分数意义以便医患沟通。
鼓励如实记录，便于随访调整；避免为“好看”而低报或过度关注数字。
疼痛管理是一场医患协同的马拉松，患者教育是提升依从性、打破认知误区、赋能自我管理的核心环节：
1. 神经病理性疼痛机制科普（Pain Neuroscience Education, PNE）：向患者清晰解释“疼痛不等于组织损伤”，阐明神经敏化、中枢放大、情绪睡眠交互作用的科学原理。使用PainSmart提供的可视化模型与动画，帮助患者理解烧灼感、电击痛、轻触痛的生物学基础，降低“未知恐惧”与“灾难化思维”。
2. 量表与疼痛日记规范使用：指导患者每日固定时间（如睡前）填写NRS、简版LANSS及疼痛日记。强调记录内容应包括：疼痛部位/性质、强度、诱发/缓解因素、活动量、睡眠时长、用药时间与剂量、情绪状态。明确告知：“分数是导航仪，不是判决书”。低报会掩盖病情，高报源于焦虑，如实记录才是调整方案的基石。
3. 药物依从性与预期管理：详细讲解处方药物的起效时间（通常需2-4周达稳态）、滴定原则（“Start low, go slow”）、常见副作用（多为暂时性）及应对策略。破除“止痛药会上瘾”“激素类药物不能长期用”等误区，强调规范用药的风险收益比。建立“药物-症状”对应表，帮助患者识别有效信号与不良反应。
4. 生活方式与行为重塑：制定个体化活动计划，遵循“ pacing（能量分配）”原则，避免“爆发-崩溃”循环。指导睡眠卫生（固定作息、卧室环境优化、睡前放松训练）、营养支持（控制血糖/血脂、补充B族维生素/α-硫辛酸）、压力管理（腹式呼吸、渐进性肌肉放松）。鼓励参与支持性团体，分享应对经验，减少病耻感。
5. 数字化工具与医患协同：推广PainSmart患者端APP，实现量表自动计算、趋势图表生成、用药提醒、在线问诊与紧急预警。教育患者将数据视为“医患对话的共同语言”，复诊时携带完整记录，共同制定下一阶段目标。赋予患者“疼痛管理者”而非“被动承受者”的角色认同，是提升长期预后与生活质量的最有效策略。

# 对乙酰氨基酚

文档标题：对乙酰氨基酚
===== 原文开始 =====
类别：药物

## 一、概述
对乙酰氨基酚（Acetaminophen/Paracetamol）是临床最常用的一线解热镇痛药物，属于非阿片类中枢性镇痛药。其核心药理特征为：具有明确的解热与镇痛作用，但几乎无外周抗炎活性；主要经肝脏代谢，不抑制外周环氧合酶（COX-1/COX-2），因此胃肠道出血与肾脏损伤风险显著低于非甾体抗炎药（NSAIDs）。在慢性疼痛管理阶梯中，对乙酰氨基酚被列为轻度至中度伤害性疼痛（如骨关节炎、术后疼痛、头痛、牙痛）的首选基础用药。尽管近年来关于其绝对疗效的循证医学证据有所争议，但在联合镇痛策略（Multimodal Analgesia）中，它仍凭借优异的安全性 profile 和药物相互作用少等优势，占据不可替代的基础地位。

## 二、病理生理机制
本类药物通过特异性靶点或通路发挥作用：NSAID 抑制环氧合酶减少前列腺素；钙通道调节剂（加巴喷丁类）结合 α2-δ 亚基；SNRI/三环类调节单胺再摄取；阿片激动 μ 受体；钠通道阻滞剂抑制异位放电。
镇痛疗效与安全性取决于药代特征、剂量及个体差异（年龄、肝肾功能、合并用药），应结合机制选药并全程监测不良反应。

【专业扩充】对乙酰氨基酚的镇痛与解热机制尚未完全阐明，目前主流假说集中于中枢神经系统。其并非通过抑制外周前列腺素合成发挥抗炎作用，而是通过选择性抑制中枢神经系统（尤其是下丘脑和脊髓背角）的环氧合酶同工酶（传统认为涉及COX-3，现多认为为COX-1/COX-2的变体或特定微环境下的活性形式），降低中枢前列腺素E2（PGE2）水平，从而提升痛阈并调节体温调定点。此外，该药还能激活下行5-羟色胺（5-HT）能镇痛通路，调节瞬时受体电位香草酸亚型1（TRPV1）通道，并发挥一定的抗氧化与神经保护效应。
在药代动力学方面，口服后吸收迅速且完全，血浆达峰时间约30-60分钟，生物利用度约63%-89%。半衰期约为2-3小时。肝脏代谢是其主要消除途径：约90%通过Ⅱ相结合反应（葡萄糖醛酸结合约占50%-60%，硫酸结合约占30%-40%）生成无毒代谢物经肾脏排泄；仅约5%-10%经细胞色素P450酶系（主要为CYP2E1，其次为CYP3A4和CYP1A2）氧化生成高活性、高毒性的中间代谢物N-乙酰对苯醌亚胺（NAPQI）。在正常剂量下，NAPQI可迅速与肝细胞内的谷胱甘肽（GSH）结合解毒；但当剂量过大、长期饮酒或营养不良导致GSH耗竭时，NAPQI将蓄积并与肝细胞蛋白共价结合，引发氧化应激、线粒体功能障碍及中心静脉区肝细胞坏死。因此，其镇痛疗效与安全性高度依赖于精准的剂量控制与个体化代谢评估。

## 三、临床评估与筛查
评估适应证、禁忌与合并用药相互作用；记录基线肝肾功能、心血管与胃肠风险及既往药物不良反应史。
治疗中随访疗效与不良反应，必要时监测血药浓度或器官功能；对复方制剂核算单一成分日总量防重复。

【专业扩充】处方前必须进行结构化临床评估。首先明确疼痛性质（伤害性、神经病理性或混合性）与严重程度（采用NRS/VAS评分及功能障碍量表），严格把握适应证。重点筛查禁忌证：活动性肝病（如病毒性肝炎活动期、肝硬化失代偿期）、严重肾功能不全（eGFR<30 mL/min/1.73m²需谨慎）、对乙酰氨基酚过敏史。详细评估合并用药，特别是华法林（可增强抗凝作用，INR升高）、抗癫痫药（卡马西平、苯妥英钠可诱导CYP酶加速代谢）、异烟肼（竞争性抑制硫酸结合，增加肝毒性风险）及酒精使用史。
基线评估必须包含：肝功能全套（ALT、AST、ALP、总胆红素、白蛋白）、肾功能（肌酐、eGFR）、血常规及凝血功能。对于长期用药或老年患者，需评估心血管与胃肠道基础风险，尽管对乙酰氨基酚本身不增加GI出血风险，但合并使用抗血小板或抗凝药物时需格外警惕。既往药物不良反应史（如皮疹、肝酶异常）需详细记录。治疗期间应动态随访，对于超剂量使用、肝酶临界升高或出现可疑肝损伤症状者，必要时监测血药浓度（结合Rumack-Matthew列线图评估毒性风险），并定期复查器官功能。针对市售数十种含对乙酰氨基酚的复方感冒药、止痛药及中成药，临床药师与医师必须逐项核算单一成分日总量，严防“隐性重复用药”导致的肝毒性。

## 四、专家诊疗思路（按类别）
选药先看机制与疼痛性质。伤害性（炎性、术后、骨痛）优选对乙酰氨基酚与 NSAID；神经病理性痛用钙通道调节剂（加巴喷丁类）、SNRI（度洛西汀）、三环类（阿米替林）或外用利多卡因；中重度癌痛用阿片。
NSAID 别两种叠加，也别长期超量——胃肠出血、血压升高、肾功能损害是其“三宗罪”，外用剂型全身暴露小、更安全。复方制剂要核算单一成分日总量，避免对乙酰氨基酚重复摄入（通常≤2000–3000 mg/日）。
阿片+苯二氮䓬是呼吸抑制高危组合，曲马多+SSRI/SNRI 有 5-羟色胺综合征风险。任何长期用药都要定期复审：还有效吗？副作用可控吗？能不能减？

【专业扩充】临床选药必须遵循“机制导向、疼痛分型、阶梯用药、多模式联合”的原则。
1. 伤害性疼痛：急性术后痛、牙痛、创伤痛首选对乙酰氨基酚单药或联合NSAIDs（如布洛芬、塞来昔布），协同增效且可延缓阿片类使用。慢性骨关节炎（OA）一线推荐对乙酰氨基酚，若疗效不足可联合外用NSAIDs或关节腔注射。
2. 神经病理性疼痛：对乙酰氨基酚单药疗效有限，不作为首选。应优先使用钙通道调节剂（加巴喷丁、普瑞巴林）、SNRIs（度洛西汀、文拉法辛）、TCAs（阿米替林）或局部外用利多卡因贴剂/辣椒素。若为混合性疼痛（如糖尿病周围神经病变伴炎性成分），可将其作为辅助镇痛药联合使用。
3. 癌痛管理：遵循WHO三阶梯原则，作为第一、二阶梯基础用药。与阿片类联用可产生协同镇痛作用，减少阿片剂量及相关副作用（如便秘、恶心、呼吸抑制）。
4. 特殊人群策略：老年人（>65岁）代谢能力下降，日总量应严格限制在2000mg以内；儿童按体重计算（10-15 mg/kg/次，间隔4-6小时）；孕妇（FDA妊娠B级）为妊娠期首选镇痛解热药；肝功能不全者需减量或禁用（Child-Pugh B/C级禁用）。
5. 药物相互作用与风险管控：严格避免两种NSAIDs叠加使用；复方制剂必须核算对乙酰氨基酚日总量（慢性疼痛常规推荐≤2000-3000 mg/日，短期急性痛且肝功能正常者最高不超过4000 mg/日，但近年FDA及多国指南趋向保守推荐≤3000 mg/日）。警惕阿片类与苯二氮䓬类联用导致的致命性呼吸抑制；曲马多或SSRI/SNRI联用需警惕5-羟色胺综合征（高热、肌阵挛、自主神经不稳定）。建立定期用药复审（Medication Review）机制：每1-3个月评估镇痛疗效、功能改善程度、不良反应及依赖风险，遵循“有效则维持，无效则调整，副作用不可控则减量或停药”的原则，避免长期无指征用药。

## 五、处理原则（药物与干预）
成人日总量通常≤2000–3000mg
过量致严重肝损伤
不与含对乙酰氨基酚复方重复
起效快、胃肠安全
肝功能异常者减量

### 通用处理框架与用药要点（按类别）
按机制与疼痛类型选药：伤害性痛优选对乙酰氨基酚/NSAID（外用优先），神经病理痛用钙通道调节剂/SNRI/三环类/外用利多卡因，中重度癌痛用阿片。
遵循低剂量起始、逐步滴定、最低有效剂量与定期复审；核对复方成分防重复（如对乙酰氨基酚日总量通常≤2000–3000 mg），规避相互作用（NSAID 叠加、阿片+苯二氮䓬、曲马多+SSRI/SNRI 致 5-HT 综合征）。

【专业扩充】
【剂量与给药规范】
- 普通片/胶囊：每次500-1000mg，每4-6小时一次，按需服用。
- 缓释制剂：每次650-1000mg，每6-8小时一次，不可掰开或嚼碎。
- 最大安全剂量：健康成人短期使用≤4000mg/日；慢性疼痛管理、老年、低体重（<50kg）、长期饮酒或营养不良者严格限制在≤2000-3000mg/日。
- 给药时机：可空腹或餐后服用，食物不影响吸收但可减轻轻微胃肠不适。避免与酒精同服。
【干预与联合策略】
对乙酰氨基酚具有明确的“天花板效应”（Ceiling Effect），超过最大剂量并不能增强镇痛效果，反而线性增加肝毒性风险。因此，对于中重度疼痛，不应盲目加量，而应转向多模式镇痛（MMA）：联合NSAIDs、局部外用药物、神经阻滞或物理治疗。对于难治性慢性疼痛，可考虑介入治疗（如射频消融、脊髓电刺激SCS、鞘内药物输注系统IDDS），但需严格把握适应证并由疼痛科专科医师操作。
【禁忌与慎用】
绝对禁忌：严重肝衰竭、对乙酰氨基酚过敏、急性酒精中毒期。
相对禁忌/慎用：轻中度肝功能异常（Child-Pugh A级需减量至2g/日）、重度肾功能不全、G6PD缺乏症（有溶血风险）、甲状腺功能亢进（增加CYP2E1活性，需减量）。
【用药教育核心】
严格遵循“最低有效剂量、最短必要疗程”原则。不推荐作为慢性疼痛的单一长期维持用药，除非联合其他机制药物。定期评估“疼痛日记”与功能目标，避免药物过度使用性头痛（MOH）或慢性疼痛敏化。

## 六、非药物与康复
多数药物辅以生活方式调整（如骨关节炎减重、糖尿病神经病变控糖、痛风低嘌呤），提升整体疗效。
用药教育提升依从性与安全性，减少误用与重复成分摄入。

【专业扩充】慢性疼痛管理强调“生物-心理-社会”医学模式，药物治疗仅为综合干预的基石之一。必须同步实施非药物与康复策略：
1. 运动康复：针对骨关节炎、慢性腰背痛，推荐低冲击有氧运动（游泳、快走、骑自行车）结合核心肌群强化训练。运动可促进内源性阿片肽释放，改善关节滑液循环，减轻中枢敏化。
2. 体重管理与代谢控制：肥胖是OA和慢性炎症性疼痛的核心驱动因素。减重5%-10%可显著降低关节负荷与全身炎症因子（IL-6, TNF-α）水平。糖尿病神经病变需严格控糖（HbA1c<7.0%），改善微循环与神经传导。
3. 心理与行为干预：认知行为疗法（CBT）、正念减压（MBSR）及疼痛神经科学教育（PNE）可有效打破“疼痛-恐惧-回避”恶性循环，降低疼痛灾难化思维，提升药物疗效与功能恢复。
4. 物理因子治疗：经皮神经电刺激（TENS）、热疗、冷敷、超声波及冲击波治疗可作为急性期或间歇期的辅助手段，缓解肌肉痉挛与局部炎症。
5. 睡眠与营养管理：慢性疼痛常伴发睡眠障碍，需优先干预睡眠（睡眠卫生教育、必要时短期使用助眠药物），因睡眠剥夺会显著降低痛阈。营养方面建议均衡膳食，补充维生素D、Omega-3脂肪酸及抗氧化剂，辅助神经修复与抗炎。
6. 依从性提升策略：通过结构化用药教育、电子提醒APP、家属监督及定期随访，确保患者准确理解药物作用、副作用识别及复方成分核对方法，从根本上杜绝重复用药与剂量滥用。

## 七、随访与监测要点
肝功能
是否重复用药
日总量

【专业扩充】建立标准化、周期性的疼痛药物随访监测体系是保障长期用药安全的核心。
【监测频率与项目】
- 基线期（处方前）：全面评估肝肾功能（ALT、AST、ALP、TBil、Cr、eGFR）、血常规、凝血功能、酒精使用筛查（AUDIT-C）、心理状态（PHQ-9/GAD-7）。
- 初始治疗期（1-2周）：评估镇痛起效时间、NRS评分变化、胃肠道及中枢神经系统不良反应。核查是否合并使用含对乙酰氨基酚的OTC药物。
- 稳定期（1-3个月）：复查肝功能（尤其ALT/AST），评估长期用药安全性。使用标准化量表（如PROMIS疼痛干扰量表、ODI功能障碍指数）量化功能改善程度。
- 长期维持期（每3-6个月）：全面复审用药指征、剂量合理性、药物依赖风险及合并症变化。对肝酶持续轻度升高（>1.5倍ULN）者，缩短监测间隔至2-4周，必要时行肝脏超声或FibroScan评估。
【关键监测指标】
1. 肝功能动态追踪：ALT/AST是早期肝损伤最敏感指标。若升高>3倍ULN或伴胆红素升高，立即停药并启动肝毒性评估流程。
2. 复方成分核对：建立“药物清单核对表”，强制核查感冒药、中成药、复方止痛贴剂中的对乙酰氨基酚含量，确保日总量≤推荐上限。
3. 日总量与血药浓度：对于疑似过量或肝酶异常者，采集血样绘制Rumack-Matthew列线图，指导N-乙酰半胱氨酸（NAC）解毒时机。
4. 功能与生活质量：疼痛评分必须与功能恢复（行走距离、睡眠时长、工作能力）结合评估，避免“唯分数论”。

## 八、预警与转诊指征
误服过量立即就医（解毒窗）

【专业扩充】建立分级预警与快速转诊通道，是防范药物相关严重不良事件（SAE）的关键。
【急性预警指征（需立即停药并急诊就医）】
1. 药物过量中毒：单次摄入>150mg/kg或成人>7.5g，或24小时总量>4g且伴高危因素。早期症状隐匿（恶心、呕吐、厌食、右上腹痛），6-24小时可出现肝酶飙升、凝血障碍、黄疸、意识模糊。解毒黄金窗口期为摄入后8-10小时内，需立即静脉输注N-乙酰半胱氨酸（NAC）。
2. 严重皮肤不良反应：虽罕见，但需警惕Stevens-Johnson综合征（SJS）或中毒性表皮坏死松解症（TEN），表现为广泛皮疹、水疱、黏膜糜烂、高热。
3. 过敏性休克/血管神经性水肿：呼吸困难、喉头水肿、血压骤降，需肾上腺素急救。
4. 肝衰竭征象：极度乏力、进行性黄疸、腹水、肝性脑病、INR显著延长。
【专科转诊指征】
1. 疼痛控制不佳：规范使用对乙酰氨基酚联合其他机制药物4-8周后，NRS评分下降<30%或功能障碍无改善，需转诊疼痛科评估介入治疗（神经阻滞、射频、SCS等）或调整镇痛阶梯。
2. 疑似神经病理性疼痛主导：出现烧灼痛、电击痛、痛觉超敏/过敏，需转诊神经内科或疼痛科，启动抗惊厥药/抗抑郁药方案。
3. 肝肾功能进行性恶化：药物性肝损伤（DILI）确诊或eGFR持续下降，需转诊肝病科/肾内科及临床药学部进行多学科会诊（MDT）。
4. 复杂共病与心理社会因素：合并重度抑郁/焦虑、物质滥用障碍、创伤后应激障碍（PTSD）或社会支持系统缺失，需转诊心理精神科及社会工作者，实施生物-心理-社会综合干预。
5. 特殊人群管理：儿童复杂疼痛、妊娠期合并症、老年多重用药（Polypharmacy）患者，建议转诊至专科疼痛门诊或临床药师进行个体化方案重构。

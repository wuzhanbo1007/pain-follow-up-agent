# 肠易激综合征(IBS)腹痛
类别：内脏痛

## 一、概述
肠易激综合征（Irritable Bowel Syndrome, IBS）是一组以慢性或复发性腹痛、腹胀为核心症状，并伴随排便习惯（频率、性状）改变及肠道功能紊乱为特征的功能性肠病。根据罗马IV诊断标准，IBS属于脑-肠互动紊乱疾病（DGBI），其病理基础并非肠道器质性破坏，而是神经-内分泌-免疫-微生态网络的功能性失调。临床表现为反复发作的腹痛，通常在排便后缓解或伴随排便频率/粪便性状改变，常受饮食、情绪、压力及昼夜节律影响。IBS全球患病率约5%~10%，女性多见，好发于青中年，具有病程迁延、易复发、显著影响生活质量及医疗资源消耗的特点。作为典型的内脏痛综合征，IBS腹痛的管理需跳出“单纯对症止痛”的局限，转向以脑-肠轴调控为核心的多学科综合干预模式。

## 二、病理生理机制
内脏痛由空腔脏器牵张、缺血、炎症或脏器包膜受牵拉引发，经交感和迷走神经传入，常定位模糊并伴自主神经与情绪反应。在IBS中，内脏痛的产生与维持涉及多机制交互：
1. **脑-肠轴（Brain-Gut Axis）失调**：中枢神经系统对肠道传入信号的整合与下行抑制功能异常，导致疼痛阈值显著降低。慢性应激通过下丘脑-垂体-肾上腺（HPA）轴激活，释放皮质醇与促炎细胞因子，加剧中枢敏化。
2. **内脏高敏感（Visceral Hypersensitivity）**：肠道机械感受器与化学感受器敏感性异常增高，正常生理性肠腔扩张（如进食后、气体积聚）即可触发痛觉传导，表现为绞痛、胀痛或烧灼样痛。
3. **胃肠动力与分泌异常**：平滑肌收缩节律紊乱（痉挛性收缩或推进力减弱），导致肠腔内压波动异常；肠道分泌功能失调引起腹泻或便秘，进一步加重黏膜牵张与痛觉放大。
4. **肠道微生态失衡与低度炎症**：菌群多样性下降、条件致病菌增殖，短链脂肪酸代谢异常，肠腔产气增多；黏膜肥大细胞活化释放组胺、5-HT、蛋白酶等，直接刺激肠神经末梢。
5. **神经递质与受体异常**：肠道5-羟色胺（5-HT）分泌与受体（如5-HT3、5-HT4）表达失衡，显著影响痛觉传导、肠蠕动与分泌功能；P物质、降钙素基因相关肽（CGRP）等痛觉相关肽释放增加。
6. **牵涉痛与躯体化**：内脏痛常沿脊髓节段放射至腰背、下腹或会阴部，易与肌肉骨骼痛或妇科/泌尿科疾病混淆；长期慢性疼痛可引发躯体症状障碍，形成“痛-焦虑-痛觉放大”恶性循环。
须重点警惕急腹症等继发性病因（如肠梗阻、穿孔、缺血、炎症性肠病、结直肠癌），疼痛性质、部位、持续时间与伴随症状（呕吐、腹胀、排便改变、发热）对鉴别至关重要。

## 三、临床评估与筛查
结合病史与查体判断受累脏器，评估疼痛与进食、排便、呼吸、体位的关系及自主神经伴随症状。IBS的评估需遵循“排除器质性疾病+确认功能紊乱+量化症状负荷”的三步策略：
1. **系统性病史采集**：详细记录腹痛部位（多位于下腹或左下腹）、性质（绞痛、胀痛、刺痛）、强度（NRS评分）、频率、持续时间；明确与排便/进食/月经周期/情绪波动的关联；询问既往抗感染治疗史（感染后IBS）、家族史、旅行史、药物使用史（NSAIDs、抗生素、PPIs）。
2. **体格检查**：腹部触诊评估压痛部位、反跳痛、肌紧张、包块及肠鸣音；直肠指检排查盆底肌高张力、触痛或隐匿性病变；全身检查关注营养状态、贫血貌、甲状腺肿大、淋巴结肿大。
3. **报警症状（Red Flags）筛查**：年龄≥45-50岁新发症状、不明原因体重下降（>5%）、夜间痛醒、持续呕吐、进行性吞咽困难、便血/黑便、发热、贫血、腹部包块、结直肠癌/炎症性肠病家族史。任一阳性均提示需优先排查器质性病变。
4. **辅助检查策略**：基础实验室（血常规、CRP/ESR、肝肾功能、甲状腺功能、乳糜泻血清学）；粪便检查（钙卫蛋白/乳铁蛋白鉴别IBD、隐血、寄生虫、培养）；影像学（腹部超声/CT排除梗阻、肿瘤、缺血）；内镜指征：符合报警症状或筛查阳性者行结肠镜+多点活检。
5. **功能与心理评估**：罗马IV问卷确认诊断；疼痛与症状日记记录发作规律；内脏高敏感评估（球囊扩张试验）；心理筛查（HADS、GAD-7、PHQ-9）评估焦虑抑郁共病。避免仅以结构检查阴性而忽视症状管理，功能性内脏痛需综合评估脑-肠轴失调与心理共病。

## 四、专家诊疗思路（按类别）
内脏痛的难点在于定位模糊、情绪色彩重，且极易与急腹症混淆。我接诊时第一件事是排除器质病因——血便、黄疸、发热、腹胀拒按、体重下降都是报警信号，该内镜、该影像别犹豫。
功能性内脏痛（如 IBS、功能性消化不良）本质是脑-肠轴失调与内脏高敏感，单纯“止痛”无效，需要解痉药（如匹维溴铵）配合饮食调整、益生菌与应激管理。子宫内膜异位症相关痛以激素治疗（COC、GnRH-a）为一线。
对于癌性内脏痛，要识别是否为空腔脏器梗阻或肝包膜牵张，处理原发病同时，神经病理成分明显者可叠加钙通道调节剂。始终记住：内脏痛患者常合并焦虑抑郁，心理评估不能省。
在IBS腹痛的临床实践中，需建立分层、分型、靶向的诊疗路径：
1. **分型导向**：依据罗马IV及排便特征分为IBS-D（腹泻型）、IBS-C（便秘型）、IBS-M（混合型）、IBS-U（未分型）。D型侧重炎症/菌群失调与快速通过；C型侧重动力低下与粪便滞留牵张；M型交替痉挛。疼痛机制与干预靶点需个体化匹配。
2. **阶梯化药物干预**：一线以解痉药（匹维溴铵、奥替溴铵、曲美布汀）缓解平滑肌痉挛；若伴明显神经病理痛特征（烧灼、电击样、持续钝痛）或中枢敏化，阶梯加用低剂量中枢镇痛调节剂（TCA如阿米替林10-25mg qn，SNRIs如度洛西汀30-60mg/d，或加巴喷丁/普瑞巴林）。
3. **共病与鉴别管理**：子宫内膜异位症、慢性盆腔痛需妇科协同（COC、GnRH-a、地诺孕素）；癌性/器质性内脏痛需MDT处理原发病与梗阻/包膜牵张；慢性胰腺炎、胆囊功能障碍需消化科联合评估。
4. **心理-神经交互干预**：慢性疼痛常伴焦虑抑郁，形成“痛-焦虑-痛觉放大”恶性循环。心理评估（HADS等）必做，必要时转诊临床心理科/精神科，采用CBT、催眠疗法、正念减压。避免将“检查阴性”等同于“无病”而放弃症状管理，亦不可盲目使用阿片类/强效NSAIDs（加重便秘、掩盖病情、导致药物过量性疼痛）。

## 五、处理原则（药物与干预）
解痉药（如匹维溴铵）对症
膳食纤维与益生菌辅助
低 FODMAP 饮食尝试
肠道菌群-脑轴与应激管理
### 通用处理框架与用药要点（按类别）
首要针对原发病（梗阻、缺血、炎症、肿瘤），解痉药（如匹维溴铵）缓解平滑肌痉挛；若存在神经病理成分可联用神经病理药物。
功能性肠病（IBS）辅以膳食纤维、益生菌、低 FODMAP 饮食尝试与脑-肠轴/应激管理；子宫内膜异位症以激素（COC、GnRH-a）一线。
避免长期依赖止泻或止痛药物掩盖病情；疼痛性质变化或报警症状出现需及时复诊排查器质性病因。
IBS腹痛的干预需遵循“机制靶向+多模态整合+动态滴定”原则：
1. **对症解痉与动力调节**：匹维溴铵（50mg tid，餐中嚼服，选择性肠道钙通道阻滞剂）；奥替溴铵、曲美布汀（双向调节胃肠动力）；薄荷油胶囊（天然钙通道阻滞剂，缓解痉挛性腹痛，肠溶制剂防胃刺激）。
2. **神经病理痛与中枢敏化调节**：低剂量TCA（阿米替林10-25mg qn，镇痛剂量低于抗抑郁剂量，改善睡眠与痛阈，注意抗胆碱能副作用）；SNRIs（度洛西汀30-60mg/d，适用于伴广泛性疼痛或抑郁者）；加巴喷丁/普瑞巴林（针对烧灼/刺痛样内脏痛，需缓慢滴定防头晕嗜睡）。
3. **肠道微生态与代谢干预**：特定菌株益生菌（双歧杆菌、乳酸杆菌、布拉氏酵母菌，需足量足疗程≥8周）；益生元（低剂量起步防胀气）；利福昔明（Rifaximin，非吸收性抗生素，用于IBS-D伴腹胀/产气过多，疗程14天可重复）；短链脂肪酸（丁酸盐）补充修复黏膜屏障。
4. **饮食与营养干预**：低FODMAP饮食（严格期2-6周，随后系统激发与个体化维持，避免长期严格限制导致营养不良）；可溶性膳食纤维（洋车前子壳5-10g/d）优于不可溶性；避免高脂、辛辣、咖啡因、酒精、人工甜味剂。
5. **介入与物理治疗（难治性病例）**：经皮穴位电刺激（TENS）、内脏神经阻滞（腹腔神经丛阻滞，严格把握指征）、生物反馈治疗（盆底肌协同失调者）、经颅磁刺激（rTMS，调节中枢痛觉通路）。
6. **用药安全与监测**：避免长期依赖洛哌丁胺/阿片类；TCA/SNRI需监测心电图、血压、抗胆碱能副作用；益生菌注意免疫抑制患者禁忌；强调“阶梯治疗、个体化滴定、定期评估疗效与不良反应”，建立药物-症状-不良反应三联档案。

## 六、非药物与康复
针对病因的生活方式与饮食调整；盆底/内脏理疗与放松训练改善内脏高敏感，心理干预降低痛觉放大。
脑-肠轴/应激管理对功能性内脏痛尤为关键，配合规律排便与饮食记录。
非药物干预是IBS腹痛管理的基石，需整合生理、心理、行为多维度康复策略：
1. **认知行为疗法（CBT）与心理干预**：识别并修正灾难化思维与疼痛恐惧，建立主动应对策略，打破“痛-焦虑-症状加重”循环；针对创伤史或PTSD患者采用眼动脱敏与再加工（EMDR）或创伤聚焦CBT。
2. **肠道定向催眠疗法（Gut-Directed Hypnotherapy）**：经多项RCT验证可显著降低内脏高敏感，改善腹痛与排便症状，需专业治疗师指导，通常8-12次疗程。
3. **盆底与内脏物理治疗**：针对盆底肌高张力/协调障碍，进行生物反馈、手法松解、呼吸训练（腹式呼吸、膈肌呼吸），降低交感神经张力，改善盆腔血流与神经传导。
4. **规律运动与节律重建**：中等强度有氧运动（快走、游泳、瑜伽、太极）促进内啡肽与脑源性神经营养因子（BDNF）释放，改善肠动力与情绪；建立固定排便习惯（利用餐后胃结肠反射，晨起或餐后30分钟如厕）。
5. **睡眠卫生与压力管理**：慢性疼痛与睡眠障碍互为因果。建立规律作息，睡前放松训练，避免睡前屏幕暴露；必要时短期助眠干预（如褪黑素、非苯二氮䓬类），恢复昼夜节律。
6. **疼痛日记与自我监测**：记录疼痛NRS评分、排便频次/性状（Bristol分型）、饮食触发因素、情绪状态、睡眠时长，为精准调整方案提供数据支持；推荐使用PainSmart随访系统数字化记录，实现医患数据同步。

## 七、随访与监测要点
腹痛频率
排便模式
生活质量
IBS腹痛的随访需从“症状控制”转向“功能恢复与带病生存质量提升”，建立结构化、周期性的监测体系：
1. **核心指标动态监测**：腹痛频率/强度（NRS/VAS）、排便模式（Bristol分型、急迫感、失禁、里急后重）、腹胀/排气情况、睡眠质量（PSQI简版）、自主神经症状（心悸、出汗、头晕）。
2. **疗效与安全性评估**：每4-8周复评症状改善率（如≥50%症状缓解为临床应答）、药物不良反应（便秘、口干、头晕、心悸、体重变化）、心理量表（PHQ-9/GAD-7）变化；评估是否达到“治疗目标”（症状可控、功能恢复、生活质量达标）。
3. **生活质量与功能恢复**：SF-36或IBS-QOL量表评估工作/社交/家庭功能恢复情况，关注“带病生存”质量而非单纯追求“无痛”；追踪医疗资源使用率（急诊就诊、住院、检查频次）。
4. **长期随访策略**：急性期后转为维持期随访（每3-6个月），根据症状波动灵活调整药物剂量与饮食方案；建立电子健康档案，追踪复发诱因（感染、压力、饮食不当、季节变化）；对难治性病例启动MDT联合随访。
5. **多学科协作随访**：疼痛科、消化科、临床心理科、营养科联合随访，确保脑-肠轴综合管理落地；利用PainSmart系统设置自动化提醒与患者端数据上传，提升随访依从性与数据连续性。

## 八、预警与转诊指征
便血、体重下降需肠镜排查
IBS为排他性诊断，任何症状演变均需保持高度警惕，明确转诊红线与多学科协作指征：
1. **绝对报警症状（需立即转诊消化科/急诊）**：不明原因体重下降（>5%体重/3个月）、夜间痛醒、持续呕吐、进行性吞咽困难、便血/黑便、发热>38℃、腹部包块、直肠指检异常、贫血（Hb进行性下降）、黄疸。
2. **结构病变筛查指征**：年龄≥45-50岁（结直肠癌筛查年龄）、结直肠癌/炎症性肠病家族史、感染后症状持续不缓解（>4周）、常规治疗3个月无效或进行性加重、粪便钙卫蛋白显著升高。
3. **心理共病转诊指征**：HADS/GAD-7/PHQ-9提示中重度焦虑抑郁、自杀意念、创伤后应激障碍（PTSD）、严重睡眠障碍影响日常功能、躯体症状障碍伴显著功能损害。
4. **介入/难治性疼痛转诊**：标准药物治疗与饮食心理干预无效，需评估腹腔神经丛阻滞、脊髓电刺激（SCS）、经皮迷走神经刺激（tVNS）或临床试验入组。
5. **特殊人群管理**：妊娠期IBS症状加重需产科/消化科联合管理（避免致畸药物）；老年患者需警惕药物相互作用、隐匿性器质病变与多重用药风险；儿童/青少年IBS需儿科/心理科协同，关注生长发育与校园适应。

## 九、患者教育与自我管理
识别报警症状（血便、黄疸、发热、腹胀拒按、体重下降）；遵医嘱调整饮食与作息。
不自行长期用止泻或止痛药物掩盖病情，症状变化及时复诊。
患者教育是慢性疼痛管理的核心环节，旨在赋能患者掌握疾病规律、提升自我效能、减少医疗依赖：
1. **疾病认知重塑**：向患者明确IBS是“脑-肠互动功能紊乱”，非器质性破坏，不癌变、不缩短寿命，但需长期管理。消除“绝症”恐惧与病耻感，建立合理预期（目标为症状可控、功能恢复，而非绝对无痛）。
2. **报警症状识别清单**：提供图文版“红色警报”卡片（血便、黑便、消瘦、夜间痛、发热、包块、进行性加重），明确告知出现任一症状立即就医，不可自行观察或盲目服药。
3. **饮食自我管理**：掌握低FODMAP饮食原则，使用食物-症状日记识别个人触发食物；循序渐进增加可溶性纤维；保证充足饮水（1.5-2L/d）；避免暴饮暴食与极端节食；外出就餐时提前了解菜单成分。
4. **药物使用规范**：严格遵医嘱用药，不自行增减/停用TCA/SNRI或解痉药；了解常见副作用及应对（如口干多饮水、便秘增加水分与活动、头晕防跌倒）；明确阿片类/强效止泻药禁用原则，避免药物过量性疼痛与依赖。
5. **压力与情绪调节**：教授腹式呼吸、渐进性肌肉放松、正念冥想技巧；鼓励参与支持性团体或线上患者社群，分享管理经验，减少孤立感；识别压力触发点，建立个人“减压工具箱”。
6. **随访依从性管理**：强调定期复诊的重要性，即使症状缓解也需维持治疗防复发；教会使用PainSmart随访APP/小程序记录症状、用药、饮食、情绪，实现医患数据同步，提升管理效率与精准度。
7. **生活方式整合**：规律作息、适度运动、戒烟限酒、维持健康体重；将疼痛管理融入日常生活，而非被动等待发作；建立“疼痛-活动-休息”平衡节律，避免过度卧床导致功能退化。通过系统化教育，使患者从“被动接受治疗”转变为“主动参与管理”，最终实现长期症状稳定与生活质量提升。

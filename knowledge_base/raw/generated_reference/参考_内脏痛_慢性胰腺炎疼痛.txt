# 慢性胰腺炎疼痛

慢性胰腺炎疼痛

类别：内脏痛

## 一、概述
慢性胰腺炎（Chronic Pancreatitis, CP）疼痛是疾病最突出且致残性最强的临床表现，约见于70%~90%的患者。其疼痛多位于中上腹部，常向腰背部呈带状放射，具有明显的餐后加重特征，严重干扰患者营养摄入与生活质量。疼痛机制复杂，涉及外周神经炎症、神经病理性改变、中枢敏化及心理社会因素的多重交互。作为典型的内脏痛综合征，其管理需遵循多学科协作（MDT）原则，强调病因治疗、阶梯镇痛与长期随访的有机结合，旨在控制疼痛、延缓胰腺功能衰竭并改善整体生存质量。

## 二、病理生理机制
慢性胰腺炎疼痛的发生机制呈多因素、动态演变特征，主要涵盖以下核心环节：
1. **胰管高压与实质炎症**：胰管结石、狭窄或蛋白栓子导致胰液排出受阻，引起胰管内压持续升高，牵张胰腺包膜及周围神经末梢。同时，反复的急性发作导致胰腺实质纤维化、钙化及周围组织慢性炎症浸润，释放大量炎性介质（如TNF-α、IL-1β、P物质、CGRP），直接刺激伤害性感受器并维持痛觉传导。
2. **神经病理性改变与神经周围炎**：炎症细胞浸润胰腺周围神经丛（尤其是腹腔神经丛），导致神经纤维脱髓鞘、轴突变性甚至神经瘤形成。神经生长因子（NGF）表达上调，促使痛觉传导通路发生结构性重塑，形成外周与中枢神经病理性疼痛。
3. **中枢敏化与脑-肠轴失调**：长期外周伤害性刺激传入脊髓背角，引发NMDA受体激活、谷氨酸释放增加及下行抑制通路功能减退，导致中枢神经系统痛阈降低。内脏高敏感状态使正常生理性胰管扩张或肠蠕动即可诱发剧烈疼痛。同时，慢性疼痛伴随的焦虑、抑郁及睡眠障碍通过脑-肠轴负反馈进一步放大痛觉信号。
4. **牵涉痛与自主神经反应**：胰腺属胚胎期前肠衍生物，其痛觉传入纤维经T5-T12交感神经节及迷走神经传入中枢，故疼痛常放射至背部（T7-T9皮节）。内脏病变可表现为体表远隔部位痛（牵涉痛），并伴随交感神经兴奋症状（如出汗、心悸）及副交感神经紊乱（如恶心、呕吐、肠蠕动异常）。
临床警示：须严格鉴别继发性急腹症（如胰腺假性囊肿破裂、消化道穿孔、肠系膜缺血、胆道梗阻），疼痛性质的突变、部位偏移或伴随全身中毒症状是鉴别的关键。

## 三、临床评估与筛查
慢性胰腺炎疼痛的评估需采用“生物-心理-社会”医学模式，实施多维度、动态化监测：
1. **病史采集与疼痛特征分析**：重点询问饮酒史、胆石症史、吸烟史、家族史及用药史。详细记录疼痛的起病形式、部位、性质（胀痛、绞痛、烧灼痛或刀割样）、放射范围、诱发/缓解因素（典型为餐后加重，弯腰抱膝位可稍缓解）、发作频率及持续时间。
2. **标准化疼痛评估工具**：常规使用数字评分法（NRS）或视觉模拟评分法（VAS）量化疼痛强度；推荐采用胰腺疾病生活质量量表（PDQL）或慢性疼痛问卷（CPQ）评估疼痛对睡眠、情绪及日常功能的影响。
3. **体格检查与腹部查体**：注意上腹部压痛部位与程度，有无肌紧张、反跳痛及包块。评估营养状况（BMI、肌肉量）、有无黄疸、腹水及腹部手术瘢痕。警惕腹膜刺激征，以排除急腹症。
4. **辅助检查与病因筛查**：
   - **实验室检查**：血清淀粉酶/脂肪酶（慢性期常正常或轻度升高）、肝功能、空腹血糖及糖化血红蛋白（评估胰岛功能）、粪便弹性蛋白酶-1（评估外分泌功能）、肿瘤标志物（CA19-9、CEA）。
   - **影像学评估**：腹部超声初筛；CT（平扫+增强）评估胰腺钙化、萎缩、胰管扩张及假性囊肿；MRCP无创显示胰胆管树结构；超声内镜（EUS）对早期慢性胰腺炎（Rosemont标准）及微小病变具有极高敏感性，并可引导细针穿刺（FNA）排除恶性肿瘤。
5. **心理与功能共病评估**：常规筛查焦虑抑郁状态（HADS量表）、睡眠障碍及物质滥用史。明确是否存在肠易激综合征（IBS）重叠或功能性消化不良，避免仅依赖结构影像学阴性而忽视症状管理。

## 四、专家诊疗思路（按类别）
慢性胰腺炎疼痛的临床诊疗难点在于其定位模糊、情绪色彩浓厚，且极易与消化道急症或恶性肿瘤混淆。我的核心诊疗逻辑遵循“排除危急-明确病因-阶梯干预-全程管理”路径：
1. **首要原则：排除器质性与急症病因**。接诊时务必警惕“报警征象”：进行性加重的体重下降、新发黄疸、可触及的腹部包块、持续发热、血便或黑便、腹胀拒按。出现上述任一表现，必须立即完善增强CT/MRCP、EUS及肿瘤标志物检测，果断排除恶性胰腺肿瘤、胆道梗阻、消化道穿孔或肠系膜缺血。该内镜、该影像绝不拖延。
2. **病因导向与阶梯镇痛**：
   - **炎症与胰管高压型**：以解除梗阻、降低胰压为核心。轻中度疼痛首选NSAIDs或对乙酰氨基酚；中重度疼痛严格遵循WHO三阶梯原则，但**慎用阿片类药物**（因可能引起Oddi括约肌痉挛加重疼痛，且依赖风险高）。若必须使用，推荐弱阿片或低剂量强阿片联合非阿片类药物。
   - **神经病理性成分突出者**：疼痛呈烧灼样、电击样或伴有痛觉超敏，应早期联用神经病理镇痛药，如加巴喷丁、普瑞巴林，或SNRIs（度洛西汀）、TCAs（阿米替林）。此类药物不仅镇痛，更能改善伴随的睡眠障碍与情绪低落。
   - **功能性内脏痛重叠（如IBS-FD）**：本质为脑-肠轴失调与内脏高敏感。单纯“止痛”往往无效甚至加重胃肠动力紊乱。需联合解痉药（匹维溴铵、奥替溴铵）、调节肠道菌群（益生菌/益生元）、低FODMAP饮食干预，并引入认知行为疗法（CBT）或正念减压训练。
3. **心理共病整合管理**：慢性胰腺炎患者焦虑抑郁发生率高达30%~50%。心理评估与干预不是“附加项”，而是疼痛管理的核心环节。必要时请精神心理科会诊，合理使用抗焦虑抑郁药物，打破“疼痛-焦虑-痛觉放大”的恶性循环。
4. **癌性疼痛鉴别**：若疼痛性质由间歇性转为持续性剧痛，伴明显消瘦、厌食，需高度警惕胰腺癌变。此时治疗目标转为姑息镇痛与生活质量维护，可早期介入姑息性神经阻滞或姑息性放疗。

## 五、处理原则（药物与干预）
慢性胰腺炎疼痛的处理需采取个体化、多学科联合的阶梯策略，涵盖药物、内镜、介入及外科手段：
1. **基础治疗与病因干预**：
   - **胰酶替代治疗（PERT）**：足量胰酶（如得每通）不仅改善脂肪泻与营养不良，其反馈抑制机制可降低胰液分泌，间接减轻胰管高压与疼痛。建议随餐分次服用。
   - **严格戒酒与戒烟**：酒精与烟草是疾病进展的独立危险因素。戒酒是阻断疼痛恶化的基石，需结合成瘾医学手段（如纳曲酮、心理支持）提高依从性。
   - **饮食管理**：推荐低脂、高蛋白、高碳水化合物饮食，少量多餐。避免暴饮暴食及高脂、辛辣食物刺激胰液大量分泌。
2. **药物治疗方案**：
   - **一线/二线镇痛**：对乙酰氨基酚、NSAIDs（注意胃肠道与肾脏保护）。
   - **神经病理调节剂**：普瑞巴林（起始75mg bid，滴定至有效剂量）、加巴喷丁、度洛西汀、去甲替林。需缓慢滴定以减轻头晕、嗜睡等副作用。
   - **阿片类药物**：仅作为最后防线。若使用，优选曲马多或羟考酮缓释片，避免使用吗啡（Oddi括约肌收缩风险高）。严格制定减量计划，防范耐受与成瘾。
3. **介入与内镜治疗**：
   - **腹腔神经丛阻滞/毁损（CPN/CPNB）**：经皮、EUS或腹腔镜下注射酒精/苯酚，破坏交感痛觉传导通路。对药物难治性疼痛有效率约60%~80%，可显著减少阿片用量，但需注意一过性低血压、腹泻等副作用。
   - **内镜下治疗**：针对胰管狭窄/结石，可行ERCP下乳头括约肌切开、胰管支架置入、体外震波碎石（ESWL）或内镜下胰管取石，直接解除梗阻、降低胰压。
4. **外科手术治疗**：适用于胰管显著扩张（>7mm）、巨大假性囊肿、可疑恶变或上述治疗失败者。术式包括引流术（Frey、Beger、Partington-Rochelle术）与切除术（胰十二指肠切除、远端胰腺切除）。手术可显著缓解疼痛，但需权衡术后外分泌/内分泌功能进一步减退的风险。

## 六、非药物与康复
非药物干预在慢性胰腺炎疼痛管理中占据不可替代的地位，旨在调节神经可塑性、改善功能状态并提升自我效能：
1. **营养与肠道康复**：在营养师指导下实施个体化低脂饮食方案。补充中链甘油三酯（MCT）作为脂肪来源，因其无需胰脂酶即可直接吸收。针对脂肪泻与脂溶性维生素（A、D、E、K）缺乏，给予针对性补充，纠正营养不良性疼痛易感性。
2. **物理治疗与盆底/内脏康复**：内脏推拿、筋膜松解及膈肌呼吸训练可改善腹腔脏器血流、降低交感张力。盆底生物反馈治疗对合并排便障碍或内脏高敏感的患者有效。经皮神经电刺激（TENS）可作为辅助镇痛手段。
3. **心理行为干预**：认知行为疗法（CBT）帮助患者重构对疼痛的灾难化认知；正念减压（MBSR）与渐进性肌肉放松训练（PMR）降低中枢敏化水平。生物反馈治疗可增强患者对自主神经系统的调控能力。
4. **脑-肠轴调节与生活方式重塑**：建立规律的进食与排便节律，避免久坐。睡眠卫生教育至关重要，因睡眠剥夺会显著降低痛阈。鼓励适度有氧运动（如散步、瑜伽），促进内源性阿片肽释放。
5. **新兴非药物技术**：重复经颅磁刺激（rTMS）靶向刺激初级运动皮层，对难治性内脏痛显示初步疗效；经皮迷走神经刺激（tVNS）通过调节迷走神经张力发挥抗炎与镇痛作用，正处于临床研究阶段。

## 七、随访与监测要点
慢性胰腺炎为进行性、不可逆疾病，需建立长期、结构化的随访监测体系（建议每3~6个月一次，急性加重期缩短至1~2个月）：
1. **疼痛与功能监测**：动态记录NRS评分、镇痛药物种类与剂量、疼痛对睡眠与日常活动的影响。评估是否存在阿片类药物滥用或药物过量性头痛/疼痛。
2. **营养与代谢指标**：定期监测BMI、血清白蛋白、前白蛋白、维生素D水平及骨密度（预防继发性骨质疏松）。评估粪便脂肪含量与体重变化，及时调整PERT剂量。
3. **内分泌与外分泌功能**：每6~12个月检测空腹血糖、糖化血红蛋白及C肽，早期发现胰腺相关性糖尿病（3c型糖尿病）并规范降糖治疗（首选胰岛素，避免磺脲类）。监测粪便弹性蛋白酶-1评估外分泌功能。
4. **并发症筛查**：年度腹部超声或CT/MRCP监测假性囊肿、胰管结石、胆道/门静脉受压情况。定期评估CA19-9等肿瘤标志物，警惕胰腺癌变（慢性胰腺炎患者癌变风险较常人高5~10倍）。
5. **心理与社会功能**：使用HADS或PHQ-9/GAD-7量表筛查抑郁焦虑，评估工作/家庭角色恢复情况。必要时启动多学科心理支持或康复转介。

## 八、预警与转诊指征
出现以下任一情况，提示病情进展或出现严重并发症，需立即启动预警机制并转诊至消化内科、肝胆胰外科或疼痛科/肿瘤科：
1. **急症与并发症预警**：疼痛性质突然改变（如由钝痛转为持续性剧痛或刀割样痛）、疼痛范围扩大或向全腹扩散；伴随高热、寒战、黄疸加深、呕血/黑便、血性腹水；腹部出现进行性膨隆、肌紧张及反跳痛（提示假性囊肿破裂、出血、感染或消化道穿孔）。
2. **恶性肿瘤可疑指征**：不明原因的进行性体重下降（>5%/6个月）、新发或难以控制的糖尿病、可触及的固定质硬包块、CA19-9进行性升高、影像学提示胰管不规则狭窄或占位性病变。
3. **治疗抵抗与功能衰竭**：规范药物及介入治疗后疼痛仍持续NRS≥7分，严重影响进食与睡眠；出现重度营养不良（BMI<18.5）、顽固性脂肪泻或胰岛素依赖型糖尿病；阿片类药物出现严重不良反应或依赖。
4. **转诊路径**：疑似急腹症/出血/穿孔→急诊外科；疑似癌变→肝胆胰外科/肿瘤科MDT；难治性疼痛/介入需求→疼痛科/消化内镜中心；营养/代谢紊乱→临床营养科/内分泌科。

## 九、患者教育与自我管理
赋能患者进行科学的自我管理是控制慢性胰腺炎疼痛、延缓疾病进展的核心环节。教育内容应具体、可操作，并定期强化：
1. **疾病认知与报警症状识别**：向患者及家属通俗讲解慢性胰腺炎的病理特点，明确告知“报警症状”清单：突发剧烈腹痛伴发热呕吐、皮肤巩膜黄染、黑便/血便、短期内体重骤降、腹部包块。出现任一症状立即就医，切勿自行观察拖延。
2. **用药依从性与安全性教育**：
   - **胰酶**：强调“随餐服用”原则，餐中或餐后立即服用效果最佳，不可空腹服用。剂量需根据进食脂肪量个体化调整。
   - **镇痛药**：严格遵医嘱按阶梯用药，不自行增减剂量或突然停药。告知NSAIDs的胃肠道风险（建议餐后服，必要时联用PPI），以及加巴喷丁/普瑞巴林的起始低剂量滴定法。严禁自行购买强效止痛药或酒精类酊剂。
   - **阿片警示**：若使用阿片类药物，需告知便秘、嗜睡、呼吸抑制风险，预防性使用通便药物，严禁饮酒或合用镇静安眠药。
3. **饮食与生活方式管理**：制定个性化低脂食谱（脂肪摄入<30g/日），采用蒸、煮、炖等烹饪方式。绝对戒酒，彻底戒烟（尼古丁加速胰腺纤维化）。保持规律作息，避免熬夜与过度劳累。记录“饮食-疼痛日记”，识别并规避个人诱发食物（如高脂、辛辣、产气食物）。
4. **心理调适与应急计划**：教授腹式呼吸、渐进式肌肉放松等即时减压技巧。建立“疼痛应急预案”：轻度疼痛时休息+热敷+非处方药；中重度疼痛或伴随报警症状时立即联系主治医生或前往急诊。鼓励加入病友支持团体，减少病耻感与社会隔离。
5. **长期随访承诺**：强调慢性胰腺炎需“带病长期生存”，定期复查（血糖、营养、影像）比单纯止痛更重要。与医疗团队建立信任伙伴关系，共同制定动态治疗目标，提升生活质量。

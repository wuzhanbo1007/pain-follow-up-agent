# 药物过度使用性头痛(MOH)

文档标题：药物过度使用性头痛(MOH)

类别：头痛

## 一、概述
药物过度使用性头痛（Medication Overuse Headache, MOH）是指原发性头痛患者长期、规律性地过量使用急性对症治疗药物，导致头痛频率增加、性质改变，最终转化为每日或近乎每日发作的继发性头痛。根据国际头痛疾病分类第三版（ICHD-3）标准，MOH的诊断核心在于头痛发作与急性药物过度使用之间存在明确的时间因果关系。该病在慢性偏头痛及慢性紧张型头痛人群中患病率高达40%~60%，是头痛门诊最常见的可逆性病因之一。MOH不仅显著降低患者生活质量与工作效能，还会导致预防性治疗药物疗效下降、急性药物耐受性增加，形成“头痛加重→频繁用药→药物反跳→头痛持续”的恶性循环。早期识别、规范戒断与系统化管理是阻断疾病进展、恢复原发性头痛基线频率的关键。

## 二、病理生理机制
头痛按病因分为原发与继发两大类。原发性头痛（偏头痛、紧张型头痛、丛集性头痛）的发病机制涉及三叉神经血管系统激活、降钙素基因相关肽（CGRP）等神经肽释放、皮质扩散性抑制（CSD）、脑干及丘脑痛觉调制中枢功能异常、头颈部肌筋膜持续收缩及多基因遗传易感性。偏头痛以神经血管源性炎症与皮层兴奋性增高为特征；紧张型头痛主要与中枢痛觉下行抑制通路功能减退及肌筋膜触发点有关；丛集性头痛则与下丘脑生物钟节律紊乱及三叉神经-副交感神经反射亢进密切相关。

MOH的病理生理机制具有高度特异性，核心在于反复过量摄入急性镇痛药引发的中枢敏化与受体适应性改变。主要机制包括：
1. **受体下调与脱敏**：长期使用曲普坦类、阿片类或复方镇痛药可导致5-HT1B/1D、μ-阿片受体及COX酶活性下调，使急性期药物镇痛阈值升高，产生耐受性。
2. **中枢痛觉调制通路失衡**：过度使用药物抑制脑干中缝大核、蓝斑核等下行抑制性神经递质（如5-HT、NE、内源性阿片肽）的释放，同时增强脊髓背角及三叉神经颈复合体的NMDA受体介导的长时程增强（LTP）效应，导致中枢敏化。
3. **神经源性炎症与血脑屏障通透性改变**：频繁药物暴露可促进P物质、CGRP及前列腺素释放，引起硬脑膜及颅外血管无菌性炎症，并破坏血脑屏障完整性，使外周致痛物质更易进入中枢。
4. **戒断反跳机制**：当血药浓度下降时，受体代偿性上调与痛觉阈值骤降共同引发“反跳性头痛”，表现为头痛频率增加、强度加剧、对常规剂量药物反应迟钝。
不同药物类别的过度使用阈值存在差异：曲普坦类/麦角胺类≥10天/月，NSAIDs/复方镇痛剂/阿片类≥15天/月，连续使用超过3个月即符合MOH诊断标准。

## 三、临床评估与筛查
系统化的临床评估是MOH诊断与分型的基础。首诊必须详细采集头痛特征与用药史，推荐使用标准化头痛日记记录至少4周，内容涵盖：发作日期与持续时间、疼痛部位与性质（搏动性/压迫性/刺痛）、疼痛强度（NRS/VAS评分）、伴随症状（恶心、畏光、畏声、自主神经症状）、明确诱因（睡眠、饮食、压力、激素波动）及急性药物名称、剂量、频次与给药途径。

筛查过程中需严格排查继发性头痛警示征象（SNOOP4原则）：Systemic症状（发热、体重下降、感染征象）；Neurologic定位体征（偏瘫、失语、视野缺损、共济失调）；Onset突发模式（雷击样头痛，1分钟内达峰值）；Other提示性疾病或Pattern显著改变（妊娠/产褥期、HIV感染、恶性肿瘤史、50岁后新发头痛、咳嗽/Valsalva动作诱发）。出现上述任一征象需紧急行头颅CT/MRI、MRV/MRA或腰穿检查，排除蛛网膜下腔出血、脑静脉窦血栓、颅内占位、可逆性脑血管收缩综合征（RCVS）及感染性/炎症性病变。

功能评估方面，推荐使用HIT-6（头痛影响问卷-6项）或MIDAS（偏头痛残疾量表）量化头痛对日常生活、工作及社交的失能程度。当HIT-6评分≥16分或MIDAS III级及以上时，提示需启动预防性治疗。MOH专项筛查需重点确认：每月急性药物使用天数是否超标、头痛是否呈每日/近乎每日发作、停药后头痛是否短暂缓解后反跳。结合ICHD-3诊断标准，满足“原发性头痛病史+急性药物过度使用+头痛频率增加+排除其他病因”即可确诊。

## 四、专家诊疗思路（按类别）
头痛患者常因长期反复发作而承受巨大身心负担，临床沟通中需充分共情，避免将慢性头痛简单归因为“心理作用”或“矫情”。原发性头痛的诊疗核心在于精准分型与阶梯管理，而MOH的识别是打破治疗僵局的前提。

**偏头痛管理**遵循“急性期尽早干预+预防期规范用药”双轨策略。急性期首选NSAIDs、曲普坦类或新型CGRP受体拮抗剂（Gepants），强调在疼痛轻度至中度时足量服用，避免空腹及强光噪音环境刺激。当每月发作≥4次、急性药物使用接近阈值或伴随显著失能时，必须启动预防治疗。一线预防药物包括β受体阻滞剂（普萘洛尔、美托洛尔）、抗癫痫药（托吡酯、丙戊酸）、钙通道阻滞剂（氟桂利嗪）及新型CGRP单克隆抗体（依瑞奈尤单抗、伽奈珠单抗等）。预防用药需足量足疗程（至少8~12周）评估疗效，并配合头痛日记动态调整。

**紧张型头痛**以肌筋膜紧张与中枢敏化为主，急性期以NSAIDs或对乙酰氨基酚为主，慢性型首选阿米替林或SNRI类（文拉法辛），联合物理治疗与认知行为干预。

**丛集性头痛**具有高度周期性与自主神经特征，急性期首选100%高流量纯氧吸入（12~15 L/min，15分钟）及皮下注射舒马曲普坦；预防期维拉帕米为金标准，难治性病例可短期使用皮质类固醇桥接或CGRP单抗。

MOH的诊疗需打破“头痛→吃药→更痛”的循环。临床实践中，我会明确要求患者建立结构化头痛日记，严格限制急性药物使用天数，同步启动预防性治疗作为“桥接”，并指导规律作息与压力管理。戒断期头痛加重属正常药理反跳，需提前告知患者以增强依从性。多学科协作（疼痛科、神经内科、心理科、康复科）是提升长期缓解率的核心。

## 五、处理原则（药物与干预）
MOH的治疗核心在于“停用过度使用药物+启动预防桥接+行为干预+长期随访”。戒断策略需根据药物种类、依赖程度及患者合并症个体化制定，主要分为突然停用与逐渐减量两类。阿片类及复方镇痛剂建议逐渐减量以降低戒断综合征风险；曲普坦类、NSAIDs及Gepants通常可安全突然停用。

戒断期（通常持续2~8周）头痛频率与强度可能显著加重，伴随恶心、呕吐、失眠、焦虑等自主神经与精神症状。此时必须实施预防性桥接治疗，以减轻反跳痛并维持功能。桥接药物选择需结合原发头痛类型：偏头痛倾向者首选托吡酯、丙戊酸或CGRP单抗；紧张型倾向者选用阿米替林或度洛西汀；难治性病例可短期（3~5天）使用地塞米松或泼尼松逐渐减量。神经阻滞（枕大神经、三叉神经分支、蝶腭神经节阻滞）及静脉输注（镁剂、维生素B族、NSAIDs）对缓解戒断期剧痛具有确切疗效。

### 通用处理框架与用药要点（按类别）
- **偏头痛**：急性期NSAIDs/曲普坦/Gepants；预防期β阻滞剂、抗癫痫药、CGRP单抗、肉毒毒素A（慢性偏头痛）。戒断期桥接首选托吡酯或CGRP单抗，联合枕神经阻滞。
- **紧张型头痛**：急性期对乙酰氨基酚/NSAIDs；慢性期阿米替林（10~75 mg/d滴定）、SNRI。戒断期桥接以低剂量三环类或度洛西汀为主，配合肌筋膜松解。
- **丛集性头痛**：急性期高流量吸氧/舒马曲普坦；预防期维拉帕米（逐步滴定至最大耐受剂量）、锂剂、CGRP单抗。戒断期桥接可短期使用皮质类固醇或枕神经/蝶腭神经节阻滞。
- **干预技术**：经皮神经电刺激（TENS）、迷走神经刺激（nVNS）、经颅磁刺激（rTMS）、针灸及肉毒毒素A注射可作为药物桥接或维持期的有效补充。难治性MOH可考虑脊髓电刺激（SCS）或脑深部电刺激（DBS）等神经调控手段。

## 六、非药物与康复
非药物干预是MOH长期管理的基石，旨在调节中枢敏化、改善痛觉阈值并重建健康行为模式。
1. **睡眠与昼夜节律管理**：保持固定作息时间，避免熬夜与周末补觉；失眠者推荐CBT-I（失眠认知行为治疗），必要时短期使用非依赖性助眠药物。
2. **压力与情绪干预**：慢性头痛常共病焦虑抑郁。推荐正念减压疗法（MBSR）、渐进性肌肉放松训练（PMR）、生物反馈治疗（EMG/皮温/HRV），可显著降低交感神经张力与头痛频率。
3. **运动康复**：中等强度有氧运动（快走、游泳、骑行，每周3~5次，每次30分钟）可促进内啡肽释放并改善脑血流调节。慢性紧张型头痛患者需结合颈椎稳定性训练、胸椎灵活性练习及触发点按压疗法。
4. **物理与替代疗法**：针灸（尤其针对风池、合谷、太阳穴）对偏头痛预防具有循证支持；经皮三叉神经/迷走神经刺激仪（如Cefaly、gammaCore）可作为居家预防工具。
5. **饮食与诱因规避**：识别并记录个体触发因素（如酒精、咖啡因骤停、味精、腌制食品、强光、气味）。保持充足水分摄入，避免长时间空腹。偏头痛患者可尝试补充镁剂（400~600 mg/d）、核黄素（B2，400 mg/d）及辅酶Q10。

## 七、随访与监测要点
MOH的随访需结构化、周期化，重点监测以下维度：
1. **急性药物使用天数**：每次随访严格核对近30天急性药使用频次，目标为降至安全阈值以下（曲普坦/麦角胺≤9天/月，NSAIDs/复方/阿片≤14天/月）。
2. **头痛模式演变**：记录头痛频率（天/月）、持续时间、NRS强度、伴随症状变化。戒断期后4~8周通常可见头痛频率下降50%以上，标志戒断成功。
3. **功能与残疾评估**：动态使用HIT-6、MIDAS、SF-36生活质量量表评估治疗反应。评分改善提示桥接方案有效。
4. **精神心理状态**：常规筛查PHQ-9（抑郁）与GAD-7（焦虑），MOH患者共病率高达30%~40%，需及时转介心理干预。
5. **药物依从性与不良反应**：监测预防药物耐受性（如托吡酯认知迟缓、丙戊酸肝功/体重、β阻滞剂心率血压）、桥接药物胃肠道反应及戒断期症状控制情况。
6. **复发预警**：随访间隔建议为戒断后1、3、6、12个月，之后每6~12个月一次。若急性药使用天数连续2个月回升，需重新评估诱因、调整预防方案或强化行为干预。

## 八、预警与转诊指征
MOH患者虽多可在门诊完成戒断，但出现以下情况需立即升级管理或转诊：
1. **严重戒断综合征**：持续剧烈呕吐致脱水/电解质紊乱、难以控制的焦虑/抑郁伴自杀意念、严重失眠或心血管不稳定（高血压危象、心动过速）。此类患者需住院静脉补液、静脉NSAIDs/皮质类固醇桥接及精神科会诊。
2. **警示征象重现或新发**：头痛模式发生质变（如突发雷击样、局灶神经缺损、发热颈强直、视乳头水肿、妊娠相关剧变），必须紧急行神经影像学及腰穿排除继发性危重疾病。
3. **门诊治疗失败**：规范戒断+桥接治疗8周后头痛频率无改善，或预防药物无法耐受，需转诊至高级别头痛中心/疼痛科，评估神经调控（SCS/DBS）、肉毒毒素A强化注射或新型靶向生物制剂。
4. **复杂共病**：合并未控制的高血压、冠心病、肝肾功能不全、妊娠/哺乳期、药物滥用史或严重精神障碍，需多学科联合管理。
5. **药物依赖与滥用**：阿片类或苯二氮䓬类依赖者需联合成瘾医学科进行规范化替代治疗与心理社会支持。

## 九、患者教育与自我管理
MOH的长期缓解高度依赖患者的疾病认知与自我管理能力。临床教育需结构化、可操作：
1. **疾病机制科普**：用通俗语言解释“反跳性头痛”原理，明确MOH是可逆的继发性头痛，打破“止痛药是万能药”的认知误区。
2. **用药安全红线**：严格限定急性药物使用频率（曲普坦/麦角胺≤2天/周，NSAIDs/复方/阿片≤3天/周）。强调“预防药需每日规律服用，急性药仅用于突破发作”，杜绝按需叠加或超量使用。
3. **触发因素管理**：指导使用标准化头痛日记识别个体诱因（睡眠、饮食、压力、激素、环境）。建立“头痛应急预案”：发作初期尽早服药+安静暗室休息+冷敷/热敷+非药物放松，避免带痛硬扛或频繁换药。
4. **生活方式重塑**：固定作息与进餐时间，避免咖啡因骤停或过量；每周保持150分钟中等强度有氧运动；学习腹式呼吸、渐进性肌肉放松等自主神经调节技术。
5. **心理支持与复发预防**：告知戒断期头痛加重属正常药理过程，通常2~4周达峰后缓解，增强治疗信心。建立“复发预警清单”（如连续3天头痛、急性药使用达阈值、睡眠紊乱），出现即联系医生调整方案。
6. **随访依从性**：强调定期复诊的重要性，携带完整头痛日记与用药清单。鼓励加入患者支持小组，分享管理经验，降低病耻感与焦虑。通过医患共同决策（SDM）制定个体化维持计划，实现从“被动止痛”向“主动管理”的转变。

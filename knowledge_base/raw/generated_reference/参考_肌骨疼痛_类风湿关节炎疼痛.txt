# 类风湿关节炎疼痛

类别：肌骨疼痛

## 一、概述
类风湿关节炎（Rheumatoid Arthritis, RA）是一种以侵蚀性、对称性多关节炎为主要临床表现的慢性、全身性自身免疫性疾病。其核心病理特征为滑膜慢性炎症、血管翳形成及进行性软骨与骨破坏。疼痛是RA最突出且最早出现的症状之一，早期多表现为炎性疼痛（静息痛、夜间痛、晨僵），随疾病进展可合并机械性疼痛（关节结构破坏、畸形导致）及神经病理性疼痛（周围神经受压或中枢敏化）。RA不仅局限于关节，常伴发全身多系统损害（如肺间质病变、心血管受累、干燥综合征等），显著影响患者生活质量与预期寿命。早期识别、规范干预与长期随访是阻断病情进展、缓解疼痛、保留关节功能的关键。

## 二、病理生理机制
RA的疼痛机制复杂，涉及外周与中枢多重通路交互作用，远超单纯的结构损伤。
1. **外周炎症与伤害性疼痛**：自身抗原激活T/B淋巴细胞，导致滑膜巨噬细胞与滑膜成纤维细胞活化，大量释放促炎细胞因子（TNF-α、IL-1β、IL-6、IL-17等）。这些介质直接刺激伤害性感受器（如TRPV1、ASICs），并促进前列腺素（PGE2）、缓激肽、神经生长因子（NGF）等致痛物质合成，降低痛阈，引发局部红肿热痛。
2. **结构破坏与机械性疼痛**：慢性滑膜炎形成血管翳，分泌基质金属蛋白酶（MMPs）与破骨细胞活化因子，侵蚀软骨下骨与关节软骨。关节间隙狭窄、骨赘形成、肌腱韧带松弛或断裂导致生物力学异常，产生负重痛与活动痛。
3. **神经病理性与中枢敏化**：长期外周炎症输入导致脊髓背角神经元兴奋性增高，NMDA受体激活，C纤维传入增强，引发中枢敏化。患者表现为痛觉超敏（Allodynia）、痛觉过敏（Hyperalgesia）及疼痛范围扩散。同时，RA常合并纤维肌痛综合征或抑郁/焦虑状态，进一步放大疼痛感知，形成“疼痛-睡眠障碍-情绪低落-功能衰退”的恶性循环。
4. **疼痛-失能循环**：因惧怕疼痛（运动恐惧症，Kinesiophobia）而长期制动，导致肌肉萎缩、关节挛缩、本体感觉下降，进一步加重关节不稳与疼痛，加速残疾进程。慢性化后疼痛性质往往从纯炎性向混合性（炎性+机械性+神经性）演变，治疗需多维度干预。

## 三、临床评估与筛查
全面评估是制定个体化镇痛与抗风湿策略的基础，需结合主观症状与客观指标。
1. **病史采集**：重点询问疼痛部位、性质（炎性/机械性/神经性）、昼夜节律（晨僵持续时间>1小时具高度提示意义）、诱发缓解因素、既往用药反应及全身症状（发热、乏力、体重下降、口干眼干、雷诺现象）。
2. **体格检查**：系统评估28个关节压痛/肿胀关节数（Tender/Swollen Joint Count），检查关节活动度、稳定性、畸形（如尺偏、天鹅颈、纽扣花畸形）及肌力。注意排查周围神经卡压（如腕管综合征、尺神经炎），此类并发症在RA中发生率高达30%-40%。
3. **实验室检查**：炎症指标（ESR、CRP）评估疾病活动度；自身抗体（RF、抗CCP抗体）辅助诊断与预后判断（抗CCP高滴度提示骨侵蚀风险高）；血常规、肝肾功能、尿常规监测基础状态及药物毒性；必要时查ANA、ENA谱排除重叠综合征。
4. **影像学评估**：X线用于基线评估与随访骨侵蚀/关节间隙变化；超声（US）对滑膜炎、血流信号（Power Doppler）及微小积液高度敏感，适合床旁动态评估；MRI可早期发现骨髓水肿、滑膜炎及隐匿性侵蚀，适用于早期或疑难病例。
5. **疼痛与功能量表**：采用NRS/VAS评估疼痛强度；HAQ-DI、DAS28、CDAI、SDAI量化疾病活动度与功能损害；结合SF-36或EQ-5D评估生活质量。鉴别炎性关节痛与骨关节炎、痛风、感染性关节炎或纤维肌痛，避免误诊误治。

## 四、专家诊疗思路（按类别）
RA疼痛管理必须遵循“达标治疗（Treat-to-Target, T2T）”原则，以临床缓解或低疾病活动度为目标，而非单纯镇痛。
1. **早期强化干预**：确诊后尽早启动改善病情抗风湿药（csDMARDs），甲氨蝶呤（MTX）为锚定药物。疼痛剧烈或炎症指标极高者，可短期联用低剂量糖皮质激素（≤10mg/d泼尼松等效）作为“桥接治疗”，迅速控制滑膜炎，减轻疼痛。
2. **分层与升级策略**：若csDMARDs治疗3-6个月未达标，应尽早升级至生物制剂（bDMARDs）或靶向合成DMARDs（tsDMARDs，如JAK抑制剂）。TNF-α抑制剂、IL-6受体拮抗剂、CTLA4-Ig及JAKi能精准阻断炎症通路，显著缓解疼痛并抑制影像学进展。
3. **疼痛多维管理**：单纯依赖NSAIDs或阿片类药物无法改变疾病进程，且增加心血管、胃肠及成瘾风险。RA疼痛常伴中枢敏化，可酌情联合加巴喷丁、普瑞巴林或度洛西汀。对于难治性局部关节痛，可考虑超声引导下关节腔注射糖皮质激素或透明质酸。
4. **共病与风险管控**：RA患者心血管风险显著升高，使用NSAIDs需严格评估CV风险并优选选择性COX-2抑制剂；长期激素需防骨质疏松；JAKi需警惕血栓、感染及血脂异常。多学科协作（风湿免疫科、疼痛科、康复科、心理科）是优化预后的核心。避免“见痛止痛”的碎片化治疗，始终将控制免疫炎症置于首位。

## 五、处理原则（药物与干预）
控制原发病炎症是缓解RA疼痛的根本，镇痛药物仅作为辅助或过渡手段。
### 通用处理框架与用药要点（按类别）
1. **病因治疗（核心）**：csDMARDs（MTX、来氟米特、柳氮磺吡啶、羟氯喹）为一线基础。生物制剂（阿达木单抗、依那西普、托珠单抗等）与靶向药（托法替布、巴瑞替尼等）用于中重度或DMARDs反应不佳者。定期监测药物不良反应（骨髓抑制、肝毒性、感染、恶性肿瘤风险）。
2. **抗炎镇痛**：NSAIDs（塞来昔布、依托考昔、双氯芬酸等）可快速缓解肿痛，但需警惕胃肠道溃疡、肾功能损害及心血管事件。高危患者联用PPI护胃。糖皮质激素仅限短期、小剂量、局部或关节腔注射使用，避免长期全身应用导致医源性库欣综合征及感染。
3. **神经病理性疼痛干预**：对伴中枢敏化或周围神经卡压者，一线选用SNRI（度洛西汀）或钙通道α2-δ配体（普瑞巴林、加巴喷丁）。避免常规使用强阿片类药物，仅在极重度难治性疼痛且获益大于风险时谨慎短期使用。
4. **介入与外科治疗**：超声/透视引导下精准关节腔注射（糖皮质激素±局麻药）适用于单/寡关节急性发作。滑膜切除术适用于药物难治性局限性滑膜炎。终末期关节破坏伴严重功能障碍者，行关节置换术（如全膝/全髋置换）可显著改善疼痛与生活质量。
5. **用药安全原则**：遵循“能外用不口服，能单药不联用，能低剂量不高剂量”原则。用药前全面评估肝肾功能、感染筛查（TB、HBV/HCV）、疫苗接种状态。建立个体化用药档案与不良反应预警机制。

## 六、非药物与康复
非药物干预是RA综合管理的基石，贯穿疾病全程，对打破疼痛-失能循环至关重要。
1. **运动疗法**：急性期以关节活动度（ROM）练习为主，维持关节灵活性；缓解期强化有氧运动（游泳、快走、骑车，每周≥150分钟）与抗阻训练（重点强化关节周围肌群，如股四头肌、核心肌群），改善生物力学稳定性。水中运动可利用浮力减轻关节负荷，是极佳的选择。
2. **物理因子治疗**：热敷、蜡疗可缓解晨僵与肌肉痉挛；冷敷适用于急性红肿热痛期；经皮神经电刺激（TENS）对部分患者有辅助镇痛作用。避免过度依赖被动理疗，应以主动运动为核心。
3. **作业治疗与辅助器具**：指导关节保护技术（如使用大关节代偿小关节、避免重复性负重动作）；定制支具、矫形鞋垫、助行器或厨房/卫浴改造器具，降低日常活动能耗与关节应力。
4. **心理与行为干预**：认知行为治疗（CBT）正念减压（MBSR）可有效改善疼痛灾难化思维、焦虑抑郁及睡眠障碍，打破疼痛-情绪恶性循环。必要时联合精神心理科进行药物干预。
5. **营养与生活方式**：推荐地中海饮食（富含Omega-3脂肪酸、抗氧化物），控制体重以减轻下肢关节负荷；严格戒烟（吸烟显著增加RA发病风险及抗TNF治疗抵抗）；保证充足睡眠与维生素D/钙补充。

## 七、随访与监测要点
RA需终身随访，动态评估疾病活动度、治疗反应、药物安全性及并发症。
1. **随访频率**：初治或调整方案期每4-8周随访一次；病情稳定达标后每3-6个月随访。每次随访需系统评估。
2. **疾病活动度监测**：记录TJC/SJC数、患者疼痛VAS、医生整体评估、ESR/CRP，计算DAS28、CDAI或SDAI评分。目标为临床缓解（DAS28<2.6）或低疾病活动度（CDAI≤10）。
3. **实验室与影像学监测**：定期复查血常规、肝肾功能、尿常规；每6-12个月复查自身抗体滴度（非必需但可参考）；X线或超声每1-2年评估骨侵蚀进展。JAKi使用者需监测血脂、血常规及凝血功能。
4. **安全性与共病筛查**：每次随访询问感染征象、消化道症状、口腔溃疡、皮疹、下肢水肿或呼吸困难；定期筛查结核、乙肝/丙肝、恶性肿瘤；监测骨密度（DXA）防骨质疏松；评估心血管风险（血压、血糖、血脂）。
5. **功能与生活质量追踪**：使用HAQ-DI、SF-36量表评估功能状态与心理社会适应，及时调整康复与心理支持策略。建立电子随访档案，实现数据连续性与趋势分析。

## 八、预警与转诊指征
出现以下情况需立即干预或转诊至风湿免疫科、疼痛科或外科：
1. **感染与急症预警**：单关节骤发红、肿、热、剧痛伴高热，高度警惕化脓性关节炎或晶体性关节炎，需紧急关节穿刺抽液培养及经验性抗感染治疗。免疫抑制剂使用者出现持续发热、咳嗽、皮疹需警惕机会性感染。
2. **药物严重不良反应**：出现不明原因发热、咳嗽、皮疹、黄疸、黑便、血尿、严重口腔溃疡、下肢肿胀或呼吸困难，提示可能为药物性肝损伤、骨髓抑制、严重感染、间质性肺病或血栓事件，需立即停药并急诊处理。
3. **疾病进展与难治性疼痛**：规范治疗3-6个月仍未达标，疼痛持续加重或出现新关节受累；或疼痛性质改变（出现放射痛、麻木、刺痛），提示神经压迫或中枢敏化加重，需调整生物制剂/靶向药方案或联合神经病理性疼痛药物。
4. **结构破坏与功能障碍**：进行性关节畸形、肌腱断裂（如手指过伸畸形）、严重活动受限或跌倒风险显著增加，需骨科/手外科评估手术干预（滑膜切除、肌腱修复、关节置换）。
5. **特殊人群管理**：备孕、妊娠或哺乳期患者需提前调整方案（停用MTX、来氟米特、JAKi，改用羟氯喹、柳氮磺吡啶、小剂量激素）；合并严重心肺疾病、恶性肿瘤或活动性感染者，需多学科会诊调整治疗策略。

## 九、患者教育与自我管理
赋能患者是长期疾病管理的核心，需建立医患共同决策模式，提升自我效能感。
1. **疾病认知与预期管理**：明确RA为慢性免疫性疾病，目前尚无法根治，但通过规范治疗可实现临床缓解与正常生活。消除“止痛药伤身”或“激素恐惧”误区，强调DMARDs的保关节价值。
2. **用药依从性教育**：严格遵医嘱规律服药，不可自行减量、停药或频繁更换方案。了解常见药物副作用及应对方法（如MTX补充叶酸防胃肠道反应，NSAIDs餐后服用）。建立用药日记，记录服药时间、剂量及不适反应。
3. **疼痛自我监测与记录**：每日记录疼痛部位、强度（0-10分）、晨僵时间、诱发因素及缓解措施。识别“红旗征”（突发高热、单关节剧痛、神经功能缺损），及时就医。
4. **关节保护与能量分配**：学习“省力原则”与“关节保护技术”，如使用双手提物、避免长时间维持同一姿势、使用辅助工具。采用“活动-休息”交替策略（Pacing），避免过度劳累导致疾病复发。
5. **生活方式与心理调适**：坚持戒烟限酒，均衡饮食，控制体重。保持适度社交与兴趣爱好，加入病友支持团体。学习放松训练（腹式呼吸、渐进性肌肉放松）应对疼痛焦虑。家属应给予情感支持，避免过度保护或指责。
6. **定期随访与疫苗接种**：遵医嘱定期复查，即使无症状也不可自行中断治疗。接种灭活疫苗（流感、肺炎球菌、带状疱疹、HPV等）以降低感染风险；使用生物制剂/JAKi期间避免接种活疫苗。鼓励患者参与疼痛管理目标设定，提升治疗黏性。

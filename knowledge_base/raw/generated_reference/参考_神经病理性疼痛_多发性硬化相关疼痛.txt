# 多发性硬化相关疼痛

类别：神经病理性疼痛

## 一、概述
多发性硬化（Multiple Sclerosis, MS）是一种中枢神经系统（脑、脊髓、视神经及三叉神经通路）的自身免疫性脱髓鞘疾病。疼痛是MS最常见的非运动症状之一，流行病学数据显示约30%~80%的MS患者在病程中会经历慢性疼痛，显著降低生活质量并加重残疾负担。MS相关疼痛主要分为三大类：①原发性中枢性神经病理性疼痛（如丘脑痛、躯干束带感、四肢灼痛/刺痛、Lhermitte征）；②继发性肌肉骨骼与痉挛性疼痛（如姿势代偿性劳损、关节退变、肌张力增高）；③其他合并疼痛（如偏头痛、膀胱/肠道痉挛痛、三叉神经痛）。疼痛科临床实践中需明确区分原发神经敏化与继发性机械/痉挛因素，避免单一镇痛策略导致的疗效不佳。

## 二、病理生理机制
神经病理性疼痛由躯体感觉神经系统结构或功能损伤所致，MS的核心病理为局灶性脱髓鞘、轴索损伤与神经炎症。其疼痛发生机制呈现多层面交互特征：
1. 外周与中枢异位放电：脱髓鞘导致郎飞结暴露，电压门控钠通道（Nav1.7/1.8/1.9）表达上调与分布异常，引发神经元膜电位不稳定与异位高频放电。
2. 中枢敏化与突触可塑性改变：脊髓背角II层神经元兴奋性持续增强，抑制性中间神经元（GABA能/甘氨酸能）功能减退，下行抑制通路（中脑导水管周围灰质-延髓头端腹内侧区-脊髓背角）功能受损。NMDA受体过度激活引发“Wind-up”现象与长时程增强（LTP），导致痛阈显著下降。
3. 神经胶质细胞活化与细胞因子网络：小胶质细胞与星形胶质细胞被异常神经信号激活，释放IL-1β、TNF-α、IL-6及PGE2等促炎介质，进一步放大痛觉传导并维持慢性化。
4. MS特异性机制：感觉传导束（如脊髓后索、内侧丘系、三叉神经脊束核）脱髓鞘导致感觉整合紊乱，引发感觉异常、触诱发痛与温度觉倒错；肌梭传入通路异常放电可诱发痛性肌痉挛（Tonic Spasms）。
临床表现以自发性疼痛（灼烧、针刺、电击、刀割样）为主，常伴痛觉超敏（Allodynia）、痛觉过敏（Hyperalgesia）及感觉减退。疼痛分布可跨越典型皮节，呈节段性、束带感或偏侧性，常与睡眠碎片化、焦虑抑郁及疲劳形成恶性循环。

## 三、临床评估与筛查
MS相关疼痛的评估需遵循多维度、分层级原则：
1. 神经病理成分筛查：常规使用DN4、painDETECT、ID-Pain及LANSS量表量化神经病理性特征。重点识别触诱发痛、冷/热痛觉异常、感觉缺失（针刺、温度、振动觉）及痛觉超敏范围。
2. 神经系统专科查体：详细记录感觉平面、深感觉/浅感觉分离、腱反射亢进、阵挛、Babinski征及Ashworth肌张力分级。明确疼痛是否与MS病灶分布一致，或呈继发性代偿模式。
3. 辅助检查定位：常规行脑脊髓MRI（T2/FLAIR高信号、强化病灶评估活动性）；必要时行神经传导速度/肌电图（EMG）排除周围神经病或根性压迫；超声或CT用于排查继发性结构病变（如椎间盘突出、肿瘤、感染）。
4. 综合功能与心理评估：采用NRS/VAS量化强度，结合Pain Disability Index (PDI)评估功能受限；常规筛查抑郁（PHQ-9）、焦虑（GAD-7）及睡眠障碍（PSQI）。严格区分原发MS疼痛与继发疼痛、肿瘤性疼痛与非肿瘤性疼痛，为个体化干预提供依据。

## 四、专家诊疗思路（按类别）
在疼痛科门诊，神经病理性疼痛约占慢性疼痛的四成。其本质是感觉神经系统的“错误放电”——外周神经损伤后钠通道表达上调、背根神经节持续去极化，脊髓层面抑制性中间神经元功能减弱，痛觉信号被反复放大，即所谓中枢敏化。
临床上我更关注三点：一是用 ID Pain、DN4 或 painDETECT 快速筛查神经病理成分，避免把所有慢性痛都当成“伤筋动骨”；二是强调按时、规律用药而非痛时再吃，一线在加巴喷丁类、度洛西汀、阿米替林、外用利多卡因之间个体化选择；三是管理预期——这类疼痛很少能“根治”，目标多为 NRS 下降 30%–50%、睡眠与功能改善。
对带状疱疹后神经痛，早期（72 小时内）足量抗病毒治疗联合普瑞巴林，可显著降低后遗神经痛发生率；对已形成的后遗痛，外用利多卡因贴剂联合口服钙通道调节剂是常用组合。
针对MS疼痛，诊疗思维需进一步细化：首先明确疼痛表型（中枢敏化型 vs 痉挛型 vs 混合性），MS患者常合并多种疼痛机制，需“分型打击”。其次，治疗决策必须与神经科疾病活动度同步，急性复发期疼痛需优先控制炎症（糖皮质激素冲击），慢性期则转向神经调节与功能重建。第三，重视药物相互作用与老年/肝肾功能减退患者的药代动力学调整。最后，建立“生物-心理-社会”整合管理模式，将疼痛控制纳入MS整体残疾管理（EDSS）框架，而非孤立对症处理。

## 五、处理原则（药物与干预）
需区分神经病理性与肌痉挛性疼痛
抗痉挛药与神经病理药物分别处理
疾病修饰治疗间接获益
### 通用处理框架与用药要点（按类别）
NICE（2013/2020）推荐初始即在阿米替林、度洛西汀、加巴喷丁、普瑞巴林中“选择一种”作为一线；三叉神经痛一线为卡马西平/奥卡西平。
普瑞巴林起始 75 mg 每日两次（150 mg/d），可在一周内依疗效与耐受增至 150 mg 每日两次，最大 600 mg/d，肾功能减退需减量，停药应≥1 周逐渐减停；度洛西汀 60–120 mg/d；阿米替林 10–25 mg 睡前起，可增至 25–150 mg；加巴喷丁需逐步滴定。
局限性疼痛可外用利多卡因贴剂；8% 辣椒素贴（需专业人员操作）用于不耐受口服或愿用外用者。阿片类不作为一线，仅可短期曲马多作 rescue；难治者可考虑联合用药、神经阻滞或脊髓电刺激（NICE：慢性痛≥6 月、VAS≥50 mm 且常规治疗无效、经成功试验后）。
**MS特异性用药与干预扩展：**
1. 一线神经病理镇痛：普瑞巴林/加巴喷丁针对钙α2δ亚基，抑制兴奋性递质释放；SNRIs（度洛西汀）与TCAs（阿米替林/去甲替林）增强下行5-HT/NE抑制通路。MS患者常伴自主神经功能紊乱，TCAs需监测QT间期与抗胆碱能副作用。
2. 痉挛性疼痛管理：口服巴氯芬（起始5mg tid，滴定至15-30mg tid）、替扎尼定或地西泮。难治性广泛痉挛可评估鞘内巴氯芬泵（ITB），对缓解痛性肌痉挛与改善睡眠具显著效益。
3. 疾病修饰治疗（DMT）的间接镇痛作用：Ocrelizumab、Natalizumab、Fingolimod等DMT可显著降低临床复发率与MRI新发/强化病灶，从源头减少脱髓鞘事件引发的急性疼痛与慢性敏化。
4. 介入与微创治疗：周围神经阻滞（如三叉神经分支、枕大神经）用于局灶性疼痛；脉冲射频调节背根神经节；脊髓电刺激（SCS）或背根神经节电刺激（DRG-SCS）适用于顽固性中枢痛，需严格筛选（试验期VAS下降≥50%）。急性期可短期硬膜外糖皮质激素缓解根性痛，但需警惕感染与血糖波动。

## 六、非药物与康复
在一线药物基础上联合运动、认知行为治疗与睡眠管理；患者教育帮助理解中枢敏化与长期管理，减少灾难化认知。
难治者可评估神经阻滞、脊髓电刺激或鞘内治疗；注意 NICE 提示 TENS 等循证有限，应以运动与心理等循证措施为核心。
**康复与心理干预深化：**
1. 物理康复：个体化拉伸与强化训练（重点改善腘绳肌、小腿三头肌痉挛），水疗（32-34℃温水）可缓解肌张力与疼痛；步态训练与平衡训练降低跌倒风险。避免过度疲劳与热敏感（Uhthoff现象），运动遵循“低强度、分次、循序渐进”原则。
2. 心理与行为干预：疼痛神经科学教育（PNE）帮助患者理解“疼痛≠组织损伤”，降低恐惧回避；CBT针对疼痛灾难化、睡眠障碍与情绪共病进行认知重构；正念减压（MBSR）与接纳承诺疗法（ACT）改善疼痛接纳度与生活质量。
3. 物理因子治疗：经皮神经电刺激（TENS）对部分患者有效，但循证等级中等，建议作为辅助；温热敷/冷敷需谨慎，MS患者常伴温度觉异常，易致烫伤或冻伤，需严格监控皮肤感觉与温度。针灸、经颅磁刺激（rTMS）在部分研究中显示对中枢痛有调节潜力，可作为难治性病例的补充选项。

## 七、随访与监测要点
发作与复发迹象
功能状态
疲劳与情绪
**结构化随访协议：**
1. 随访频率与节点：初治/调药期每2-4周随访，稳定期每3-6个月。每次评估需记录疼痛表型变化、NRS/VAS趋势、PDI功能评分及药物不良反应。
2. 疾病活动与神经系统监测：同步追踪MS复发频率、新发神经功能缺损、EDSS评分变化及MRI病灶活动性。疼痛急性加重或性质改变需警惕新发脱髓鞘事件或继发感染（如UTI可诱发症状性痉挛痛）。
3. 药物安全性与代谢监测：定期复查肝肾功能、电解质、血常规；TCAs/SNRIs监测血压、心率及心电图；加巴喷丁类关注水肿、嗜睡及认知影响；长期使用需评估骨密度与维生素D水平。
4. 心理与睡眠量化：每3个月复测PHQ-9、GAD-7及PSQI，识别抑郁/焦虑恶化或失眠慢性化。疲劳评估采用Fatigue Severity Scale (FSS)，区分疼痛相关疲劳与MS原发疲劳。
5. 治疗目标动态调整：以“功能恢复与疼痛可接受”为核心，若NRS下降<30%或副作用不可耐受，及时启动药物轮换、联合或介入评估。

## 八、预警与转诊指征
急性复发病灶需神经科处理
**多学科预警与转诊路径：**
1. 神经科紧急转诊：出现急性进行性感觉平面、新发运动无力、视力急剧下降、严重头痛伴呕吐/视乳头水肿（警惕PRES或静脉窦血栓）、大小便潴留/失禁、鞍区感觉减退（马尾/圆锥综合征）。提示急性横贯性脊髓炎、视神经脊髓炎谱系疾病（NMOSD）重叠或MS复发，需立即行MRI与激素冲击治疗。
2. 疼痛科/介入科转诊：优化足量足疗程药物治疗（≥4-6周）仍无效；疼痛严重影响ADL与睡眠；需评估SCS、ITB泵、脉冲射频或超声引导下神经丛阻滞；怀疑复杂性区域疼痛综合征（CRPS）或继发性骨关节病变。
3. 精神心理科转诊：PHQ-9≥15分、GAD-7≥10分、存在自杀意念或严重睡眠障碍；需抗抑郁/抗焦虑药物干预或强化心理治疗。
4. 康复医学科转诊：Ashworth肌张力≥3级伴痛性痉挛；步态不稳/跌倒高风险；需制定个体化运动处方与辅具适配。

## 九、患者教育与自我管理
告知疼痛属神经敏化、可管理；按时服药而非剧痛时才用；记录疼痛与睡眠变化。
避免饮酒与跌倒，出现新发无力、鞍区或二便障碍、突发剧烈头痛等需立即就诊。
**系统化患者赋能计划：**
1. 疼痛神经科学教育：向患者通俗解释“脱髓鞘导致神经线路短路”“中枢敏化如同音量旋钮被调高”，明确疼痛是疾病的一部分而非病情恶化的唯一标志，建立合理治疗预期，减少焦虑与过度医疗。
2. 用药依从性与安全管理：强调神经病理药物需“规律服用、缓慢滴定、不可骤停”；解释常见副作用（嗜睡、头晕、口干）多为自限性，可通过睡前服药或剂量微调缓解；严禁自行联用酒精、苯二氮䓬类或其他中枢抑制剂，防跌倒与呼吸抑制。
3. 自我监测与日记管理：指导使用疼痛-功能-睡眠三联日记，记录疼痛性质、诱因（热、疲劳、压力、感染）、药物起效时间与不良反应；识别个人触发因素，制定应对预案。
4. 生活方式与居家安全：保持规律作息，采用“能量守恒”策略（Pacing）避免过度劳累；居家防滑、安装扶手、穿防滑鞋；温度调节注意避免极端冷热刺激；均衡饮食，补充钙/维D，维持肠道功能。
5. 紧急识别与就医指征：明确告知“红色警报”症状（突发肢体瘫痪、视力丧失、大小便失控、剧烈头痛、高热伴意识改变），出现即刻急诊就诊。鼓励加入MS患者支持团体，获取心理支持与经验交流，提升长期疾病管理能力。

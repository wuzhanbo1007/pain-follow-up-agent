# 内脏痛(癌性)

类别：癌痛

## 一、概述
内脏痛(癌性)是指由胸腔、腹腔、盆腔等实质性或空腔性脏器受到肿瘤直接浸润、包膜牵张、管腔梗阻、缺血或邻近结构压迫所引发的疼痛综合征。其临床特征以定位模糊、弥散性钝痛、胀痛或阵发性绞痛为主，常伴随明显的自主神经功能紊乱症状（如恶心、呕吐、出汗、面色苍白、血压波动及心率失常）。在肿瘤病程中，内脏痛可独立存在，但更多时候与躯体痛（骨转移、软组织浸润）及神经病理性痛（神经丛受压、化疗神经毒性）交织形成混合型癌痛。常见原发部位包括胃肠道、胰腺、肝胆、泌尿生殖系统及妇科恶性肿瘤。早期识别、精准分型与多模式干预是改善患者生存质量的核心。

## 二、病理生理机制
癌性内脏痛的病理生理机制复杂，呈现多因素、多通路交织特征。
1. **伤害性感受传导与中枢整合**：内脏传入纤维主要由Aδ纤维（传导快痛、定位较准）和C纤维（传导慢痛、弥散性痛及自主神经反射）组成。肿瘤浸润或管腔扩张刺激内脏感受器，信号经交感/副交感神经传入脊髓背角。由于内脏传入纤维在脊髓节段存在广泛的汇聚投射（Convergence Projection），易出现牵涉痛（如胰腺癌痛放射至背部，妇科肿瘤痛放射至大腿内侧）。
2. **炎症微环境与神经可塑性**：肿瘤微环境中大量释放前列腺素（PGs）、白三烯、缓激肽及多种细胞因子（TNF-α、IL-1β、IL-6）。这些介质不仅直接致敏外周伤害性感受器，还通过血脑屏障激活小胶质细胞与星形胶质细胞，上调脊髓背角NMDA受体、AMPA受体及降钙素基因相关肽（CGRP）表达，引发中枢敏化（Central Sensitization），导致痛阈下降、痛觉过敏及异常性疼痛。
3. **神经病理性成分与敏化**：肿瘤压迫神经丛（如腹腔神经丛、腹下神经丛）或化疗药物（紫杉醇、奥沙利铂、顺铂）导致轴突变性与脱髓鞘，产生自发性放电与异位放电。慢性疼痛状态下，下行抑制通路（5-HT、NE能）功能减弱，下行易化通路（谷氨酸、P物质）亢进，形成恶性循环。
4. **阿片诱导的痛觉超敏（OIH）与快速耐受**：长期大剂量阿片类药物使用可激活脊髓小胶质细胞，释放促炎因子，同时上调脑干蓝斑核去甲肾上腺素能活性及脊髓Dynorphin释放，导致对疼痛刺激的反应性异常增高。OIH需与疾病进展严格鉴别：前者表现为疼痛范围扩大、性质改变、对阿片增量反应差甚至恶化，而后者通常伴随肿瘤标志物上升或影像学进展。处理策略应转向多模式镇痛、NMDA受体拮抗剂（如氯胺酮/美沙酮）应用及阿片轮换。

## 三、临床评估与筛查
癌痛评估必须遵循“全面、动态、多维度”原则，为个体化治疗提供依据。
1. **疼痛强度与特征量化**：常规采用数字评分法（NRS 0-10分）或视觉模拟评分法（VAS）评估静息与活动时强度。结合简明疼痛量表（BPI）评估疼痛对睡眠、情绪、日常活动及行走能力的干扰程度。详细记录疼痛性质（钝痛、胀痛、绞痛、烧灼痛）、部位、发作规律、加重/缓解因素及牵涉痛区域。
2. **爆发痛专项评估**：明确爆发痛（Breakthrough Pain, BTP）的定义（在稳定背景痛基础上出现的短暂性疼痛加剧）。记录诱因（如体位改变、肠道蠕动、排便）、发作频率（每日次数）、持续时间、疼痛峰值及既往抢救药物（Rescue medication）的起效时间与缓解程度。BTP频率是调整背景阿片剂量的关键指标。
3. **用药史与耐受状态评估**：详细记录既往阿片类药物种类、剂量、使用时长、疗效及不良反应。计算吗啡等效日剂量（MEDD），评估阿片耐受状态（连续使用≥1周且MEDD≥60 mg为耐受）。筛查药物代谢相关基因多态性（如CYP2D6、CYP3A4）对药物疗效的潜在影响。
4. **共病与心理社会筛查**：常规使用PHQ-9、GAD-7及医院焦虑抑郁量表（HADS）筛查抑郁、焦虑及谵妄风险。评估睡眠障碍、癌性疲乏及社会支持系统。心理共病不仅降低疼痛阈值，还显著影响治疗依从性。
5. **体格检查与辅助检查**：腹部视触叩听（注意肠鸣音、肌紧张、反跳痛、包块）；神经系统查体（感觉平面、肌力、反射、病理征）。结合影像学（增强CT、MRI、PET-CT、超声）明确肿瘤负荷、梗阻部位、骨转移范围及神经受压情况。实验室检查涵盖血常规、肝肾功能、电解质（警惕高钙血症）、肿瘤标志物及凝血功能，为药物选择与剂量调整提供安全基线。

## 四、专家诊疗思路（按类别）
癌痛是肿瘤患者最常见的伴随症状之一，约50%初诊患者及70%-90%晚期患者全程受累。我的核心诊疗理念是“充分镇痛、最小副作用、保障生活质量与尊严”，严格遵循WHO三阶梯原则与NCCN/ESMO成人癌痛临床实践指南，强调动态滴定与多模式协同。
1. **基础镇痛与阿片滴定**：中重度癌痛（NRS≥4）以阿片类药物为基石。阿片未耐受者起始推荐吗啡即释片5-7.5 mg q4h PRN（或5-15 mg起始），羟考酮即释2.5-5 mg q4h，或氢吗啡酮2 mg q4h。滴定遵循“小步快跑、密切监测”原则：每24-48小时根据疼痛评分与不良反应，将日总量增加30%-100%。切忌因恐惧成瘾或过度担心呼吸抑制而长期欠量镇痛，癌痛患者发生物质使用障碍（SUD）的概率极低。
2. **爆发痛与背景痛协同管理**：爆发痛必须单独处方抢救药物。单次Rescue剂量通常设定为24小时背景阿片总量的10%-20%（或约日剂量的1/6-1/10）。即释口服给药后1小时、静脉给药后15-30分钟必须复评疼痛缓解程度。若每日需使用Rescue药物≥4次，提示背景剂量不足，应按比例上调基础阿片剂量。
3. **不良反应前瞻性与预防性干预**：自阿片起始第一天即启动阿片诱导的便秘（OIC）预防方案（刺激性泻药如番泻叶/比沙可啶+渗透性泻药如聚乙二醇/乳果糖+必要时促分泌剂）。恶心呕吐多在用药初期出现，通常1-2周内耐受，可短期使用甲氧氯普胺或昂丹司琼；持续不缓解需排查肠梗阻或脑转移。
4. **特殊情境处理与阿片轮换**：出现中枢敏化、OIH或快速耐受时，不应盲目叠加阿片剂量，而应实施阿片轮换（Opioid Rotation）。根据等效剂量表换算后，给予原剂量的25%-50%作为新阿片起始剂量，以规避不完全交叉耐受。美沙酮或丁丙诺啡对神经病理性成分及OIH有独特优势。终末期患者应以舒适护理（Comfort Care）为核心，尊重预先医疗指示，必要时启用镇静镇痛方案。
5. **原发病与并发症靶向处理**：积极处理可逆性疼痛源，如经皮内镜下胃肠造瘘（PEG）、胆道/肠道支架置入、腹腔穿刺放液减压。骨转移痛联合双膦酸盐/地舒单抗及局部姑息性放疗（8 Gy单次或20 Gy/5次）。

## 五、处理原则（药物与干预）
癌性内脏痛机制区别于单纯躯体痛，常需多靶点干预。遵循“无创优先、阶梯递进、多模式联合、个体化精准”原则。
1. **阿片类药物优化**：
   - 即释制剂用于滴定与爆发痛处理；缓释制剂（吗啡、羟考酮、氢吗啡酮缓释片）用于背景痛维持，q12h或q24h给药。
   - 芬太尼透皮贴剂适用于吞咽困难、胃肠道梗阻或需稳定血药浓度的患者，需计算等效剂量并过渡36-72小时。
   - 避免使用哌替啶（代谢产物去甲哌替啶致神经毒性/癫痫）与丙氧芬（心脏毒性）。
2. **辅助镇痛药物（Adjuvants）**：
   - **抗胆碱能/解痉药**：山莨菪碱、丁溴东莨菪碱、匹维溴铵等，有效缓解空腔脏器痉挛性绞痛。
   - **糖皮质激素**：地塞米松（4-8 mg/d）减轻肿瘤周围水肿、包膜牵张及神经压迫，改善食欲与整体状态，注意血糖、感染及骨质疏松监测。
   - **抗抑郁/抗惊厥药**：度洛西汀、阿米替林、加巴喷丁、普瑞巴林，针对合并的神经病理性痛成分及中枢敏化。
   - **NMDA受体拮抗剂**：低剂量氯胺酮（静脉或皮下）或美沙酮，用于难治性疼痛、OIH或阿片耐受者。
   - **骨靶向药物**：唑来膦酸、地舒单抗预防骨相关事件（SREs），显著降低骨转移痛。
3. **非阿片类镇痛药**：对乙酰氨基酚（≤3 g/d）与NSAIDs（塞来昔布、双氯芬酸、布洛芬）可作为轻中度疼痛基础或阿片联合用药。NSAIDs需严格评估胃肠道出血、肾功能及心血管风险，必要时联用PPI。
4. **介入与微创治疗**：
   - **神经阻滞/毁损**：腹腔神经丛阻滞（CPB）用于胰腺癌、上腹部肿瘤痛；腹下神经丛阻滞用于盆腔肿瘤痛。乙醇或酚甘油毁损适用于预期生存期短、药物难控者。
   - **鞘内药物输注系统（IDDS）**：适用于口服困难、严重OIC、阿片毒性或需极低剂量高效镇痛者，可联合阿片、局麻药（罗哌卡因）及佐剂（可乐定、齐考诺肽）。
   - **姑息性放疗与手术**：局部放疗缓解骨转移/软组织压迫痛；内镜/介入支架解除梗阻；姑息性减瘤手术缓解机械性疼痛。
   - **其他**：经皮神经电刺激（TENS）、脉冲射频调节神经传导。

## 六、非药物与康复
癌痛管理绝非单纯药物堆砌，非药物干预在改善功能状态、心理韧性及生活质量方面具有循证医学支持。
1. **心理社会干预**：认知行为疗法（CBT）帮助患者重构疼痛认知，打破“疼痛-焦虑-肌肉紧张-疼痛加重”循环；正念减压疗法（MBSR）与引导性想象可降低交感兴奋，改善睡眠。提供个体或团体心理咨询，处理疾病恐惧、死亡焦虑及家庭角色转变。
2. **物理康复与体位管理**：在疼痛可耐受范围内进行轻度活动（如床边坐起、短距离行走），预防肌肉萎缩、深静脉血栓及压疮。指导患者采用减压体位（如屈膝侧卧、腹部垫枕），使用矫形垫或气垫床分散压力。
3. **营养与代谢支持**：联合临床营养师评估营养风险（NRS-2002）。针对癌性恶病质提供高蛋白、高热量、易消化饮食；必要时启用肠内/肠外营养支持。纠正电解质紊乱（低钾、低镁可加重肠麻痹与痛觉敏感）。
4. **终末期舒缓与安宁疗护**：早期整合缓和医疗团队，聚焦症状控制而非疾病治愈。开展预先医疗指示（Advance Directives）沟通，明确抢救意愿（DNR/DNI）。为家属提供照护技能培训与哀伤辅导，构建延续性支持网络。多学科团队（疼痛科、肿瘤科、护理、心理、营养、社工）每周联合查房，统一治疗目标。

## 七、随访与监测要点
建立结构化、周期性的随访档案，实现疼痛管理的闭环监控。
1. **疼痛与症状动态追踪**：每次随访记录NRS评分（静息/活动）、BPI干扰评分、爆发痛频率及Rescue药物使用次数。同步监测腹胀、恶心、呕吐、肠鸣音变化，评估肠道功能恢复情况。
2. **用药安全与不良反应监测**：定期评估镇静程度（Ramsay或Sedation-RASS评分）、呼吸频率（≥12次/分）、瞳孔变化及血氧饱和度。监测肝肾功能（肌酐清除率调整阿片代谢）、电解质（钠、钾、钙、镁）、血常规及凝血指标。筛查阿片诱导的内分泌功能障碍（性腺功能减退、肾上腺皮质功能抑制），必要时检测睾酮、皮质醇及骨密度。
3. **营养与代谢指标**：记录体重、BMI、白蛋白、前白蛋白、淋巴细胞计数。评估进食量、液体摄入量及排便频率/性状（Bristol大便分类法），调整泻药方案。
4. **心理与功能状态评估**：每4-8周复测PHQ-9、GAD-7、HADS。使用ECOG或KPS评分量化体能状态。采用EORTC QLQ-C30或FACT-P评估生活质量变化。
5. **肿瘤负荷与疾病进展监测**：结合影像学复查（每2-3个月）与肿瘤标志物趋势，判断疼痛变化是源于疾病进展还是药物耐受/不良反应，及时调整治疗策略。

## 八、预警与转诊指征
识别红色警报症状，避免延误危及生命的并发症处理。
1. **急腹症与外科干预指征**：突发剧烈持续性腹痛伴腹肌紧张、反跳痛、板状腹（提示穿孔或急性腹膜炎）；阵发性绞痛进行性加重伴呕吐、肛门停止排气排便、肠鸣音亢进或消失（提示完全性肠梗阻）；影像学证实游离气体、肠壁缺血坏死或绞窄。需紧急外科会诊、胃肠减压、液体复苏及手术干预。
2. **神经系统急症**：新发或进行性加重的腰背痛伴下肢无力、感觉平面、大小便失禁或尿潴留（提示脊髓压迫或马尾综合征）；需24小时内行MRI及大剂量地塞米松，紧急放疗或椎板减压术。
3. **药物毒性/过量预警**：呼吸频率持续<8-10次/分，SpO2<90%，瞳孔针尖样缩小，深度镇静或意识模糊（阿片过量）；频繁呕吐、严重便秘伴腹胀（粪石性梗阻）；肌阵挛、高热、意识改变（5-羟色胺综合征或NMS，多见于联用SSRI/SNRI与曲马多/美沙酮）。需立即停药、支持治疗、纳洛酮拮抗或ICU监护。
4. **难治性疼痛与高级干预指征**：规范多模式镇痛2-4周后NRS仍≥7分，或出现严重阿片毒性无法耐受；需转诊疼痛科评估神经阻滞、鞘内泵植入、射频消融或临床试验药物。
5. **心理社会危机**：出现自杀意念、严重抑郁发作、家庭照护崩溃或沟通障碍。转诊精神心理科、社工及安宁疗护团队。

## 九、患者教育与自我管理
赋能患者与家属，建立科学、安全的居家疼痛管理认知与行为模式。
1. **规范用药原则**：强调“按时服药（By the clock）”维持稳定血药浓度，而非“按需服药（By the need）”导致疼痛波动。爆发痛可单独使用即释药物，但需记录使用频次，若每日≥4次需联系医生调整背景剂量。严禁自行突然停药（防戒断综合征）或随意加倍剂量（防中毒）。
2. **便秘预防与管理**：便秘是阿片类药物几乎必然发生的副作用，不会随用药时间延长而耐受。教育患者从用药首日即采取综合措施：每日饮水1500-2000 ml（心肾功能允许下），增加膳食纤维（蔬菜、全谷物），规律排便习惯。按医嘱阶梯使用通便药物，若3天未排便或腹胀明显及时就医。
3. **不良反应识别与应对**：初期恶心呕吐多在1-2周内自行缓解，可少量多餐、避免油腻；持续不适可备用止吐药。瘙痒避免抓挠，可冷敷或外用炉甘石，严重者可遵医嘱使用抗组胺药或阿片减量。嗜睡若持续不缓解或影响日间活动，需复诊评估。
4. **安全储存与应急处置**：所有镇痛药置于儿童无法触及、阴凉干燥处，避免与酒精同服。剩余或过期药品按医疗废物规范回收，严禁转赠。家属必须掌握纳洛酮鼻喷剂或注射剂的使用方法，遇到呼吸抑制或意识丧失时立即肌注/鼻喷并拨打急救电话。
5. **生活方式与心理调适**：鼓励在体力允许下进行温和活动（如散步、太极、瑜伽），改善肠道蠕动与情绪。保证规律作息，营造安静舒适的睡眠环境。学习腹式呼吸、渐进性肌肉放松等自我调节技巧。明确告知：癌痛使用阿片类药物成瘾率极低，规范镇痛是基本人权，无需背负心理包袱。提供疼痛日记模板，记录用药时间、疼痛评分、爆发痛事件及不良反应，复诊时携带以供医生精准调药。

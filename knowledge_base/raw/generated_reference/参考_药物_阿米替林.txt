# 阿米替林

文档标题：阿米替林
===== 原文开始 =====
类别：药物

## 一、概述
阿米替林（Amitriptyline）属于经典的三环类抗抑郁药（TCA），在慢性疼痛管理中具有不可替代的临床地位。尽管其抗抑郁剂量通常为75–150 mg/日，但在神经病理性疼痛（NP）、偏头痛预防、紧张型头痛及纤维肌痛综合征的循证治疗中，广泛采用小剂量起始策略（通常10–25 mg/日，滴定至25–75 mg/日）。该药物凭借其独特的中枢镇痛机制与镇静作用，常被用作夜间给药的首选药物，不仅能有效降低疼痛强度（通常要求NRS评分下降≥30%或50%），还可显著改善慢性疼痛患者共病的睡眠结构（增加慢波睡眠、减少夜间觉醒）。作为多模式镇痛方案的基石药物之一，阿米替林在疼痛科、神经内科及全科临床中均被列为一线或二线核心用药。

## 二、病理生理机制
阿米替林的镇痛作用并非源于其抗抑郁特性，而是通过多靶点调节中枢与外周疼痛传导通路实现：
1. **单胺能再摄取抑制**：强效抑制脊髓背角及脑干网状结构（如中缝大核、蓝斑核）突触前膜对5-羟色胺（5-HT）和去甲肾上腺素（NE）的再摄取，增强下行抑制性疼痛调制通路（PAG-RVM-脊髓背角）的张力，从而“关闭”痛觉上传闸门。
2. **电压门控钠通道阻滞**：直接阻断神经元细胞膜上的Na⁺通道，降低异位自发放电频率，对神经病理性疼痛中的感觉异常、痛觉超敏及电击样疼痛具有特异性抑制作用。
3. **受体拮抗作用**：同时拮抗M胆碱能受体、H1组胺受体及α1-肾上腺素能受体。H1受体拮抗贡献了其显著的镇静与促眠效应；α1受体拮抗则可能导致体位性低血压；M受体拮抗则是口干、便秘、尿潴留及心动过速等抗胆碱能不良反应的药理学基础。
4. **药代动力学特征**：口服吸收完全，生物利用度约30–60%，首过效应明显。主要在肝脏经CYP2D6、CYP2C19及CYP3A4代谢为活性代谢物去甲替林（Nortriptyline）。消除半衰期约10–28小时，个体差异极大，受基因多态性、年龄及合并用药影响显著。老年患者及肝功能不全者需大幅减量。

## 三、临床评估与筛查
启动阿米替林治疗前必须进行系统化临床评估与风险筛查：
1. **适应证与疼痛表型确认**：明确疼痛性质（神经病理性、伤害性、混合性或中枢敏化型），推荐使用DN4、PainDETECT或S3量表进行表型分类，确保药物匹配疼痛机制。
2. **心血管基线评估**：TCA可延长QTc间期并诱发室性心律失常。治疗前必须行12导联心电图，评估QTc间期、QRS波宽度及是否存在房室传导阻滞。既往有心肌梗死史、心力衰竭、未控制的心律失常者属绝对禁忌。
3. **肝肾功能与代谢筛查**：检测ALT、AST、肌酐、eGFR、空腹血糖及血脂。严重肝功能不全者代谢能力下降，易致蓄积中毒；糖尿病或代谢综合征患者需警惕体重增加与血糖波动。
4. **禁忌证与相互作用排查**：排查闭角型青光眼、前列腺增生伴严重尿潴留、癫痫未控制、甲状腺功能亢进等相对禁忌。全面核对合并用药清单，重点规避CYP2D6强抑制剂（如氟西汀、帕罗西汀、奎尼丁）、其他抗胆碱能药物、中枢抑制剂及5-HT能药物（防5-羟色胺综合征）。
5. **精神心理与共病评估**：筛查抑郁、焦虑、自杀意念及物质滥用史。TCA过量致死率高，对精神心理脆弱患者需严格评估用药安全与家属监管能力。

## 四、专家诊疗思路（按类别）
疼痛治疗需遵循“机制导向、阶梯递进、个体化滴定”原则。阿米替林在镇痛谱系中的定位如下：
- **神经病理性疼痛**（糖尿病周围神经病变、带状疱疹后神经痛、坐骨神经痛、化疗诱导周围神经病变）：作为一线推荐药物。起始10 mg睡前口服，每3–7日递增10–25 mg，目标镇痛剂量通常为25–50 mg/日（极少超过75 mg/日）。若单药疗效不足，可与加巴喷丁类、SNRI或外用利多卡因/辣椒素联合，但需密切监测中枢抑制与5-HT能风险。
- **头痛预防**（偏头痛、慢性紧张型头痛）：剂量同NP，起效需2–4周。对合并失眠、焦虑的头痛患者优势显著。
- **纤维肌痛综合征**：作为多成分镇痛方案的核心，改善广泛性疼痛、晨僵与疲劳感。
- **伤害性疼痛**（骨关节炎、术后痛）：不作为首选，仅在合并中枢敏化或NP特征时作为辅助用药。
- **癌痛管理**：用于阿片类药物减量辅助或神经病理性癌痛成分控制，避免与强阿片、苯二氮䓬类无指征联用以防呼吸抑制。
- **停药与转换策略**：疗效不佳（足量足疗程4–6周无效）或无法耐受不良反应时，应果断转换至SNRI（如度洛西汀）或新型钙通道调节剂。长期用药需每3–6个月进行“用药复审”（Deprescribing）：评估持续获益、尝试阶梯减量、寻找最低有效维持剂量。

## 五、处理原则（药物与干预）
### 通用处理框架与用药要点（按类别）
1. **给药规范**：严格遵循“低剂量起始、缓慢滴定、最低有效剂量维持”原则。推荐睡前30–60分钟整片吞服，利用其镇静作用改善睡眠，同时减轻日间抗胆碱能不适。避免与酒精同服。
2. **抗胆碱能不良反应管理**：口干（建议无糖口香糖、人工唾液、增加饮水）、便秘（膳食纤维、渗透性泻剂如聚乙二醇、规律排便训练）、视力模糊（避免长时间用眼）、尿潴留（BPH患者监测排尿日记，必要时泌尿科会诊）。
3. **心血管与代谢监测**：监测卧立位血压防体位性低血压；定期监测体重、腰围、空腹血糖及血脂。老年患者遵循Beers标准，谨慎使用。
4. **绝对禁忌与慎用人群**：近期心梗、心律失常、传导阻滞、窄角型青光眼、严重肝病、MAOI使用史（需间隔14天以上）、妊娠期（尤其孕早期致畸风险）及哺乳期禁用或慎用。
5. **多模式干预整合**：药物仅为疼痛管理的一环。应同步整合物理治疗、神经调控（如TENS）、心理干预及必要时的介入治疗（如神经阻滞、脉冲射频、脊髓电刺激），实现靶点互补与剂量节约。

## 六、非药物与康复
慢性疼痛的长期管理必须依托生物-心理-社会医学模式，非药物干预与药物治疗具有协同增效作用：
- **认知行为疗法（CBT）**：纠正灾难化思维、疼痛恐惧回避行为，建立适应性应对策略，显著降低疼痛相关残疾指数。
- **睡眠卫生优化**：固定作息、卧室环境控制、睡前放松训练（渐进性肌肉放松、正念冥想），减少夜间痛觉敏化与药物依赖。
- **运动康复与物理治疗**：针对纤维肌痛与NP，推行低冲击有氧运动（游泳、快走）、核心肌群强化、神经滑动术与筋膜松解。遵循“循序渐进、避免过度疲劳”原则，结合节拍器或心率监测控制运动强度。
- **营养与代谢干预**：糖尿病神经病变患者严格控糖（HbA1c<7.0%）；炎症性疼痛采用地中海饮食或抗炎饮食模式；控制体重以减轻骨关节负荷。
- **多学科疼痛门诊（MDT）**：整合疼痛科、康复科、心理科、营养科与药学部，制定个体化长期管理路径，提升整体功能状态与生活质量。

## 七、随访与监测要点
建立结构化随访路径，动态评估疗效与安全性：
- **初期随访（用药1–4周）**：重点监测耐受性、镇静程度、抗胆碱能反应及体位性血压。评估睡眠改善情况。必要时复查心电图（QTc）。
- **疗效评估期（用药4–8周）**：采用标准化量表（NRS/VAS、PDI、SF-36）评估疼痛强度下降幅度、功能恢复及生活质量改善。目标为疼痛缓解≥30%且不良反应可控。
- **维持期随访（每3–6个月）**：复查肝肾功能、空腹血糖、血脂、体重指数。评估药物依赖、耐受性及减量可能性。对难治性病例可考虑治疗药物监测（TDM），检测去甲替林血药浓度（治疗窗通常50–150 ng/mL），指导精准滴定。
- **长期监测**：年度心电图评估心脏传导安全性；骨密度筛查（长期TCA使用与骨质疏松风险相关）；精神心理状态随访，警惕迟发性抑郁或自杀意念。

## 八、预警与转诊指征
识别危险信号并及时干预是保障患者安全的核心：
- **急性中毒与过量预警**：TCA治疗窗窄，过量可致致死性心律失常（QRS>100ms、QTc>500ms）、难治性低血压、中枢抑制、癫痫发作及抗胆碱能危象（高热、谵妄、肠麻痹）。一旦出现嗜睡加重、意识模糊、心悸晕厥、呼吸减慢或抽搐，立即停药并急诊就医。
- **严重不良反应预警**：出现剥脱性皮炎、Stevens-Johnson综合征等皮疹；黑便/呕血（消化道出血）；进行性水肿或尿量锐减（心肾功能损害）；眼痛、视力骤降（急性闭角型青光眼发作）；5-羟色胺综合征（高热、肌强直、阵挛、交感神经兴奋）。
- **转诊指征**：足量足疗程治疗无效或无法耐受；出现严重心血管/精神神经系统并发症；需升级介入治疗（如神经根阻滞、椎管内给药、脊髓电刺激植入）；共病复杂精神障碍需精神科协同管理；疑似药物滥用或依赖。

## 九、患者教育与自我管理
提升患者用药依从性与自我管理能力是慢性疼痛长期控制的关键：
- **规范用药原则**：严格按医嘱剂量与频次服用，切勿自行加量、减量或突然停药。突然停药可引发撤药综合征（失眠、恶心、头痛、焦虑、感觉异常），需采用4–6周阶梯式减量。
- **相互作用与生活方式警示**：避免饮酒及非处方中枢抑制剂；驾驶或操作精密机械前评估镇静影响；外出携带用药清单。合并感冒药、抗过敏药时需核对成分，防抗胆碱能叠加。
- **不良反应应对与记录**：掌握常见副作用的自我缓解技巧（如口干含冰片、便秘增加饮水与膳食纤维）。记录疼痛日记与用药反应，复诊时提供客观依据。
- **安全储存与应急准备**：药物置于儿童无法触及的阴凉干燥处，原包装保存。家属需知晓过量中毒的紧急处理流程（立即拨打急救电话，勿催吐，保留药瓶）。
- **赋能与心理支持**：强调疼痛管理的长期性与阶段性目标，建立合理预期。鼓励参与患者支持团体，获取同伴经验与心理支持，提升疾病掌控感与治疗信心。

# ID Pain 量表
类别：评估工具

## 一、概述
ID Pain 量表是一种简短、高效、经过多中心验证的筛查工具，主要用于快速筛查神经病理性疼痛（Neuropathic Pain, NP）成分。该量表由 Breuil 等学者于 2008 年开发，包含 5 个核心症状条目，涵盖烧灼痛、冷诱发性疼痛、电击样痛、触觉异常性疼痛及麻木感。其设计初衷是为临床医生在繁忙的门诊或随访场景中提供一把“快速标尺”，弥补传统问诊在识别隐匿性神经病理成分时的盲区。量表总分范围为 0-10 分，≥1 分提示存在神经病理性疼痛特征。在中国慢性疼痛管理实践中，ID Pain 已被广泛纳入多模式疼痛评估体系，尤其适用于糖尿病周围神经病变、带状疱疹后神经痛、坐骨神经痛及纤维肌痛综合征等疾病的初筛与疗效动态监测。

## 二、病理生理机制
ID Pain 量表本身为评估工具，不直接对应病理机制，但其条目设计精准映射了神经病理性疼痛的核心病理生理过程。NP 的发生主要源于外周或中枢神经系统的损伤或疾病，导致痛觉传导通路结构与功能异常。外周机制包括伤害性感受器敏化、离子通道（如 Nav1.7/1.8、TRPV1）异常表达、神经纤维脱髓鞘及异常神经放电；中枢机制涉及脊髓背角上行传导通路的长时程增强（LTP）、下行抑制通路（如 5-HT/NE 系统）功能减退、小胶质细胞与星形胶质细胞活化，以及皮层-边缘系统对疼痛情绪维度的放大。ID Pain 的 5 个条目分别对应不同机制：烧灼痛与电击样痛反映异位冲动发放与离子通道功能障碍；冷诱发性疼痛提示 Aδ 纤维或 C 纤维异常敏化；触觉异常性疼痛（轻触即痛）是中枢敏化与 Aβ 纤维异常投射至痛觉通路的典型表现；麻木感则指向大纤维传入障碍或感觉整合异常。通过将主观疼痛与功能、情绪、睡眠等维度量化，ID Pain 便于纵向比较与随访决策，弥补仅凭回忆的偏差。不同工具侧重点不同（强度、神经病理成分、干扰、情绪、睡眠），应依据场景组合使用并理解其适用边界与信效度。

## 三、临床评估与筛查
规范的疼痛评估是精准治疗的前提。依据评估目的选择工具：强度用 NRS/VAS，神经病理用 ID Pain/DN4/painDETECT，干扰用 BPI，情绪用 PHQ-9/GAD-7，睡眠用 PSQI，生活质量用 SF-36/EQ-5D。ID Pain 适用于门诊初筛、慢性病程追踪及多中心研究的数据标准化，其优势在于耗时短（<2 分钟）、跨文化适用性强、对轻中度 NP 敏感性高。临床使用时需注意：ID Pain 仅提示“可能”存在 NP 成分，不能替代神经系统查体、肌电图/神经传导速度（EMG/NCV）、皮肤活检或影像学检查。定期复测以观察趋势，并将结果转化为可执行的随访计划与目标调整，避免“为评分而评分”。在 PainSmart 系统中，ID Pain 数据可与电子病历、可穿戴设备生理参数联动，构建患者疼痛数字表型，为个体化干预提供循证依据。

## 四、专家诊疗思路（按类别）
疼痛是主观的，没有工具就靠猜。我在门诊常规用 NRS 量化强度，但绝不止看一个数字——BPI（简明疼痛量表）能告诉我痛对生活各方面的干扰，PHQ-9/GAD-7 筛查抑郁焦虑共病，PSQI 看睡眠，ID Pain/DN4/painDETECT 专门抓神经病理成分。随访时这些工具要纵向复测，看的是趋势不是单次值。关键是对结果“采取行动”：共病阳性的转心理科，干扰重的积极干预，神经病理阳性的换用对应药物。工具不是给科研凑数的，是用来决定下一步方案的。
在临床决策中，ID Pain 阳性（≥1 分）应触发“神经病理疼痛路径”：首先排除继发性病因（如肿瘤压迫、感染、代谢紊乱），随后结合神经系统定位体征与辅助检查明确诊断。若 ID Pain 与 BPI 高干扰评分并存，提示疼痛已引发显著功能残疾，需启动多模式联合治疗；若与 PHQ-9/GAD-7 共病阳性，应优先处理情绪障碍，因抑郁/焦虑会显著降低镇痛药物疗效并放大中枢敏化。评估结果必须与患者共同解读，将抽象分数转化为“疼痛对行走/睡眠/工作的具体影响”，从而设定可量化的治疗目标（如 NRS 下降≥30% 或 BPI 干扰评分改善≥2 分）。

## 五、处理原则（药物与干预）
5 题快速自评
≥1 提示 NP 可能
适合初筛
不替代诊断
### 通用处理框架与用药要点（按类别）
按维度组合使用工具（强度 NRS/VAS、神经病理 ID Pain/DN4、干扰 BPI、情绪 PHQ-9/GAD-7、睡眠 PSQI），并在基线+随访复测以观察趋势。
用结果指导随访频率与目标：高干扰或共病阳性需积极干预与转介，避免仅看单次 NRS。
药物治疗遵循“阶梯化、个体化、靶向化”原则。一线药物包括钙通道α2-δ配体（加巴喷丁、普瑞巴林）、SNRIs（度洛西汀、文拉法辛）及 TCAs（阿米替林、去甲替林），其机制在于增强下行抑制通路、调节谷氨酸释放及稳定神经元膜电位。二线药物包括局部外用利多卡因贴剂或辣椒素高浓度贴剂，适用于局灶性 NP。阿片类药物在 NP 中疗效有限且风险较高，仅作为难治性疼痛的短期桥接或严格监管下的长期方案。非药物治疗与介入手段包括：脉冲射频调节背根神经节、脊髓电刺激（SCS）或周围神经刺激（PNS）、经颅磁刺激（rTMS）、认知行为疗法（CBT）及运动康复。治疗决策应基于 ID Pain 评分趋势与功能改善程度动态调整，实现“以功能恢复为导向”的精准镇痛。

## 六、非药物与康复
评估本身配合患者教育；结果用于制定个体化目标与随访计划，确保工具使用一致以便趋势比较。
教会患者正确自评，减少因误解导致的焦虑或过度关注数字。
非药物干预是慢性疼痛管理的基石。物理治疗应聚焦于神经肌肉控制训练、渐进性抗阻运动与有氧耐力训练，以改善局部血流、促进神经营养因子释放并逆转中枢敏化。心理康复引入接纳承诺疗法（ACT）与疼痛神经科学教育（PNE），帮助患者重构对疼痛的认知图式，降低灾难化思维与恐惧回避行为。睡眠障碍管理需结合睡眠卫生教育、光照疗法及必要时短期使用具有镇静作用的镇痛药（如米氮平、曲唑酮）。康复计划应与 ID Pain 及 BPI 评分挂钩，设定阶段性里程碑（如“疼痛可控前提下恢复每日步行 30 分钟”）。多学科疼痛门诊（MDT）模式整合康复医师、心理治疗师、营养师与社工，确保非药物干预的系统性与可持续性。

## 七、随访与监测要点
基线 + 随访复测
慢性疼痛随访需建立标准化监测节点：初治期每 2-4 周复评一次，重点观察药物耐受性、ID Pain 趋势及不良反应；稳定期每 3-6 个月复评，侧重功能恢复与生活质量。随访内容应涵盖：疼痛强度与性质演变、ID Pain/DN4 评分变化、BPI 干扰维度、PHQ-9/GAD-7 情绪筛查、PSQI 睡眠评估及肝肾功能/血常规（尤其使用 TCAs/SNRIs 或 AEDs 时）。PainSmart 系统支持移动端自动推送量表，患者居家填写后数据实时同步至临床端，生成趋势折线图与风险预警。随访决策应遵循“达标治疗（Treat-to-Target）”原则：若连续 2 次复测 ID Pain 无改善且 NRS 下降<30%，需重新评估诊断准确性、调整药物剂量/种类或升级介入/心理干预；若评分波动但功能改善，可维持当前方案并强化自我管理。

## 八、预警与转诊指征
阳性需进一步评估
临床预警指征是保障患者安全与避免延误诊治的关键。出现以下情况应立即启动升级评估或转诊：① 神经系统体征进行性加重（如肌力下降、病理征阳性、括约肌功能障碍）；② ID Pain 评分短期内急剧升高伴疼痛性质改变（提示新发病变或并发症）；③ BPI 干扰评分≥7 分且伴随显著社会功能退缩或自杀意念；④ 常规药物联合治疗 8-12 周无效，或出现严重不良反应（如肝酶升高、心律失常、嗜睡跌倒风险）；⑤ 怀疑恶性肿瘤骨转移、感染、自身免疫性神经病或脊髓压迫。转诊路径应明确：神经内科/神经外科（结构性病变）、精神心理科（共病抑郁焦虑/创伤后应激）、康复医学科（功能重建）、疼痛介入科（神经阻滞/神经调控）及姑息治疗科（终末期疼痛管理）。预警机制应与 PainSmart 系统的自动化阈值报警联动，实现早期干预。

## 九、患者教育与自我管理
教会患者正确使用量表与疼痛日记；理解分数意义以便医患沟通。
鼓励如实记录，便于随访调整；避免为“好看”而低报或过度关注数字。
患者教育是提升治疗依从性与长期预后的核心环节。应通过可视化图表与通俗语言讲解疼痛的神经生物学机制，破除“疼痛=组织损伤”的误区，降低疾病恐惧。指导患者规范填写疼痛日记与 ID Pain 量表，强调“如实记录优于完美分数”，避免因迎合医生期望而低报疼痛或夸大症状。自我管理策略包括：疼痛分级应对计划（轻度时运动放松，中度时药物干预，重度时休息与求助）、正念呼吸与渐进性肌肉放松训练、活动节律管理（Pacing 技术）及家庭支持系统建设。医患共同决策（Shared Decision Making）贯穿始终，将量表结果转化为患者可理解的健康目标，增强自我效能感。长期随访中，定期回顾 ID Pain 趋势与功能改善，强化正向行为反馈，最终实现从“被动镇痛”向“主动康复”的转变。

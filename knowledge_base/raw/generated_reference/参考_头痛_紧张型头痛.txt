# 紧张型头痛

## 一、概述
紧张型头痛（Tension-Type Headache, TTH）是临床最常见的原发性头痛疾病，约占头痛专科门诊就诊量的40%~50%。其典型临床特征为双侧、压迫样或紧箍样轻中度头痛，病程可持续30分钟至数天不等。头痛强度通常不足以妨碍日常活动，无进行性加重趋势，且一般不伴有恶心或呕吐。疼痛的发生与头颈部肌肉持续收缩、精神应激及中枢痛觉调制功能异常密切相关。根据国际头痛疾病分类第三版（ICHD-3）标准，TTH明确分为发作性（每月发作<15天）与慢性（每月发作≥15天，持续>3个月）两型。慢性TTH常与焦虑、抑郁、睡眠障碍及药物过度使用形成恶性循环，显著降低患者生活质量与工作能力，需纳入慢性疼痛管理体系进行规范化、个体化干预。

## 二、病理生理机制
头痛分为原发与继发。原发性（偏头痛、紧张型、丛集性）与神经血管调节异常、皮质扩散性抑制、头颈肌持续收缩及遗传易感性相关。偏头痛涉及三叉神经血管系统激活与 CGRP 释放；紧张型头痛以肌紧张与中枢敏化为主；丛集性头痛具周期性自主神经症状。规律、过量使用急性镇痛药可转化为药物过度使用性头痛（MOH），需警惕“反跳性”每日头痛。

**病理机制深度解析：**
1. **外周机制**：头颈部浅表与深层肌肉（如颞肌、咬肌、斜方肌、头半棘肌）持续等长收缩导致局部微循环障碍，乳酸、缓激肽、前列腺素等致痛代谢产物堆积，刺激肌筋膜伤害性感受器。部分患者存在肌筋膜触发点（Trigger Points），按压可诱发特征性牵涉痛。
2. **中枢机制**：核心病理在于下行痛觉抑制通路（涉及中脑导水管周围灰质、延髓头端腹内侧区、蓝斑、中缝核）功能减退，5-羟色胺与去甲肾上腺素能神经传递失衡。长期应激或睡眠剥夺可导致三叉颈复合体（TCC）中枢敏化，痛阈降低，轻微刺激即可引发广泛性头痛。
3. **神经化学与影像学研究**：TTH患者脑脊液及血浆中P物质、谷氨酸水平常升高，CGRP释放程度显著低于偏头痛。fMRI显示前扣带回、岛叶、丘脑及前额叶皮层在疼痛发作期及静息态下存在功能连接异常，提示中枢痛觉调制网络重塑。
4. **遗传与环境交互**：多基因易感性（涉及5-HTTLPR、COMT等位点）与环境应激、不良姿势、颞下颌关节紊乱、心理共病共同构成“生物-心理-社会”致病模型。

## 三、临床评估与筛查
记录头痛日记（频率、时长、部位、性质、伴随症状、诱因与急性用药），识别警示征象（突发雷击样、发热、神经体征、妊娠）。必要时行头颅影像（CT/MRI）排除继发性病因（出血、肿瘤、静脉窦血栓）；HIT-6 等评估失能程度，指导预防用药。重点排查药物过度使用性头痛：当每月急性药使用天数过多且头痛呈每日/近乎每日时需警惕反跳。

**标准化评估流程：**
1. **病史采集与ICHD-3诊断标准核对**：明确头痛部位（双侧为主）、性质（压迫/紧箍）、强度（轻中度，VAS/NRS 3-5分）、持续时间（30分钟-7天）、加重因素（日常活动不加重）、伴随症状（可有畏光或畏声，但不同时具备恶心呕吐）。严格区分发作性与慢性分型。
2. **头痛日记规范化记录**：建议患者连续记录4-8周，涵盖发作日期、起止时间、疼痛评分、伴随症状、可能诱因（压力、睡眠、饮食、月经）、急性药物名称/剂量/服用时间/疗效。为后续疗效评估与MOH筛查提供客观依据。
3. **量表与功能评估**：使用HIT-6（头痛影响问卷）或MIDAS（弥散性残疾评估量表）量化失能程度；同步筛查PHQ-9（抑郁）、GAD-7（焦虑）、PSQI（睡眠质量），识别共病对头痛的维持作用。
4. **警示征象筛查（SNOOP4原则）**：系统性症状（发热、体重下降、感染）、神经系统体征（局灶性缺损、脑膜刺激征）、起病特征（突发雷击样、进行性加重）、其他高危因素（年龄>50岁新发、妊娠/产褥期、免疫抑制、肿瘤史、创伤史）。
5. **辅助检查指征**：TTH为临床诊断，无特异性实验室或影像学标志物。仅当存在警示征象、神经系统查体异常、头痛模式发生显著改变或常规治疗无效时，才建议行头颅MRI/MRA/MRV或腰穿，以排除继发性病因（颅内占位、静脉窦血栓、蛛网膜下腔出血、巨细胞动脉炎等）。

## 四、专家诊疗思路（按类别）
头痛患者最怕被当成“没病”或“矫情”。原发性头痛以偏头痛、紧张型、丛集性为主，我的评估重在鉴别继发性——突发雷击样、发热、神经定位体征、妊娠相关剧变者必须影像。偏头痛管理分两层：急性期 NSAIDs/曲普坦/gepant 尽早用，避免空腹与强光；预防用药在每月发作≥4 次或明显失能时启动，β阻滞剂、抗癫痫药、CGRP 单抗都是可选。最容易被忽视的是药物过度使用性头痛——患者因频繁头痛而天天吃止痛药，反而陷入每日头痛。我会明确要求患者建立头痛日记、限制急性药使用天数，并配合规律作息与放松训练。丛集性头痛急性期高流量吸氧+曲普坦、预防用维拉帕米，效果明确。

**临床决策路径：**
1. **共情与疾病认知重建**：首诊即明确告知患者TTH为明确的神经系统疾病，非“心理作用”或“体质差”，消除病耻感，建立治疗同盟。
2. **鉴别诊断与分型**：重点与偏头痛鉴别（TTH无搏动性、无中重度活动加重、无显著胃肠道症状）；与丛集性头痛鉴别（TTH无单侧眼眶痛及自主神经症状）。注意“混合性头痛”（TTH与偏头痛共存）的识别，治疗策略需兼顾。
3. **MOH专项排查**：每月使用单纯镇痛药≥15天、复方镇痛药/曲普坦/阿片类≥10天，持续>3个月，且头痛频率进行性增加，高度提示MOH。需立即启动药物撤除计划，并桥接预防治疗。
4. **共病驱动因素管理**：TTH极少孤立存在。睡眠呼吸暂停、颞下颌关节紊乱、颈源性疼痛、广泛性焦虑/抑郁是核心维持因素。必须多学科协作，同步干预，否则单一镇痛治疗极易失败。
5. **阶梯化治疗决策**：发作性TTH以急性对症治疗+生活方式干预为主；慢性TTH或每月发作≥4次且影响生活者，必须启动预防性治疗。治疗目标非“完全无痛”，而是“发作频率下降≥50%、失能程度减轻、恢复正常社会功能”。

## 五、处理原则（药物与干预）
放松与运动有效
NSAID 短期对症
阿米替林用于慢性
管理焦虑与睡眠
### 通用处理框架与用药要点（按类别）
偏头痛急性期用 NSAIDs、曲普坦或 gepant；频繁发作者（每月≥4 次或明显失能）考虑预防：β受体阻滞剂、抗癫痫药、CGRP 单抗等，并记录头痛日记评估反应。紧张型头痛以放松、运动与阿米替林（慢性）为主；丛集性头痛急性发作用高流量吸氧、曲普坦，预防用维拉帕米。警惕并避免药物过度使用性头痛：规律、过量使用急性镇痛药会转化为每日头痛，处理以停用过度药物+预防桥接为主。

**规范化干预方案：**
1. **急性期对症治疗**：首选NSAIDs（布洛芬400mg、萘普生500mg、双氯芬酸50mg）或对乙酰氨基酚（1000mg）。强调“早期足量”原则，头痛初起（VAS≥3分）时立即服用。严禁频繁使用含咖啡因复方制剂、阿片类或曲普坦类药物（TTH对曲普坦无效且易诱发MOH）。急性药物使用频率严格限制：单纯镇痛药≤15天/月，复方/曲普坦≤10天/月。
2. **预防性药物治疗**：慢性TTH或高频率发作性TTH的一线首选为三环类抗抑郁药（TCA），尤以阿米替林为代表。起始10-12.5mg qn，每1-2周递增10-25mg，目标剂量50-100mg/d。需监测心电图（QT间期）、抗胆碱能副作用及体重变化。二线可选文拉法辛（SNRI）、米氮平、氟桂利嗪或托吡酯。治疗起效需4-8周，有效后维持6-12个月再缓慢减量。
3. **介入与物理治疗**：
   - **触发点注射**：局部浸润利多卡因或联合小剂量糖皮质激素，快速缓解肌筋膜疼痛，适用于局限性压痛明显者。
   - **神经阻滞**：枕大神经、眶上神经或星状神经节阻滞，适用于颈源性成分突出或急性发作期桥接治疗。
   - **肉毒毒素A**：目前指南未常规推荐用于TTH，但对部分合并肌张力异常、对传统预防治疗无效的难治性慢性TTH可尝试超说明书应用。
   - **针灸与干针**：多项RCT证实特定穴位针刺可显著降低头痛频率，机制与调节内源性阿片肽及局部血流相关。
4. **共病与MOH管理**：焦虑抑郁共病者优先选用兼具镇痛与抗焦虑作用的药物（如文拉法辛、阿米替林）；睡眠障碍者强化睡眠卫生或短期使用非苯二氮卓类助眠药；MOH患者必须制定阶梯撤药计划，可短期桥接NSAIDs、糖皮质激素或预防药物，配合认知行为干预。

## 六、非药物与康复
规律作息、压力管理与触发因素规避；放松训练与有氧运动具预防价值，偏头痛可考虑生物反馈。建立“不滥用急性药”的自我管理习惯，记录并减少诱因暴露。

**多维康复体系：**
1. **物理治疗与姿势矫正**：针对长期伏案、低头手机族，开展颈椎深层屈肌强化、胸椎灵活性训练、肩胛稳定肌群激活。纠正头前倾、圆肩等不良姿势，减轻枕下肌群代偿性紧张。
2. **放松与神经调节训练**：渐进性肌肉放松训练（PMR）、腹式呼吸、正念冥想（MBSR）可显著降低交感神经张力，提升痛阈。肌电生物反馈（EMG-BF）指导患者实时监测颞肌/斜方肌电活动，学习自主降低肌肉紧张度，临床证据等级高。
3. **有氧运动处方**：每周3-5次、每次30-45分钟的中等强度有氧运动（快走、游泳、骑行），促进内啡肽释放，改善脑血流与睡眠结构。强调“循序渐进、避免过度疲劳诱发头痛”。
4. **认知行为疗法（CBT）**：针对灾难化思维、疾病焦虑、回避行为进行认知重构，教授疼痛应对技巧（Pacing策略、分心技术、问题解决训练），显著降低慢性头痛失能率。
5. **职业与生活环境优化**：人体工学工作站评估（屏幕高度、座椅支撑、键盘位置）、定时微休息（每45分钟起身活动颈肩）、减少强光/噪音/刺鼻气味暴露。

## 七、随访与监测要点

应激水平
睡眠
**结构化随访路径：**
1. **随访节奏**：初始治疗期每2-4周随访1次（评估急性药使用、副作用、依从性）；预防治疗稳定期每1-3个月随访1次；长期维持期每3-6个月随访1次。
2. **核心监测指标**：
   - **头痛负荷**：头痛日记回顾，计算月均发作天数、平均持续时间、VAS/NRS评分变化。
   - **功能恢复**：HIT-6或MIDAS评分改善≥30%视为临床有效；PHQ-9/GAD-7/PSQI追踪共病状态。
   - **用药安全**：严格核查急性药物使用频率，防范MOH复发；监测预防药物肝肾功能、心电图、代谢指标。
3. **疗效判定与方案调整**：若规范预防治疗8-12周后发作频率减少<50%或失能无改善，需重新评估诊断准确性、共病控制情况、依从性及药物血药浓度/代谢表型。可考虑换用二线预防药物、联合非药物干预或转诊疼痛专科/神经心理科。
4. **停药指征**：连续6个月头痛频率稳定在基线50%以下、功能恢复正常、共病控制良好，方可尝试每1-2个月递减预防药物剂量，全程密切监测反跳。

## 八、预警与转诊指征
新发持续加重头痛需影像
**明确转诊红线：**
1. **继发性头痛警示征象（SNOOP4）**：年龄>50岁新发头痛；突发雷击样或进行性加重头痛；伴发热、盗汗、体重下降；出现局灶性神经系统体征（偏瘫、失语、视野缺损、共济失调）；视乳头水肿；头痛与体位/咳嗽/Valsalva动作明确相关；妊娠或产褥期新发剧烈头痛；免疫抑制或恶性肿瘤病史者新发头痛。出现任一征象需立即行头颅影像学及必要实验室检查，排除卒中、感染、占位、静脉血栓、巨细胞动脉炎等危急重症。
2. **专科转诊指征**：
   - **神经内科/头痛专科**：诊断不明确、混合性头痛难辨、疑似MOH需专业撤药管理、常规预防治疗失败≥2种方案。
   - **疼痛科/介入科**：需实施枕神经阻滞、触发点注射、脊髓电刺激（SCS）或经皮神经电刺激（TENS）等高级干预。
   - **精神心理科**：重度抑郁/焦虑障碍、创伤后应激障碍（PTSD）、物质滥用、CBT或药物治疗无效者。
   - **康复医学科/口腔科**：明确颈源性疼痛主导、颞下颌关节紊乱病（TMD）、严重睡眠呼吸暂停（需CPAP治疗）。

## 九、患者教育与自我管理
记录诱因、规律用药不滥用；急性发作尽早处理，固定作息减少发作。出现警示征象（雷击样、发热、神经体征、妊娠相关剧变）及时就医，不盲目家用强效药。
**赋能型自我管理方案：**
1. **疾病认知教育**：明确TTH为慢性复发性疾病，治疗目标是“控制而非根治”。打破“头痛即需强效止痛”的误区，理解预防药物需长期规律服用方能重塑中枢痛阈。
2. **用药安全铁律**：严格区分急性对症药与预防维持药。急性药“早用、足量、限频”；预防药“小量起始、缓慢滴定、足疗程”。绝不自行叠加多种镇痛药或频繁更换处方。
3. **触发因素图谱构建**：通过头痛日记识别个人特异性诱因（如特定食物、月经周期、屏幕蓝光、信息过载、肌肉劳损）。制定个性化规避策略，建立“压力-睡眠-疼痛”平衡三角。
4. **数字化工具应用**：推荐使用经临床验证的头痛管理APP或可穿戴设备，自动记录发作节律、提醒用药、生成月度趋势报告，便于医患共同决策。
5. **应急与就医指南**：掌握家庭急救包配置（常规NSAIDs、温水、暗室休息指引）。明确急诊指征：头痛性质突变、伴随呕吐/意识障碍/肢体无力/高热、外伤后头痛、孕期新发剧痛。出现警示征象立即拨打急救电话或前往急诊，切勿自行服用强效镇痛药掩盖病情。
6. **社会支持与长期随访**：鼓励加入慢性头痛患者互助小组，分享应对经验。强调定期复诊的重要性，即使症状缓解也需按医嘱逐步减量，防止隐匿性复发。医患共同制定个性化“头痛行动计划（Headache Action Plan）”，提升自我效能感。

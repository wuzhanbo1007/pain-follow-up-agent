# 慢性每日头痛

类别：头痛

## 一、概述
慢性每日头痛（Chronic Daily Headache, CDH）并非单一疾病实体，而是根据国际头痛疾病分类第三版（ICHD-3）定义的一组以高频次头痛为特征的临床综合征。其核心诊断标准为：每月头痛发作天数≥15天，且病程持续≥3个月。CDH在普通人群中的患病率约为1%~4%，女性显著高于男性，常始于青少年或青年期，具有明显的慢性化与致残倾向。
临床实践中，CDH主要分为原发性与继发性两大类。原发性CDH包括慢性偏头痛（CM）、慢性紧张型头痛（CTTH）、新发每日持续性头痛（NDPH）及半侧持续头痛（HC）；继发性CDH则涵盖颅内病变（肿瘤、静脉窦血栓、自发性颅内低压）、颅颈交界区结构异常、药物过度使用性头痛（MOH）、全身性疾病（如高血压、睡眠呼吸暂停、颞动脉炎）及精神心理障碍所致头痛。CDH的慢性化常伴随中枢敏化与下行疼痛调制通路功能失调，形成“疼痛-睡眠障碍-情绪异常-功能受损”的恶性循环。早期识别、精准分型与多学科干预是阻断疾病进展、改善预后的关键。

## 二、病理生理机制
头痛的病理生理机制复杂，涉及外周伤害性感受器激活、中枢神经传导通路异常及高级皮层调制功能紊乱。
1. **原发性头痛机制**：
   - **偏头痛**：核心为三叉神经血管系统（Trigeminal Vascular System, TVS）异常激活。皮层扩散性抑制（CSD）作为先兆的神经电生理基础，触发硬脑膜血管扩张与无菌性炎症，释放降钙素基因相关肽（CGRP）、P物质、神经激肽A等神经肽，导致血管通透性增加与神经源性炎症。CGRP作为关键致病介质，直接作用于三叉神经节与脑干孤束核，放大痛觉信号。
   - **紧张型头痛**：传统认为以头颈部肌筋膜持续收缩与缺血为主，现代观点强调中枢敏化（Central Sensitization）的核心地位。外周伤害性输入反复激活脊髓背角与三叉神经颈复合体（TNC），导致NMDA受体磷酸化、突触可塑性改变及痛阈降低。同时，内源性下行抑制通路（如5-HT、去甲肾上腺素能系统）功能减退，使正常非痛刺激被感知为疼痛。
   - **丛集性头痛**：具有高度特异性，与下丘脑背内侧核的节律性异常放电密切相关。激活三叉神经-自主神经反射弧，导致同侧泪腺、鼻黏膜血管扩张与腺体分泌亢进，表现为典型的自主神经症状。
2. **药物过度使用性头痛（MOH）机制**：长期、规律性使用急性镇痛药（如曲普坦类、阿片类、复方镇痛药、麦角胺）可破坏中枢痛觉调制平衡。机制涉及阿片受体下调、5-HT2B受体脱敏、下丘脑-垂体-肾上腺轴功能紊乱及CGRP系统代偿性上调，导致“反跳性”头痛阈值显著降低，形成药物依赖与头痛慢性化的正反馈循环。
3. **遗传与表观遗传因素**：偏头痛具有多基因遗传倾向（如CACNA1A、ATP1A2、SCN1A基因突变与家族性偏瘫性偏头痛相关），全基因组关联研究（GWAS）已鉴定出数十个易感位点。表观遗传修饰（DNA甲基化、非编码RNA）在环境触发与基因表达交互中发挥重要作用。

## 三、临床评估与筛查
规范的临床评估是CDH精准管理的基石，需遵循“排除继发性、明确原发性、评估共病与失能”的原则。
1. **病史采集与体格检查**：采用结构化问诊（如SOCRATES或OPQRST模式），详细记录头痛部位、性质、强度、持续时间、发作频率、伴随症状（恶心、呕吐、畏光、畏声、自主神经症状）、诱因（压力、睡眠、饮食、激素波动、天气）及缓解因素。全面神经系统查体，重点排查脑膜刺激征、视乳头水肿、颅神经 deficits、颈项强直及肌筋膜压痛点。
2. **红旗征象（SNOOP4/5）筛查**：必须高度警惕继发性头痛。警示征象包括：Systemic（发热、体重下降、恶性肿瘤史）、Neurologic（局灶性神经体征、认知改变、癫痫）、Onset（突发雷击样头痛，1分钟内达峰值）、Older（>50岁新发头痛）、Pattern（头痛模式发生显著改变）、Pregnancy（妊娠期或产褥期新发剧痛）、Precipitated（Valsalva动作、咳嗽、性交诱发）、Papilledema（视乳头水肿）、Positional（体位性头痛提示低颅压）、Progressive（进行性加重伴影像学占位效应）。
3. **辅助检查**：
   - **神经影像**：对存在红旗征象、神经系统查体异常、头痛模式突变或常规治疗无效者，首选头颅MRI（含增强）及MRV/MRA，排除脑肿瘤、静脉窦血栓、颈动脉/椎动脉夹层、正常压力脑积水及Chiari畸形。CT仅用于急诊排除急性出血。
   - **实验室检查**：根据临床怀疑行ESR、CRP（排查巨细胞动脉炎）、TSH、血常规、电解质、自身抗体谱等。
   - **量表评估**：头痛日记（金标准）、HIT-6（头痛影响问卷）、MIDAS（弥散性头痛失能筛查）、PHQ-9/GAD-7（抑郁焦虑筛查）、PGIC（整体印象改善评分）及VAS/NRS疼痛评分，量化失能程度与治疗反应。
4. **药物过度使用性头痛（MOH）专项评估**：严格依据ICHD-3标准，若患者每月使用曲普坦/麦角胺≥10天，或NSAIDs/复方镇痛药/阿片类≥15天，持续>3个月，且头痛频率进行性增加，应高度怀疑MOH。需与慢性偏头痛或慢性紧张型头痛进行鉴别诊断。

## 四、专家诊疗思路（按类别）
慢性头痛患者常因长期病痛产生病耻感、焦虑或“被忽视”体验。临床诊疗需摒弃“头痛即止痛”的线性思维，转向生物-心理-社会医学模式，强调精准分型与个体化阶梯管理。
1. **鉴别诊断优先**：原发性头痛的诊断是“阳性诊断”而非“排除诊断”。面对每日头痛患者，首要任务是排除继发性病因。对突发雷击样、伴发热/颈强直、出现局灶神经体征、妊娠期剧变或影像学异常者，必须立即启动神经影像与专科会诊流程，严禁盲目经验性镇痛。
2. **慢性偏头痛（CM）管理**：CM的核心是发作频率慢性化与中枢敏化。急性期治疗强调“尽早干预”，在疼痛轻度至中度时即使用NSAIDs、曲普坦或新型CGRP受体拮抗剂（Gepants），避免空腹服药及暴露于强光/噪音环境。预防治疗是阻断慢性化的关键，指征为每月发作≥4天、急性药物无效或存在MOH风险。一线预防药物包括β受体阻滞剂（普萘洛尔、美托洛尔）、抗癫痫药（托吡酯、丙戊酸钠）、三环类抗抑郁药（阿米替林）及CGRP单克隆抗体（依瑞奈尤单抗、夫瑞奈尤单抗等）。肉毒毒素A（Botox）皮下多点注射对CM具有明确循证依据，需每12周规范重复。
3. **慢性紧张型头痛（CTTH）管理**：CTTH常与颈源性疼痛、肌筋膜触发点及睡眠障碍交织。治疗重心在于打破中枢敏化与肌肉紧张循环。急性期避免频繁使用镇痛药，预防首选阿米替林或文拉法辛，联合物理治疗（颈椎松动术、姿势矫正、肌筋膜释放）。认知行为疗法（CBT）对改善疼痛灾难化思维与功能恢复至关重要。
4. **新发每日持续性头痛（NDPH）与半侧持续头痛（HC）**：NDPH起病急骤，24小时内达峰值并持续存在，常与病毒感染、重大应激或激素变化相关，治疗反应较差，需长期预防管理。HC为单侧持续性头痛伴自主神经症状，对吲哚美辛呈绝对性、特异性缓解，该反应本身即为诊断标准。
5. **共病管理**：CDH患者常合并失眠、焦虑、抑郁、纤维肌痛或肠易激综合征。情绪障碍不仅是共病，更是头痛慢性化的独立危险因素。需同步进行精神心理评估，必要时联合使用SNRIs或SSRIs，并引入正念减压（MBSR）与接纳承诺疗法（ACT）。

## 五、处理原则（药物与干预）
CDH的药物治疗需遵循“急性期对症、预防期治本、干预期突破、共病期协同”的原则，严格规避MOH风险。
1. **急性期治疗**：
   - **NSAIDs**：布洛芬、萘普生、双氯芬酸等，适用于轻中度头痛。注意胃肠道与心血管风险，建议餐后服用。
   - **曲普坦类**：舒马曲普坦、佐米曲普坦、利扎曲普坦等，特异性激动5-HT1B/1D受体，收缩扩张血管并抑制三叉神经肽释放。禁用于缺血性心脏病、未控制高血压及偏瘫性偏头痛。
   - **新型靶向药物**：Gepants（瑞美吉潘、乌布吉潘）与Ditans（拉司米坦）不收缩血管，适用于心血管高危或曲普坦禁忌者。拉司米坦具5-HT1F激动活性，可能致嗜睡，服药后8小时内禁止驾驶。
2. **预防性治疗**：
   - **口服药物**：β受体阻滞剂（普萘洛尔40-160mg/d）、抗癫痫药（托吡酯起始25mg/d渐增至50-100mg/d，注意认知副作用与肾结石风险；丙戊酸钠育龄期女性慎用）、抗抑郁药（阿米替林10-75mg/d睡前服，改善睡眠与疼痛阈值；文拉法辛75-225mg/d）。钙通道阻滞剂（氟桂利嗪5-10mg/d，注意锥体外系反应与抑郁风险）。
   - **生物制剂**：CGRP单抗（依瑞奈尤单抗、伽奈珠单抗、弗瑞奈珠单抗、埃普奈珠单抗）每月或每季度皮下/静脉注射，靶向阻断CGRP通路，对难治性CM疗效显著且安全性良好。
   - **肉毒毒素A**：针对CM，于额肌、颞肌、枕肌、颈夹肌等31个位点各注射5U，每12周一次，可显著降低头痛天数。
3. **药物过度使用性头痛（MOH）专项处理**：
   - **停药策略**：推荐逐渐减量（2-4周内）或突然停用过度使用的急性药物。突然停药初期可能出现1-2周“戒断期”头痛加重，属正常病理生理过程。
   - **桥接治疗**：为缓解戒断症状，可短期使用NSAIDs（如萘普生500mg bid）、糖皮质激素（泼尼松40-60mg/d渐减）、止吐药（甲氧氯普胺）或短效曲普坦。同时尽早启动或优化预防性药物，以平稳过渡。
   - **监测**：停药后需严格限制急性药使用（≤10天/月），配合头痛日记追踪，通常4-8周后头痛频率可显著下降。
4. **介入与神经调控治疗**：
   - **神经阻滞**：枕大/枕小神经阻滞、三叉神经分支阻滞、翼腭神经节阻滞，适用于局灶性疼痛或作为桥接治疗。
   - **无创神经调控**：Cefaly（经皮眶上神经刺激）、gammaCore（迷走神经刺激）、Relivion（三叉神经刺激），通过调节皮层兴奋性与下行抑制通路减少发作频率，适合药物不耐受或预防需求者。
   - **难治性病例**：可考虑脊髓电刺激（SCS）或深部脑刺激（DBS，严格限于临床试验）。

### 通用处理框架与用药要点（按类别）
- **偏头痛**：急性期NSAIDs/曲普坦/Gepants尽早足量；预防期每月≥4天或失能即启动，优选β阻滞剂、托吡酯、阿米替林或CGRP单抗。Botox用于CM。严格记录头痛日记评估疗效。
- **紧张型头痛**：以物理康复、姿势矫正、阿米替林/文拉法辛预防为主；急性期避免频繁镇痛。重点处理颈源性触发点与睡眠障碍。
- **丛集性头痛**：急性期高流量纯氧（12-15L/min，15分钟）+皮下注射舒马曲普坦；预防期维拉帕米（起始80mg tid，渐增至最大480mg/d，需监测心电图）或托吡酯。锂剂与CGRP单抗为二线选择。
- **MOH管理**：核心为停用过度药物+预防桥接。急性药使用天数必须控制在安全阈值内（曲普坦/复方药≤10天/月，单纯NSAIDs≤15天/月）。
- **共病处理**：同步筛查并治疗失眠、焦虑抑郁。SSRIs/SNRIs可改善情绪与疼痛共病。避免使用含巴比妥类或阿片类的复方镇痛药。

## 六、非药物与康复
非药物干预是CDH长期管理的支柱，旨在重塑神经可塑性、改善功能状态并降低复发率。
1. **心理行为干预**：认知行为疗法（CBT）是循证等级最高的非药物疗法，通过识别并重构“疼痛灾难化”思维、建立适应性应对策略、进行暴露与反应预防，显著降低头痛频率与失能程度。正念减压疗法（MBSR）与接纳承诺疗法（ACT）有助于提升疼痛耐受度与生活质量。
2. **物理治疗与康复训练**：针对颈源性成分，开展颈椎关节松动术、深层颈屈肌强化训练、肩胛带稳定性训练及肌筋膜触发点干针/按压治疗。纠正不良姿势（如“手机颈”、“电脑颈”），优化人体工学工作环境。
3. **运动处方**：规律的有氧运动（快走、游泳、骑行，每周≥150分钟中等强度）可促进内源性阿片肽与脑源性神经营养因子（BDNF）释放，下调中枢敏化。建议从低强度开始，循序渐进，避免过度疲劳诱发头痛。
4. **睡眠卫生与节律管理**：建立固定作息，保证7-9小时高质量睡眠。避免睡前屏幕暴露、咖啡因摄入及剧烈运动。对合并阻塞性睡眠呼吸暂停（OSA）者，强制进行多导睡眠图（PSG）检查并规范使用CPAP治疗。
5. **生物反馈与神经调控设备**：肌电生物反馈（EMG-BF）训练患者识别并放松头颈部过度收缩肌肉；温度生物反馈改善血管舒缩功能。家用无创神经调控设备（如Cefaly、gammaCore）可作为药物辅助，通过经皮电刺激调节三叉神经或迷走神经通路。
6. **生活方式与饮食调整**：识别并规避个体化诱因（如酒精、陈年奶酪、味精、腌制食品、强光、异味、天气骤变）。保持充足水分摄入（每日≥2L），规律进餐避免低血糖。部分患者可尝试补充镁剂（400-600mg/d）、核黄素（维生素B2，400mg/d）或辅酶Q10，证据等级中等，安全性高。

## 七、随访与监测要点
CDH为慢性复发性疾病，需建立结构化、数据驱动的长期随访体系（建议每1-3个月初期随访，稳定后每3-6个月）。
1. **核心监测指标**：
   - **头痛负荷**：通过PainSmart数字随访系统或纸质头痛日记，追踪每月头痛天数、急性药使用天数、疼痛强度（NRS/VAS）、持续时间及先兆变化。
   - **功能与失能**：定期复测HIT-6与MIDAS量表，评估工作、社交及家庭功能恢复情况。治疗有效标准通常为头痛天数减少≥50%或MIDAS评分下降≥3分。
   - **药物安全性**：监测预防药物的不良反应（如托吡酯的认知迟钝、丙戊酸的肝功/体重变化、β阻滞剂的心率/血压、阿米替林的抗胆碱能效应）。严格核查急性药使用频率，预警MOH复发。
   - **共病筛查**：每次随访常规使用PHQ-9、GAD-7及PSQI（匹兹堡睡眠质量指数）评估情绪与睡眠状态，及时调整综合治疗方案。
2. **疗效评估与方案调整**：若预防治疗8-12周后无效（头痛天数减少<30%），需重新评估诊断准确性、依从性、诱因控制及共病管理。可考虑剂量滴定、药物轮换、联合用药或升级至CGRP单抗/肉毒毒素/神经调控。建立“治疗-评估-调整”闭环，避免无效长期用药。
3. **数字化随访管理**：利用PainSmart系统实现远程数据上传、AI趋势分析、用药提醒与预警推送。系统可自动生成月度报告，辅助医生快速识别恶化趋势，实现精准干预。

## 八、预警与转诊指征
CDH患者出现以下情况时，必须立即启动预警机制并转诊至神经内科、神经外科或疼痛科多学科团队（MDT）：
1. **红旗征象出现**：突发雷击样头痛、进行性加重伴呕吐/视物模糊、新发局灶性神经功能缺损（偏瘫、失语、共济失调）、发热伴颈强直、视乳头水肿、头部外伤后头痛、妊娠期或产褥期新发剧痛、>50岁新发头痛伴颞动脉压痛或ESR显著升高。
2. **难治性与复杂性病例**：经过≥2种规范预防药物足量足疗程治疗仍无效；合并严重药物过度使用性头痛需住院 detox 治疗；疑似颅内静脉窦血栓、自发性颅内低压、正常压力脑积水、巨细胞动脉炎或脑肿瘤等继发性病因。
3. **功能严重受损或精神危机**：MIDAS评分极重度（≥21分），社会功能完全丧失；合并重度抑郁、焦虑障碍、自杀意念或物质滥用；需高级介入治疗（如神经阻滞、神经调控、鞘内药物输注系统植入）或参与临床试验。
4. **特殊人群**：儿童/青少年CDH、老年首次发作、合并多系统自身免疫性疾病或妊娠/哺乳期头痛管理。

## 九、患者教育与自我管理
慢性头痛的管理是一场“马拉松”，患者从被动接受者转变为主动管理者是治疗成功的核心。
1. **疾病认知重塑**：破除“头痛是小事/矫情/忍忍就好”的错误观念，明确CDH是涉及神经血管与中枢调制的器质性疾病，需长期规范管理。强调预防性药物需每日规律服用以稳定神经阈值，而非“疼了才吃”。
2. **用药安全与MOH预防**：严格掌握急性药物使用红线（曲普坦/复方镇痛药≤10天/月，单纯NSAIDs≤15天/月）。教育患者识别“反跳性头痛”特征，建立“阶梯用药”习惯（轻度先试NSAIDs，中重度及时用特异性药物），绝不自行加量或联合多种镇痛药。
3. **诱因管理与日记记录**：指导患者规范填写头痛日记，记录发作时间、强度、伴随症状、可能诱因（睡眠、饮食、压力、天气、月经）及用药反应。通过数据回溯识别个人特异性触发因素，采取针对性规避策略，但避免过度焦虑导致“诱因恐惧”。
4. **应急行动计划**：制定书面版“头痛发作应对流程”：识别先兆/早期症状→立即停止当前活动→转移至安静暗室→按医嘱服用急性药物→必要时启动生物反馈/冷敷/放松训练→若2小时未缓解或出现红旗征，立即就医。
5. **心理支持与社群赋能**：鼓励患者加入正规患者支持团体，分享管理经验，减轻病耻感。推荐家属参与健康教育，构建支持性家庭环境。强调“带痛生活”而非“无痛生活”的目标设定，聚焦功能恢复与生活质量提升。
6. **数字化工具应用**：熟练使用PainSmart随访系统或官方推荐APP，实现用药提醒、日记打卡、数据同步与在线问诊。利用系统推送的个性化健康教育内容（如睡眠卫生视频、放松训练音频、饮食指南）进行日常自我管理。定期复诊前整理数据，提高医患沟通效率。

# 子宫内膜异位症疼痛

类别：内脏痛/慢性盆腔痛

## 一、概述
子宫内膜异位症（Endometriosis, EMS）是指具有生长功能的子宫内膜组织（腺体和间质）出现在子宫体被内膜所覆膜以外的其他部位。其核心临床三联征为进行性加重的痛经、性交痛与慢性盆腔痛（CPP），常合并不孕及盆腔无菌性炎症反应。疼痛呈周期性或持续性，严重影响患者生活质量、心理健康及生育功能。作为典型的慢性内脏痛与神经病理性痛混合类型，其管理需遵循个体化、多学科协作（MDT）及长期随访原则，旨在控制疼痛、抑制病灶进展、保留或促进生育功能。

## 二、病理生理机制
子宫内膜异位症疼痛的发生机制复杂，是多因素交互作用的结果，主要包括：
1. **炎症与免疫微环境失衡**：异位内膜病灶持续分泌前列腺素（PGs，尤其是PGE2、PGF2α）、白介素（IL-1β、IL-6）、肿瘤坏死因子-α（TNF-α）等炎性介质，导致盆腔局部无菌性炎症、组织水肿及粘连形成。前列腺素直接刺激痛觉神经末梢并降低痛阈，引发内脏痛。
2. **神经新生（Neurogenesis）与神经病理性痛**：异位病灶周围及腹膜表面存在丰富的交感与副交感神经纤维增生。神经生长因子（NGF）、脑源性神经营养因子（BDNF）表达上调，促使感觉神经（如TRPV1、Nav1.7通道）侵入病灶，形成“疼痛-炎症-神经增生”恶性循环，导致痛觉超敏与异常性疼痛。
3. **中枢敏化与脑-肠/脑-盆轴失调**：长期慢性盆腔刺激导致脊髓背角及高位中枢神经元兴奋性增高，痛觉传导通路重塑。患者常出现内脏高敏感（Visceral Hypersensitivity），轻微牵拉或炎症即可引发剧烈疼痛。同时，伴随焦虑、抑郁等情绪障碍，进一步放大痛觉信号。
4. **激素依赖性**：病灶生长高度依赖雌激素（E2）。芳香化酶（Aromatase）在异位内膜中异常高表达，形成局部“雌激素自主合成”微环境，导致疼痛与月经周期密切相关。
5. **牵涉痛与解剖关联**：盆腔内脏痛经交感神经（T10-L2）和副交感神经（S2-S4）传入，定位模糊。深部浸润型内异症（DIE）累及宫骶韧带、直肠阴道隔、输尿管或膀胱时，可表现为腰骶部放射痛、排便痛、排尿痛，甚至下肢放射痛。

## 三、临床评估与筛查
全面评估是制定精准治疗方案的前提，需结合病史、体格检查、影像学及心理量表：
1. **病史采集**：详细记录疼痛起始时间、性质（钝痛、刺痛、绞痛）、程度（NRS评分）、与月经周期/排便/排尿/性交的明确关系。询问既往手术史、生育史、家族史及避孕方式。
2. **体格检查**：妇科双合诊/三合诊重点评估子宫活动度、后陷凹/宫骶韧带结节触痛、附件区包块压痛、直肠阴道隔硬结。注意有无盆腔压痛、肌筋膜触发点及盆底肌张力异常。
3. **辅助检查**：
   - **影像学**：经阴道超声（TVUS）为一线筛查工具，对卵巢子宫内膜异位囊肿（巧克力囊肿）及深部浸润型内异症（DIE）有较高诊断价值。盆腔MRI适用于复杂DIE、肠道/泌尿系受累及术前规划。
   - **实验室检查**：CA125、CA19-9可轻度升高，但特异性有限，主要用于疗效监测而非诊断。
   - **金标准**：腹腔镜检查结合病理活检，适用于诊断不明、药物治疗无效或合并不孕需手术干预者。
4. **疼痛与心理评估**：使用视觉模拟评分（VAS）、疼痛问卷（EPQ）、SF-36生活质量量表。常规筛查焦虑抑郁（HADS、PHQ-9、GAD-7），评估内脏高敏感及盆底肌张力。
5. **鉴别诊断**：须重点排除肠易激综合征（IBS）、间质性膀胱炎/膀胱疼痛综合征（IC/BPS）、盆腔炎性疾病（PID）、盆腔静脉淤血综合征、泌尿系结石及胃肠道器质性疾病。警惕急腹症等继发性病因（如囊肿破裂、蒂扭转、肠梗阻、穿孔），疼痛性质突变、伴随发热、血便、黄疸、腹胀拒按、体重下降为关键报警信号。

## 四、专家诊疗思路（按类别）
子宫内膜异位症疼痛的诊疗难点在于病程慢性化、疼痛机制混合（内脏痛+神经病理性痛+肌筋膜痛）及复发率高。临床接诊遵循“排除急症-明确分型-个体化治疗-长期管理”路径：
1. **首要排除器质性与急症**：任何突发剧烈腹痛、伴休克征象、肠梗阻或泌尿系梗阻表现者，需立即急诊干预（如囊肿破裂出血、蒂扭转）。常规评估中，发热、黄疸、血便、进行性消瘦、腹部拒按均为绝对报警信号，必须优先完善影像学及内镜检查。
2. **分型与机制导向治疗**：
   - **浅表腹膜型/卵巢型**：以炎症和激素依赖为主。一线采用NSAIDs联合激素抑制排卵（COC、地诺孕素、GnRH-a）。
   - **深部浸润型（DIE）**：累及肠管、输尿管、膀胱及神经丛。疼痛常呈持续性且与周期关系减弱，神经病理性成分重。需多学科评估，药物控制不佳时优先考虑病灶切除手术。
   - **合并盆底肌功能障碍/中枢敏化**：单纯“止痛”或“抑制激素”往往效果有限。需联合盆底康复、神经调节药物（如加巴喷丁、度洛西汀）及认知行为疗法（CBT）。
3. **生育需求导向**：有生育计划者，避免长期GnRH-a或手术损伤卵巢储备。优先尝试促排卵+宫腔内人工授精（IUI）或试管婴儿（IVF-ET）。术前需与生殖科充分沟通。
4. **心理与脑-肠/脑-盆轴管理**：慢性疼痛患者共病焦虑抑郁比例高达30%-50%。心理评估与干预应贯穿全程，必要时联合精神科使用SNRI/SSRI类药物治疗疼痛共病。

## 五、处理原则（药物与干预）
治疗目标为缓解疼痛、抑制病灶进展、促进生育、提高生活质量。策略需根据年龄、症状严重程度、生育要求及既往治疗反应个体化制定。
### 通用处理框架与用药要点（按类别）
1. **药物治疗（一线）**：
   - **非甾体抗炎药（NSAIDs）**：如布洛芬、萘普生、塞来昔布。通过抑制COX酶减少前列腺素合成，缓解痛经及炎症痛。建议经前3-5天开始规律服用，而非痛极时才用。注意胃肠道及心血管风险。
   - **激素治疗**：核心为抑制排卵、造成假孕或假绝经状态。
     - 复方口服避孕药（COC）：一线首选，连续服用或周期性服用，有效缓解痛经及盆腔痛。
     - 孕激素：地诺孕素（2mg/d）为内异症特效药，直接抑制异位内膜生长，副作用相对较小，适合长期管理。
     - GnRH激动剂/拮抗剂：造成可逆性“药物性卵巢切除”，快速缩小病灶、缓解剧痛。需反向添加疗法（RT）预防低雌激素引起的骨质疏松及血管舒缩症状。
     - 左炔诺孕酮宫内缓释系统（LNG-IUS）：局部高浓度孕激素释放，对痛经及盆腔痛疗效确切，尤其适合合并不孕或不愿全身用药者。
2. **手术治疗**：
   - **保守性手术**：腹腔镜下病灶电灼/切除、囊肿剥除、粘连松解。适用于药物治疗无效、合并不孕或囊肿>4cm者。需由经验丰富的妇科内镜医师操作，最大限度保护卵巢功能。
   - **确定性手术**：全子宫+双附件切除术。仅适用于无生育要求、症状极重、多次复发或怀疑恶变者。术后仍需警惕残端内异症。
3. **介入与神经调控治疗（难治性疼痛）**：
   - **神经阻滞**：髂腹下/髂腹股沟神经阻滞、骶管阻滞、上腹下神经丛（SHP）或下腹下神经丛（PPP）阻滞/射频消融。适用于定位明确的慢性盆腔痛或术后疼痛。
   - **脊髓电刺激（SCS）**：对于药物、手术均无效的顽固性神经病理性盆腔痛，可考虑植入式SCS，通过门控理论抑制痛觉传导。
   - **肌筋膜触发点注射**：针对盆底肌痉挛及肌筋膜疼痛综合征，使用局麻药±糖皮质激素注射。
4. **联合用药策略**：若存在明显神经病理痛特征（烧灼感、电击感、痛觉超敏），可联用钙通道调节剂（加巴喷丁、普瑞巴林）或SNRI（度洛西汀、文拉法辛）。避免长期单一依赖阿片类药物，以免导致阿片诱导的痛觉过敏（OIH）及成瘾。

## 六、非药物与康复
非药物干预是慢性疼痛管理的基石，需贯穿疾病全程：
1. **盆底物理治疗与内脏松解**：由专业康复师指导，进行盆底肌筋膜触发点松解、内脏推拿（Visceral Manipulation）、生物反馈训练。可有效改善盆底肌高张力、缓解性交痛及排便痛。
2. **生活方式与饮食调整**：建议低FODMAP饮食或抗炎饮食（富含Omega-3、抗氧化剂），减少高脂、高糖及促炎食物摄入。保持规律有氧运动（如瑜伽、游泳、快走），促进内啡肽释放，改善盆腔血液循环。
3. **心理与认知行为干预**：正念减压（MBSR）、认知行为疗法（CBT）可显著降低疼痛灾难化思维，改善睡眠障碍及情绪共病。建立疼痛日记，识别并规避诱发因素。
4. **中医与替代疗法**：针灸、艾灸、中药调理在缓解痛经及调节内分泌方面有一定循证支持，可作为辅助手段。热敷、经皮神经电刺激（TENS）对部分患者有效。

## 七、随访与监测要点
子宫内膜异位症为慢性复发性疾病，需建立长期、规律的随访档案：
1. **疼痛与症状监测**：每3-6个月复查NRS/VAS评分、疼痛部位及性质变化。记录月经周期、经量及伴随症状（如排便/排尿异常）。
2. **药物不良反应监测**：
   - 长期使用NSAIDs：定期监测血常规、肝肾功能、胃肠镜指征。
   - 激素治疗（GnRH-a/地诺孕素/COC）：监测血压、血糖、血脂、肝功能；GnRH-a治疗>6个月需定期行骨密度（DEXA）检查及补充钙剂/维生素D。
   - 神经调节药物：监测嗜睡、头晕、体重变化及情绪波动。
3. **生育功能评估**：有生育需求者，定期监测AMH、窦卵泡计数（AFC）。术后或药物停药后尽早规划妊娠。
4. **生活质量与心理状态**：每年使用SF-36或EHP-30量表评估生活质量。动态筛查焦虑抑郁，必要时转介心理/精神专科。
5. **影像学复查**：无症状者无需频繁超声。若疼痛复发或触及包块，行TVUS或MRI评估病灶进展或复发。

## 八、预警与转诊指征
出现以下情况需立即升级诊疗或紧急转诊：
1. **急腹症预警**：突发撕裂样或刀割样下腹痛，伴恶心呕吐、冷汗、血压下降、腹部板状硬或拒按。高度怀疑卵巢囊肿破裂、蒂扭转、盆腔脓肿破裂或肠穿孔，需急诊手术。
2. **泌尿系/肠道梗阻**：进行性加重的排尿困难、血尿、肾积水；或便秘与腹泻交替、便血、肠梗阻表现。提示DIE侵犯输尿管或肠管，需泌尿外科/胃肠外科紧急会诊。
3. **治疗失效与病情进展**：规范药物治疗3-6个月疼痛无缓解或进行性加重；影像学提示囊肿快速增大（>5cm）、实性成分增多或血流异常，需警惕恶变（内异症相关卵巢癌）。
4. **严重药物不良反应**：出现严重过敏反应、肝肾功能急剧恶化、严重抑郁自杀倾向或阿片类药物滥用迹象。
5. **多学科协作指征**：复杂DIE累及肠道/泌尿系、顽固性神经病理性痛、合严重精神心理障碍者，应启动妇科、疼痛科、康复科、心理科、生殖科MDT模式。

## 九、患者教育与自我管理
赋能患者是长期管理成功的关键：
1. **疾病认知教育**：明确内异症为慢性、激素依赖性、易复发的良性疾病，非绝症但需长期管理。疼痛与病灶大小不完全正相关，微小病灶亦可引起剧痛，消除“切干净就根治”的误区。
2. **识别报警症状**：熟记急腹症、肠梗阻、泌尿系梗阻及异常出血的预警信号。一旦出现，立即就医，勿自行服用强效止痛药掩盖病情。
3. **规范用药与依从性**：强调激素药物需连续、规律服用，不可症状稍缓即自行停药，否则极易反跳。NSAIDs应足量足疗程使用。了解药物副作用及应对策略。
4. **生活方式与自我管理工具**：指导记录“疼痛-月经-饮食-情绪”日记，寻找个人诱发规律。坚持盆底肌放松训练、热敷、温和运动。保持健康体重，戒烟限酒。
5. **生育规划与心理支持**：尽早与医生沟通生育计划，制定个体化助孕路径。加入患者支持团体，获取同伴支持。家属应给予充分理解，避免将慢性疼痛简单归结为“心理作用”。
6. **复诊纪律**：建立固定随访周期，即使无症状也需定期复查。任何治疗方案调整均需在专业医师指导下进行，切勿轻信偏方或未经证实的“根治”疗法。

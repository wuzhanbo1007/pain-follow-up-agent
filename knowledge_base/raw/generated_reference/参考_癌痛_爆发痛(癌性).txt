# 爆发痛(癌性)

文档标题：爆发痛(癌性)

类别：癌痛

## 一、概述
爆发痛（Breakthrough Cancer Pain, BTCP）是指在慢性持续性癌性背景痛得到基本控制的前提下，患者突发的短暂性、中重度疼痛发作。其临床特征表现为起病急骤、强度剧烈、持续时间通常较短（多为5–30分钟，极少超过1小时），具有明显的“多事件性”与“可预测/不可预测”之分。流行病学数据显示，约50%–70%的癌痛患者在其疾病进程中会经历爆发痛，严重干扰患者的睡眠、日常活动、情绪状态及社会功能。根据发作诱因与规律，临床通常将其分为三类：①事件性爆发痛（Incident BTCP）：由特定生理活动（如翻身、行走、咳嗽）、医疗操作（如换药、穿刺）或内脏功能活动（如排便）诱发；②自发性爆发痛（Spontaneous BTCP）：无明确诱因，随机发作；③特发性爆发痛（Idiopathic BTCP）：发作无规律且对常规背景镇痛药物反应不佳。规范识别与个体化处理爆发痛，是提升癌痛综合管理质量、实现“无痛睡眠、无痛休息、无痛活动”核心目标的关键环节。

## 二、病理生理机制
癌痛本质为多因素、多通路交织的复杂病理过程，爆发痛的发生机制在此基础上呈现动态放大效应。
1. **外周敏化与炎症级联**：肿瘤组织浸润、压迫或坏死释放大量炎性介质（如前列腺素E2、白介素-1β、TNF-α、神经生长因子NGF、缓激肽等），直接激活伤害性感受器（nociceptors）上的TRPV1、P2X3等离子通道，降低痛阈。肿瘤微环境中的成纤维细胞、巨噬细胞与肿瘤细胞形成“疼痛轴”，持续维持外周致敏状态。
2. **中枢敏化与神经可塑性**：持续的伤害性输入导致脊髓背角神经元NMDA受体过度激活，引发钙离子内流与“上行风车现象”（Wind-up phenomenon）。星形胶质细胞与小胶质细胞被激活，释放促炎细胞因子，削弱下行抑制通路（如5-HT、NE能系统），导致疼痛信号放大与时间/空间扩散。爆发痛发作时，中枢敏化网络呈现瞬时高频放电，表现为疼痛强度骤增与痛觉超敏（Allodynia）。
3. **神经病理性成分**：肿瘤压迫神经丛、神经根或化疗药物（如紫杉类、铂类、长春碱类）引起的轴突变性与脱髓鞘，导致异位放电与自发放电。神经病理性痛觉常与伤害性痛觉叠加，使爆发痛更具顽固性与难治性。
4. **阿片诱导的痛觉超敏（OIH）与耐受**：长期大剂量阿片类药物使用可激活脊髓胶质细胞谷氨酰胺酶通路，促进阿片肽降解，同时增强NMDA受体活性，导致机体对疼痛刺激的反应性异常增高。OIH需与肿瘤进展、疾病恶化严格鉴别，其临床表现为疼痛范围扩大、强度反常增加，且增加阿片剂量反而加重疼痛。此时应优先考虑阿片轮换、添加NMDA受体拮抗剂（如氯胺酮、美沙酮）或多模式镇痛，而非单纯递增剂量。
5. **心理-神经-内分泌轴调控**：焦虑、抑郁、恐惧等负性情绪通过杏仁核-下丘脑-垂体-肾上腺轴（HPA轴）放大疼痛感知，形成“疼痛-失眠-情绪恶化-痛阈降低”的恶性循环。

## 三、临床评估与筛查
规范的评估是精准干预的前提，必须采用多维、动态、量化的工具进行系统筛查。
1. **疼痛强度与特征量化**：常规采用数字评分法（NRS）或视觉模拟评分法（VAS）评估背景痛与爆发痛强度（1–3分轻度，4–6分中度，7–10分重度）。推荐使用简明疼痛量表（BPI）全面评估疼痛对情绪、睡眠、行走能力、日常兴趣、人际交往、夜间休息及整体生活质量的干扰程度。
2. **爆发痛专项评估（4W原则）**：
   - **What（性质与部位）**：明确是否为锐痛、灼痛、电击样痛或绞痛，定位是否准确，有无放射痛。
   - **When（频率与时长）**：记录24小时内发作次数、平均持续时间、起效与缓解时间。若每日发作≥4–5次，强烈提示背景镇痛剂量不足或给药间隔不合理。
   - **Where（诱因与情境）**：区分事件性（如活动、体位改变、医疗操作）与自发性。记录诱发因素有助于制定预防性用药策略。
   - **Why（背景控制状态）**：评估当前背景镇痛方案的有效性、血药浓度稳定性及是否存在耐受或OIH。
3. **药物暴露与耐受评估**：详细记录阿片类药物种类、剂量、给药途径、换算历史（MEDD计算）、不良反应（便秘、恶心、嗜睡、呼吸抑制风险）及既往阿片使用史。未耐受患者需从低剂量起始并缓慢滴定。
4. **共病与心理社会筛查**：常规使用PHQ-9筛查抑郁，GAD-7筛查焦虑，Pain Catastrophizing Scale（PCS）评估疼痛灾难化思维。中重度癌痛患者抑郁/焦虑共病率高达30%–50%，需同步干预。
5. **器质性并发症排查**：对突发剧烈疼痛或性质改变者，必须结合影像学（X线、CT、MRI、骨扫描/PET-CT）与实验室检查（血常规、肝肾功能、电解质、碱性磷酸酶、PSA、肿瘤标志物），排除病理性骨折、脊髓压迫、肠梗阻、胆道梗阻、感染或肿瘤快速进展。

## 四、专家诊疗思路（按类别）
癌痛管理遵循“以患者为中心、多模式镇痛、动态滴定、全程管理”的核心原则。我的临床路径强调：在确保背景痛平稳控制的基础上，针对性处理爆发痛，最终实现疼痛可控、功能可保、尊严可存。
1. **背景痛基石与滴定策略**：中重度癌痛以阿片类药物为基石。未耐受患者推荐从吗啡即释片5–7.5 mg q4h PRN（或羟考酮2.5–5 mg、氢吗啡酮2 mg）起始。滴定遵循“小步快跑、密切监测”原则，每24–48小时根据NRS评分与不良反应调整剂量，增幅通常为原剂量的30%–100%。切忌因恐惧成瘾或过度担忧副作用而长期欠量镇痛，癌痛治疗中成瘾发生率极低（<1%），规范用药安全性高。
2. **爆发痛的独立干预逻辑**：爆发痛必须作为独立临床事件处理，不可仅依赖增加背景药剂量。单次救援剂量（Rescue Dose）通常设定为24小时阿片总剂量的10%–20%（或约日剂量的1/6–1/10）。即释制剂口服后1小时、静脉给药后15分钟必须进行复评。若24小时内爆发痛发作频繁（>4次）或救援剂量需求持续增加，提示背景方案失效，需重新评估病因、调整背景药剂量或考虑阿片轮换。
3. **事件性爆发痛的预防性用药**：对于可预测的发作（如康复训练、伤口换药、排便），应在诱因出现前30–60分钟预防性给予救援剂量，或采用短效透皮芬太尼贴剂/鼻喷剂提前覆盖。
4. **阿片轮换与OIH管理**：当出现快速耐受、剂量递增无效或严重不良反应时，应启动阿片轮换。采用等效剂量换算表，并实施25%–50%的剂量削减以应对不完全交叉耐受。若怀疑OIH，可减量原阿片，加用美沙酮（兼具NMDA拮抗作用）或氯胺酮，配合非阿片类辅助药物。
5. **终末期与缓和医疗整合**：疾病晚期应以患者舒适与意愿为最高准则。强化症状群管理（疼痛、谵妄、恶心、呼吸困难），尽早引入缓和医疗团队。尊重预先医疗指示（Advance Directives），聚焦生活质量而非过度侵入性干预。

## 五、处理原则（药物与干预）
单次 rescue 约为日剂量 1/6–1/10
即释阿片间隔≥1h
缓释阿片间隔≥2–4h
频繁爆发痛提示背景剂量不足
记录诱因有助于调整

### 通用处理框架与用药要点（按类别）
严格遵循WHO三阶梯镇痛原则与NCCN/ESMO癌痛管理指南，实施个体化、阶梯化、多模式治疗。
1. **阿片类药物精准应用**：
   - **即释阿片（救援用药）**：吗啡、羟考酮、氢吗啡酮口服起效快（10–30 min），峰值30–60 min，作用2–4 h。芬太尼透皮贴剂不适用于爆发痛处理（起效慢、半衰期长），但芬太尼口腔黏膜制剂（舌下片、颊黏膜片、鼻喷剂）起效极快（5–10 min），适用于快速发作的爆发痛，尤其适合吞咽困难或胃肠道功能障碍患者。
   - **缓释阿片（背景用药）**：吗啡缓释片、羟考酮缓释片、芬太尼透皮贴剂提供平稳血药浓度，给药间隔2–12 h不等。严禁掰开、咀嚼或碾碎缓释制剂，以免突释导致呼吸抑制。
   - **滴定与换算**：使用标准等效剂量表进行跨阿片换算，并扣除25%–50%交叉耐受减量。每日总剂量调整需结合NRS、功能状态与不良反应综合决策。
2. **辅助镇痛药物（Adjuvants）**：
   - **非甾体抗炎药（NSAIDs）**：对骨转移痛、炎症性痛、内脏包膜牵拉痛效果显著。需注意胃肠道、心血管及肾脏毒性，高危者联用PPI。
   - **糖皮质激素**：地塞米松可减轻肿瘤周围水肿、缓解神经压迫与内脏包膜张力，对骨痛、神经压迫、肠梗阻早期疼痛有快速缓解作用。短期使用（如4–8 mg/d），注意血糖、感染与肌病风险。
   - **抗惊厥药与抗抑郁药**：加巴喷丁、普瑞巴林针对神经病理性痛；度洛西汀、阿米替林调节下行抑制通路，改善疼痛伴随的睡眠障碍与情绪症状。
3. **阿片相关性便秘（OIC）的主动管理**：便秘为阿片类药物最常见且不会耐受的不良反应。自用药首日即启动预防：刺激性泻药（番泻叶、比沙可啶）联合渗透性/软化剂（聚乙二醇、乳果糖、多库酯钠）。若常规泻药无效，及时启用外周μ阿片受体拮抗剂（PAMORAs，如甲基纳曲酮、纳洛格、莫沙必利衍生物），不干扰中枢镇痛。
4. **介入与微创治疗**：
   - **神经阻滞与毁损**：腹腔神经丛阻滞（上腹部脏器痛）、腹下神经丛阻滞（盆腔脏器痛）、椎旁/硬膜外阻滞、射频热凝或化学毁损。
   - **鞘内药物输注系统（IDDS）**：适用于多模式镇痛失败、严重全身不良反应或需极低剂量高效镇痛的患者。可单独输注阿片（如吗啡、氢吗啡酮、齐考诺肽）或联合局麻药/可乐定。
   - **姑息性放疗与骨改良药物**：骨转移痛首选局部放疗（单次8 Gy或分次20 Gy/5次）；联合双膦酸盐（唑来膦酸）或地舒单抗抑制破骨细胞活性，降低骨骼相关事件（SREs）风险。
5. **高危用药安全管控**：避免使用哌替啶（代谢产物去甲哌替啶致神经毒性）与丙氧芬（心脏毒性）。避免在阿片依赖者使用部分激动/拮抗剂（如丁丙诺啡、纳布啡、喷他佐辛）以免诱发戒断。MEDD>50 mg、联用苯二氮䓬类、有呼吸睡眠暂停或过量史者，必须配备纳洛酮并培训家属。

## 六、非药物与康复
癌痛管理绝非单纯药物叠加，必须整合心理、康复、营养与缓和医疗，构建全人照护网络。
1. **心理行为干预**：认知行为疗法（CBT）帮助患者重构疼痛认知，打破灾难化思维；正念减压（MBSR）与渐进性肌肉放松训练可降低交感神经张力，减轻疼痛焦虑；催眠疗法与生物反馈对部分患者有显著辅助镇痛效果。
2. **物理康复与体位管理**：在疼痛可控前提下，制定个体化活动计划。使用辅助器具（腰围、助行器）减轻负重；针对骨转移患者避免剧烈扭转与负重；采用减压垫、体位垫缓解压痛；温和的拉伸与呼吸训练可改善肌肉痉挛与胸腹式呼吸受限。
3. **中医与替代疗法**：针灸（尤其针对内脏痛与神经病理性痛）、经皮神经电刺激（TENS）、推拿与中药外敷在多项指南中被列为辅助推荐。需由持证专业人员操作，避免在肿瘤病灶局部或凝血功能障碍者使用侵入性操作。
4. **营养与代谢支持**：癌痛常伴发癌性厌食-恶病质综合征（CACS）。提供高蛋白、高热量、抗炎饮食（富含ω-3脂肪酸）；纠正电解质紊乱（低钾、低镁可加重疼痛与心律失常）；必要时启用食欲刺激剂（甲地孕酮）或肠内/肠外营养支持。
5. **缓和医疗与安宁疗护**：疾病终末期，治疗目标转向舒适护理。强化症状群综合控制，提供灵性照护与哀伤辅导。推行预先医疗计划（ACP）与POLST/MOLST表格，明确患者对心肺复苏、气管插管、营养支持的意愿，确保医疗决策符合患者价值观。多学科团队（疼痛科、肿瘤科、缓和医疗科、临床药师、心理师、社工、营养师）每周联合查房，动态调整照护方案。

## 七、随访与监测要点
建立结构化、周期性的随访档案，实现疼痛管理的闭环控制。
1. **随访频率**：初始治疗期每周1次，病情稳定后每2–4周1次，终末期或方案调整期按需加密（3–7天/次）。
2. **核心监测指标**：
   - **疼痛日记**：连续记录背景NRS、爆发痛发作时间/诱因/持续时间、救援用药剂量与起效时间。
   - **功能与生活质量**：ECOG评分、KPS评分、睡眠障碍指数（ISI）、日常活动能力量表。
   - **药物安全性**：呼吸频率、镇静评分（Ramsay或Sedation-Agitation Scale）、便秘程度（Bristol粪便分型）、恶心呕吐频率、肝肾功能、电解质、血常规。
   - **心理社会指标**：PHQ-9/GAD-7复评、疼痛灾难化量表、社会支持评定量表（SSRS）。
3. **疗效判定标准**：背景痛NRS≤3分或较基线下降≥30%；24小时爆发痛发作≤2次；救援用药成功率>70%；不良反应可耐受；功能状态改善或维持。
4. **动态调整机制**：若连续3天救援剂量>背景剂量的20%，或爆发痛频率>4次/日，必须重新评估背景方案；若出现新发疼痛部位或性质改变，立即启动影像学排查；若NRS持续>7分且多模式治疗无效，启动疼痛专科会诊或介入治疗评估。

## 八、预警与转诊指征
癌痛病情复杂多变，识别红色预警信号并及时转诊是保障患者安全的核心。
1. **急诊转诊指征（立即就医/呼叫120）**：
   - 爆发痛持续不缓解（>1小时）或进行性加重，常规救援药物无效。
   - 出现急性脊髓压迫征象：突发腰背痛伴双下肢无力、感觉平面、大小便失禁或尿潴留。
   - 严重阿片毒性反应：呼吸频率<8次/分、SpO2<90%、深度镇静/意识模糊、瞳孔针尖样。
   - 急性腹部综合征：剧烈腹痛伴呕吐、腹胀、停止排气排便，疑恶性肠梗阻或穿孔。
   - 高钙危象：多饮多尿、意识障碍、心律失常、严重脱水。
2. **专科/多学科转诊指征**：
   - 爆发痛频繁发作且背景药滴定已达最大耐受剂量，需评估阿片轮换或鞘内泵植入。
   - 疑诊阿片诱导的痛觉超敏（OIH）或严重药物不良反应。
   - 疼痛性质转为典型神经病理性，需调整辅助用药或行神经阻滞/射频治疗。
   - 合并严重精神心理障碍（重度抑郁、自杀倾向、谵妄）或药物滥用史。
   - 骨转移伴病理性骨折风险或已发生骨折，需骨科/放疗科/介入科联合干预。
3. **转诊沟通规范**：提供完整疼痛档案、用药清单（含等效剂量换算）、既往干预记录、影像学资料及患者意愿声明，确保医疗信息无缝衔接。

## 九、患者教育与自我管理
赋能患者与家属是维持长期镇痛效果、预防并发症、提升治疗依从性的基石。
1. **用药依从性教育**：
   - 强调“按时服药”优于“按需服药”：缓释阿片需严格遵医嘱定时服用，维持稳定血药浓度，预防爆发痛发生。
   - 明确“爆发痛用救援”：即释药物仅用于突破痛发作，不可作为背景药替代。记录每次救援用药时间、剂量与效果，复诊时务必携带疼痛日记。
   - 严禁自行增减剂量、停药或更改给药途径（如碾碎缓释片），以免引发戒断反应或药物过量。
2. **便秘预防与日常管理**：自用药首日即启动“饮水+膳食纤维+规律排便习惯+预防性泻药”四联策略。告知家属：阿片相关便秘不会随用药时间延长而自行耐受，需持续管理。出现腹胀、排便困难及时联系药师调整方案。
3. **安全储存与废弃物处理**：阿片类药物必须存放于儿童与宠物无法触及的专用药箱中，避免共享或转赠。过期、剩余或不再需要的药品应通过医院回收点或社区指定渠道销毁，严禁冲入下水道或随意丢弃。
4. **呼吸抑制识别与急救**：家属需掌握纳洛酮使用方法（鼻喷或肌注），并牢记呼吸抑制预警征象：呼吸缓慢浅表（<8–10次/分）、嘴唇/甲床发绀、呼之不应、皮肤湿冷。一旦出现，立即停止阿片、保持气道通畅、呼叫急救，并按规定使用纳洛酮。
5. **心理调适与生活方式**：鼓励患者参与支持小组，分享应对经验；保持规律作息，避免熬夜与过度劳累；戒烟限酒；学习腹式呼吸与放松技巧应对疼痛焦虑。明确告知：规范使用阿片治疗癌痛不会导致“成瘾”，恐惧用药反而加剧痛苦。
6. **数字化自我管理工具**：推荐患者使用合规的疼痛管理APP或微信小程序，设置服药提醒、记录疼痛日记、查看用药指南与紧急联络方式。鼓励家属共同参与数字化随访，实现医患家三方协同管理。

# 慢性颈痛

类别：肌骨疼痛

## 一、概述
慢性颈痛（Chronic Neck Pain）是指持续或反复发作超过3个月的颈肩部疼痛综合征，是疼痛科、康复医学科及骨科门诊最常见的就诊主诉之一。其临床表现高度异质，可局限于颈后部及枕下区，亦可向肩胛内侧缘、上肢放射，常伴随颈部僵硬、活动受限、紧张性头痛及上肢感觉运动异常。流行病学显示，久坐办公、低头使用移动终端、不良睡姿、职业性重复劳损及心理社会因素是主要诱因与维持因子。根据病因与受累结构，临床常分为颈型、神经根型、脊髓型、交感型、椎动脉型及肌筋膜疼痛综合征等亚型。早期识别与规范干预可有效阻断急性向慢性转化，避免中枢敏化与继发性功能残疾，提升患者生活质量与职业回归率。

## 二、病理生理机制
慢性颈痛的病理生理基础复杂，涉及外周伤害性感受、神经病理性损伤及中枢敏化等多重机制交互作用。
1. **外周伤害性机制**：颈椎间盘退变、纤维环微撕裂、小关节软骨磨损、黄韧带肥厚或钙化导致局部机械应力异常与微动增加。退变组织与受损细胞释放炎性介质（如前列腺素E2、白介素-1β、肿瘤坏死因子-α、P物质、CGRP、BDNF），降低伤害性感受器阈值，引发局部无菌性炎症、血管通透性增加及肌肉保护性痉挛。
2. **神经病理性机制**：神经根受压、牵拉或化学性刺激导致轴突运输障碍、背根神经节（DRG）神经元兴奋性增高及电压门控离子通道（如Nav1.7/1.8、TRPV1）异常表达，产生自发放电与异位冲动，表现为放射性刺痛、电击样痛、感觉过敏或感觉减退。
3. **中枢敏化与“运动恐惧”**：持续外周伤害性输入导致脊髓背角神经元突触可塑性改变（长时程增强，LTP），下行抑制通路（5-HT、NE系统）功能减弱，痛觉传导通路阈值显著下降，非伤害性刺激（如轻触、日常活动）引发痛觉超敏（Allodynia）与痛觉过敏（Hyperalgesia）。同时，患者因恐惧疼痛加重或再次损伤而采取“运动回避”（Fear-Avoidance）策略，导致颈深屈肌（长头肌、多裂肌）与肩胛稳定肌群废用性萎缩、本体感觉减退、筋膜粘连，形成“疼痛-肌肉失衡-功能下降-再疼痛”的恶性循环。此外，慢性疼痛常伴随边缘系统（杏仁核、前扣带回、岛叶）与默认模式网络功能重组，引发焦虑、抑郁、睡眠障碍及疼痛灾难化思维，进一步放大疼痛感知与残疾程度。

## 三、临床评估与筛查
系统评估是制定个体化方案的前提，需严格区分结构性病变与功能性/机械性来源，避免过度依赖单一检查。
1. **病史采集**：详细询问起病诱因、疼痛性质（钝痛、刺痛、烧灼痛、紧束感）、放射范围、昼夜节律、加重/缓解因素（如颈部后伸、咳嗽、打喷嚏、长时间低头）。重点排查红旗征（严重外伤史、发热/寒战、夜间痛醒、静息痛、不明原因体重下降、肿瘤/感染/免疫病史、进行性神经功能缺损）。
2. **体格检查**：
   - **视诊与触诊**：观察头颈姿势（前倾头、翼状肩胛、圆肩），触诊斜方肌、肩胛提肌、头夹肌、胸锁乳突肌等是否存在激痛点（Trigger Points）、条索状硬结及压痛节段。
   - **关节活动度（ROM）**：测量前屈、后伸、侧屈、旋转角度，记录终末感（骨性阻挡、肌肉痉挛或疼痛诱发），评估活动受限对ADL的影响。
   - **神经专科检查**：Spurling试验（神经根牵拉）、臂丛神经牵拉试验（Eaton试验）、Hoffmann征、Babinski征、病理反射、肌力分级（C5-T1皮节/肌节对应肌群）、感觉减退区、深腱反射（肱二头肌C5/6、肱三头肌C7、桡骨膜反射）。
   - **血管与交感评估**：椎动脉扭曲试验（需极度谨慎，阳性仅提示血流动力学改变，非确诊依据）、Horner综合征体征、交感神经兴奋表现（头晕、视物模糊、耳鸣、心悸、出汗异常）。
3. **辅助检查**：影像学（X线正侧位+双斜位、动力位评估不稳；MRI金标准评估椎间盘、神经根、脊髓信号及压迫程度；CT评估骨性结构、小关节退变）仅在存在红旗征、进行性神经损害、保守治疗6-8周无效或拟行介入/手术时针对性使用。避免对无神经体征者常规行MRI，以防“影像-症状分离”引发医源性焦虑与过度医疗。
4. **量表评估**：采用颈部功能障碍指数（NDI）、视觉模拟评分（VAS/NRS）、SF-36健康调查简表、疼痛灾难化量表（PCS）及心理筛查（PHQ-9/GAD-7）量化疼痛强度、功能损害程度及心理共病风险，为疗效判定提供客观基线。

## 四、专家诊疗思路（按类别）
慢性颈痛属门诊最高频病种，以颈椎退行性变、肌筋膜疼痛综合征、神经根型颈椎病为主。临床诊疗需遵循“阶梯化、多学科、个体化”原则，摒弃“以片定症”与“过度医疗”误区。
1. **药物策略**：坚持“能外用不口服，能单药不联合，能短程不长期”。轻中度疼痛首选对乙酰氨基酚或外用NSAIDs（如双氯芬酸二乙胺乳胶剂、氟比洛芬凝胶贴膏）。口服NSAIDs前必须评估胃肠道溃疡史、心血管风险、肾功能及血压，高危者联用质子泵抑制剂（PPI）或换用COX-2选择性抑制剂。合并神经病理性成分者，早期引入加巴喷丁/普瑞巴林或SNRIs（度洛西汀/文拉法辛）。肌肉痉挛明显者短期使用中枢性肌松药（如替扎尼定、乙哌立松、托哌酮），避免长期依赖。严格限制阿片类药物，仅用于难治性急性发作期短期桥接，并密切监测成瘾与耐受风险。
2. **影像使用边界**：切忌将退变影像直接等同于疼痛来源。无症状的颈椎间盘突出、骨质增生、椎间盘信号减低在中年人群中极为常见。影像学发现必须与临床症状、体征高度吻合方可定位责任节段。无红旗征者，首选保守治疗，盲目送检MRI常导致患者焦虑与不必要的手术讨论。
3. **核心干预理念**：运动康复是打破恶性循环的基石。有氧运动改善全身微循环与内源性镇痛物质分泌，颈深屈肌（长头、多裂肌）与肩胛稳定肌（前锯肌、菱形肌、斜方肌中下束）强化重建动态稳定性。人机工效学干预（屏幕高度、座椅支撑、定时微休息、手机使用习惯）从源头削减机械负荷。
4. **多学科整合**：对慢性顽固性颈痛，常规联合物理治疗、手法松解、认知行为疗法（CBT）及疼痛神经科学教育（PNE）。长期卧床绝对禁忌，应鼓励“疼痛允许下的活动”（Pacing）。若为炎性脊柱关节病（如强直性脊柱炎、银屑病关节炎、反应性关节炎），风湿免疫科主导的DMARDs/生物制剂治疗才是治本之策，NSAIDs/短期糖皮质激素仅作急性期对症过渡。

## 五、处理原则（药物与干预）
1. **活动与拉伸为主**：避免绝对制动，推行“相对休息+渐进性负荷”原则，维持关节滑液循环与肌肉弹性。
2. **外用药物对症**：NSAIDs贴剂/凝胶、辣椒素贴剂、利多卡因贴剂、薄荷醇/水杨酸甲酯制剂可直接作用于皮下组织与浅表筋膜，全身不良反应极低，适合老年及合并症多者。
3. **人机工效改善**：优化工作站人体工学设置（显示器平视、键盘鼠标贴近身体、腰部支撑）；使用符合颈椎生理曲度的枕头（仰卧枕高约一拳，侧卧枕高与肩宽相等）；避免长时间低头、趴睡、高枕。
4. **放松与睡眠管理**：认知放松训练、正念冥想、渐进性肌肉放松（PMR）、睡眠卫生教育，打破“疼痛-失眠-疲劳-痛阈降低-疼痛加重”的恶性循环。
### 通用处理框架与用药要点（按类别）
- **退行性/机械性颈痛**：一线外用NSAIDs+对乙酰氨基酚；二线口服NSAIDs/肌松药；三线神经调节药物（普瑞巴林/度洛西汀）。小关节源性疼痛可考虑选择性神经阻滞或射频消融。
- **神经根型颈椎病**：急性期短期口服糖皮质激素（如甲泼尼龙阶梯冲击或地塞米松短期口服）减轻神经根水肿与炎症；配合颈托短期制动（≤2周，防肌肉萎缩）；无效者行颈椎硬膜外类固醇注射（CESI）或选择性神经根阻滞（SNRB）。
- **肌筋膜疼痛综合征**：激痛点干针/湿针注射、局部麻醉药+低浓度激素封闭、体外冲击波治疗（ESWT）、干式针刀效果显著，可快速打断疼痛-痉挛循环。
- **炎性/风湿性颈痛**：以DMARDs（甲氨蝶呤、柳氮磺吡啶、来氟米特）或生物制剂（TNF-α/IL-6/JAK抑制剂）控制原发病为核心，NSAIDs/短期糖皮质激素仅作急性期对症。
- **介入治疗阶梯**：保守治疗无效且责任节段明确者，可阶梯式开展：超声引导下小关节注射/神经阻滞 → 射频热凝/脉冲射频（调节背根神经节或交感链） → 颈椎间盘造影+臭氧/PRP注射（严格把握适应证，争议较大） → 微创椎间孔镜/减压融合术/人工椎间盘置换（终末手段，需严格手术指征）。

## 六、非药物与康复
1. **运动处方**：
   - **颈肩核心稳定训练**：收下巴练习（Chin Tucks，强化颈深屈肌）、肩胛骨后缩挤压、Y-T-W-L字母操、弹力带抗阻划船/外旋、靠墙天使（Wall Angels）。
   - **有氧与柔韧性**：快走、游泳（尤以蛙泳/仰泳为宜，避免过度后仰）、瑜伽/普拉提、太极，每周≥150分钟中等强度，循序渐进。
   - **本体感觉与协调**：平衡垫训练、闭眼单腿站立、头颈协调性练习（如视动整合训练），改善颈椎位置觉与动态控制。
2. **物理因子治疗**：经皮神经电刺激（TENS）、干扰电、超声波、低能量激光治疗（LLLT）、温热疗法、蜡疗可短期缓解肌肉痉挛与疼痛，但应作为运动治疗的辅助，避免被动依赖导致功能退化。
3. **手法治疗**：关节松动术（Maitland/Kaltenborn分级Ⅰ-Ⅳ级）改善关节活动度与滑液分布；软组织松解术（Myofascial Release、筋膜刀）缓解激痛点与筋膜粘连。*注意：颈椎椎动脉走行变异、骨质疏松、椎动脉型颈椎病、脊髓型颈椎病者禁用暴力旋转扳法，以防椎动脉夹层或脊髓损伤。*
4. **心理与行为干预**：疼痛神经科学教育（PNE）纠正“组织损伤=疼痛”的错误认知，降低灾难化思维；CBT处理回避行为与负性情绪；正念减压（MBSR）调节自主神经张力与痛觉加工。
5. **体重与代谢管理**：肥胖增加颈椎机械负荷及全身低度炎症状态（脂肪因子如瘦素、脂联素异常），减重5%-10%可显著改善症状与预后。

## 七、随访与监测要点
慢性疼痛管理是动态过程，需建立结构化、目标导向的随访路径：
1. **疼痛轨迹监测**：每次随访记录NRS/VAS评分变化趋势，区分“疼痛强度下降”与“疼痛耐受/功能提升”的不同临床意义，关注疼痛性质转变（如锐痛转钝痛提示神经炎症消退）。
2. **功能与生活质量**：定期复测NDI量表（目标下降≥10分或≥30%改善），评估ADL（穿衣、梳头、驾驶、工作）及职业回归能力，设定阶段性康复目标。
3. **药物安全性监测**：NSAIDs定期查血常规、肝肾功能、电解质、血压；阿片类/肌松药监测嗜睡、便秘、跌倒风险、认知功能；加巴喷丁类注意头晕、共济失调、水肿；SNRIs监测血压、心率、5-羟色胺综合征风险。
4. **心理状态筛查**：每3-6个月使用PHQ-9、GAD-7、PCS量表评估情绪与疼痛认知，识别抑郁/焦虑共病，必要时转介临床心理科或精神科。
5. **影像与神经功能复查**：仅对进行性神经损害、疑似肿瘤/感染或拟手术者安排复查MRI/肌电图/神经传导速度。常规随访不依赖影像学“好转”，而以功能恢复与生活质量为核心终点。
6. **多学科协作**：与康复师、理疗师、心理医师、营养师、职业治疗师保持沟通，动态调整综合方案，确保治疗连贯性。

## 八、预警与转诊指征
出现以下“红旗征”或“黄旗征”需立即转诊或升级干预，延误可能导致不可逆神经损伤：
1. **脊髓受压征象（黄/红旗）**：双下肢无力、步态不稳（踩棉花感）、精细动作障碍（扣扣子困难、持物易落）、大小便功能障碍（尿潴留/失禁、便秘）、Hoffmann/Babinski征阳性、颈髓过伸试验阳性、Lhermitte征（屈颈电击感）。*提示颈椎管狭窄或脊髓型颈椎病，需紧急脊柱外科评估，禁忌盲目推拿、牵引或剧烈活动。*
2. **进行性神经根损害**：特定肌节肌力进行性下降（如C7伸腕/伸指无力、C8握力下降）、肌肉萎缩、反射消失、感觉缺损范围扩大。
3. **血管危象**：突发眩晕、复视、构音障碍、吞咽困难、共济失调、Horner综合征、对侧偏瘫，伴颈部外伤、剧烈咳嗽或近期手法治疗史。*高度怀疑椎动脉夹层或颈动脉夹层，需神经内科/血管外科急诊CTA/MRA，禁忌颈部按摩。*
4. **感染/肿瘤/骨折**：高热、寒战、静脉吸毒史、近期感染灶、免疫抑制状态；夜间痛醒、静息痛、进行性加重、不明原因体重下降、既往恶性肿瘤史、骨质疏松伴轻微外伤后畸形压痛。
5. **难治性疼痛与心理危机**：规范保守治疗≥3个月、多模式干预无效、疼痛致残（NDI>40%）、严重心理共病（重度抑郁/自杀倾向/物质滥用）、社会功能完全丧失。需转诊疼痛科介入治疗、多学科疼痛门诊或精神心理专科。

## 九、患者教育与自我管理
1. **疼痛认知重塑**：向患者阐明慢性颈痛多为“机械负荷累积+中枢敏化+心理社会因素”所致，影像学退变不等于疼痛来源，消除“骨头坏了必须手术”或“休息就能好”的错误认知。疼痛是保护性信号，而非组织破坏的直接指标。
2. **活动节律管理（Pacing）**：摒弃“不痛不动、痛就卧床”的极端模式。采用“少量多次、循序渐进、量力而行”原则，在疼痛可耐受范围内（NRS≤4）维持日常活动，避免周末“报复性活动”导致周一剧痛（Boom-Bust循环）。记录活动日记，识别诱发因素。
3. **姿势与工学优化**：电脑屏幕平视（上缘与眉弓齐平），手机举至眼部高度；每工作45分钟起身活动3-5分钟（喝水、远眺、拉伸）；选择支撑性良好的枕头；避免长时间低头、趴睡、高枕、软床；驾驶时使用腰靠与头枕。
4. **居家康复依从性**：每日坚持收下巴、肩胛稳定训练10-15分钟，动作质量重于数量；热敷/温水浴缓解晨僵与肌肉紧张；学习自我激痛点按压与筋膜球/泡沫轴放松技巧；呼吸训练（腹式呼吸）降低交感张力。
5. **复发预防与应急**：识别早期预警信号（晨僵加重、活动受限、放射痛再现），及时启动强化康复、外用药物与休息；避免盲目寻求“正骨复位”、长期佩戴硬质颈托（>2周致肌肉萎缩与依赖）或滥用止痛药。
6. **建立支持系统**：鼓励家属参与疼痛教育，提供情感支持与活动陪伴；加入慢性疼痛病友支持小组，分享应对策略，减少病耻感与孤立感。疼痛管理是长期战役，目标是“带痛生活、功能优先、质量提升”，而非追求绝对无痛。建立医患同盟，共同制定可实现的短期与长期目标。

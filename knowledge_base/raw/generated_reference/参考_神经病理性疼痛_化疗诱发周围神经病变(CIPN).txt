# 化疗诱发周围神经病变(CIPN)

类别：神经病理性疼痛

## 一、概述
化疗药物（如铂类、紫杉类、长春碱类、蛋白酶体抑制剂及免疫调节剂等）在杀伤肿瘤细胞的同时，常对周围神经系统产生剂量依赖性与累积性毒性，导致化疗诱发周围神经病变（Chemotherapy-Induced Peripheral Neuropathy, CIPN）。CIPN是肿瘤患者最常见的非血液学毒性之一，主要表现为肢体远端（“手套-袜套样”分布）的感觉、运动及自主神经功能障碍。其病理本质属于典型的神经病理性疼痛与感觉运动神经损伤。CIPN不仅显著降低患者生活质量，还常导致化疗剂量削减、疗程延迟甚至提前终止，直接影响抗肿瘤治疗的疗效与患者生存期。早期识别、规范评估与多学科综合管理是改善预后的关键。

## 二、病理生理机制
CIPN的发生机制复杂，核心在于化疗药物对周围神经结构的直接损伤与继发性神经病理性疼痛级联反应。
1. **细胞骨架与线粒体损伤**：紫杉类与长春碱类主要靶向微管蛋白，破坏轴突运输与神经纤维结构完整性；铂类药物（如奥沙利铂）与DNA交联，诱发氧化应激与线粒体功能障碍，导致ATP合成减少与活性氧（ROS）累积，引发神经元凋亡。
2. **离子通道与异位放电**：受损神经元细胞膜稳定性下降，电压门控钠通道（如Nav1.7、Nav1.8）与钙通道（如Cav3.2 T型钙通道）表达上调或功能异常，导致背根神经节（DRG）神经元自发放电阈值降低，产生持续性异位冲动。
3. **外周与中枢敏化**：外周损伤释放P物质、CGRP、IL-1β、TNF-α等炎症介质，激活伤害性感受器（外周敏化）。痛觉信号经Aδ与C纤维传入脊髓背角，谷氨酸与P物质大量释放，激活NMDA受体与AMPA受体，引发“Wind-up”现象与长时程增强（LTP）。同时，脊髓抑制性中间神经元（释放GABA/甘氨酸）功能受抑，下行抑制通路（如中脑导水管周围灰质-延髓头端腹内侧区-脊髓背角）活性减弱，导致中枢敏化。
4. **纤维选择性损伤**：奥沙利铂易损伤小直径无髓C纤维与薄髓Aδ纤维，表现为冷诱发性疼痛与感觉异常；紫杉类与铂类更易累及粗大有髓Aβ与Aα纤维，导致振动觉、本体感觉减退与运动协调障碍。

## 三、临床评估与筛查
CIPN的评估需采用多维度、标准化量表结合客观检查，以精准量化神经损伤程度并指导治疗。
1. **主观症状量表**：常规采用NCI-CTCAE v5.0、EORTC QLQ-CIPN20及PRO-CTCAE评估症状频率与严重程度；使用ID Pain、DN4、painDETECT、LANSS等量表筛查神经病理成分，识别痛觉超敏、触诱发痛与感觉缺失。
2. **体格检查**：重点评估“手套-袜套样”感觉分布区。精细检查针刺觉、温度觉、轻触觉、振动觉（128Hz音叉）及关节位置觉。运动功能评估肌力、肌张力、腱反射（常早期减弱或消失）。自主神经评估包括直立性低血压、出汗异常、瞳孔变化等。
3. **客观辅助检查**：神经传导速度（NCS）与肌电图（EMG）对大纤维损伤敏感，但CIPN早期常表现为正常（小纤维神经病变特征）。必要时行皮肤活检检测表皮神经纤维密度（IENFD）或角膜共焦显微镜检查以确诊小纤维病变。影像学（MRI）主要用于排除肿瘤压迫、脊柱病变或脱髓鞘疾病等结构性病因。
4. **综合功能评估**：覆盖疼痛强度（NRS/VAS）、睡眠质量（PSQI）、情绪状态（PHQ-9/GAD-7）、日常生活能力（ADL）及跌倒风险。需严格区分CIPN与肿瘤骨转移压迫、副肿瘤综合征、营养缺乏（如B12）或糖尿病等继发因素。

## 四、专家诊疗思路（按类别）
在疼痛科与肿瘤多学科团队（MDT）门诊中，CIPN的诊疗需兼顾抗肿瘤治疗连续性与神经功能保护。其本质是化疗药物诱导的周围神经损伤与继发性中枢敏化交织的复杂病理过程。
临床上我重点关注三个核心环节：一是**精准鉴别与分层**，利用DN4或painDETECT快速筛查神经病理成分，避免将CIPN误诊为普通劳损或肿瘤进展痛；二是**阶梯化与个体化干预**，强调按时、规律用药以维持血药浓度、稳定神经元膜电位，而非“痛时再吃”。一线药物需在加巴喷丁类、度洛西汀、阿米替林及外用制剂中根据患者共病、肝肾功能及副作用谱进行个体化选择；三是**科学管理预期**，CIPN的神经修复周期长，治疗目标并非“彻底根治”，而是实现NRS下降≥30%、睡眠结构改善、功能状态恢复及化疗耐受性提升。
针对特定亚型，如奥沙利铂引起的急性冷诱发性喉痉挛与慢性感觉运动神经病，需特别注意温度规避与剂量调整；对于已形成的顽固性CIPN，外用利多卡因贴剂联合口服钙通道调节剂（普瑞巴林/加巴喷丁）或SNRI类药物是常用且循证充分的组合。需特别指出，CIPN与带状疱疹后神经痛（PHN）机制有重叠但病因不同，PHN强调早期抗病毒与神经保护，而CIPN更侧重化疗方案优化与神经毒性拮抗。

## 五、处理原则（药物与干预）
表现为麻木、刺痛、感觉迟钝，可影响步态与精细动作。度洛西汀对部分CIPN疼痛有效（ASCO/NCCN 1级推荐）。需与癌性疼痛（伤害性疼痛为主）严格区分处理，CIPN属神经病理性疼痛，对传统NSAIDs或单纯阿片类反应差。功能康复与防跌倒在长期管理中至关重要。
### 通用处理框架与用药要点（按类别）
1. **一线药物治疗**：ASCO（2020更新）与NICE指南推荐，初始治疗应单一用药，避免盲目联用。首选**度洛西汀**（60–120 mg/d，证据等级最高）、**普瑞巴林**（起始75 mg bid，1周内滴定至150 mg bid，最大600 mg/d）或**加巴喷丁**（起始100-300 mg qd/tid，逐步滴定至900-3600 mg/d）。普瑞巴林/加巴喷丁主要调节α2δ亚基，减少钙内流与兴奋性递质释放；度洛西汀通过抑制5-HT/NE再摄取增强下行抑制通路。阿米替林（10–25 mg睡前起，渐增至25–150 mg）因抗胆碱能副作用及心脏毒性，多用于年轻、无心血管基础病者。肾功能不全者需按肌酐清除率调整剂量，停药必须≥1周缓慢递减以防撤药反应。
2. **局部与外用治疗**：局限性、表浅性疼痛可首选5%利多卡因贴剂（每日贴敷≤12小时）；8%高浓度辣椒素贴剂（需专业医护人员操作，单次60分钟）通过耗竭P物质起效，适用于口服不耐受或追求快速缓解者。
3. **难治性疼痛与介入治疗**：阿片类不作为一线，仅可短期使用弱阿片（如曲马多）或强阿片作为“救援（rescue）”治疗。对于常规治疗无效、症状严重影响生活的难治性CIPN，可考虑多学科评估后实施周围神经阻滞（如股神经、胫神经阻滞）、脉冲射频调节或脊髓电刺激（SCS）。NICE指出，慢性神经病理性疼痛≥6个月、VAS≥50 mm且经充分药物试验无效者，可考虑神经调控治疗。
4. **预防与化疗方案优化**：化疗期间预防性使用维生素B族、α-硫辛酸或阿巴西普证据有限，不常规推荐。临床更强调化疗前基线神经功能评估、化疗中定期筛查、出现2级以上毒性时及时减量、延迟给药或更换非神经毒性替代药物。奥沙利铂化疗前后冰水含漱/戴冰帽可显著降低急性神经毒性发生率。

## 六、非药物与康复
在一线药物基础上，必须联合运动疗法、认知行为治疗（CBT）与睡眠管理，构建“药物-康复-心理”三位一体管理模式。患者教育帮助理解中枢敏化机制与长期管理策略，有效减少疼痛灾难化认知与焦虑抑郁情绪。
1. **运动与物理康复**：规律的中低强度有氧运动（如快走、游泳、固定自行车）每周≥150分钟，可促进神经营养因子（BDNF）释放，改善轴突运输与微循环。平衡训练（如太极、瑜伽）与抗阻训练可显著降低跌倒风险，改善本体感觉缺失导致的步态异常。
2. **心理与行为干预**：CBT针对疼痛相关恐惧回避行为进行认知重构，结合正念减压（MBSR）降低中枢敏化水平。睡眠卫生教育（固定作息、避免睡前蓝光、限制咖啡因）对打破“疼痛-失眠-痛阈降低”恶性循环至关重要。
3. **补充与替代医学**：针灸（尤其电针）在多项RCT中显示可缓解CIPN症状，机制可能与调节内源性阿片肽及抗炎通路有关。经皮神经电刺激（TENS）循证证据有限，NICE不常规推荐，但可作为辅助手段个体化尝试。
4. **难治性病例进阶管理**：经规范药物与康复仍无效者，应转诊至疼痛专科评估周围神经松解术、脊髓电刺激（SCS）或鞘内药物输注系统（IDDS）。需严格把握适应证，充分知情同意，并定期评估设备并发症与感染风险。

## 七、随访与监测要点
CIPN的随访需贯穿化疗全程及停药后至少6-12个月，部分患者症状可能持续数年。
1. **症状与体征动态监测**：每次随访必查感觉缺失范围是否进展、痛觉过敏/触诱发痛程度（NRS）、步态稳定性、手部精细动作（扣纽扣、写字）及腱反射变化。建议每疗程化疗前后进行标准化量表复评。
2. **功能与生活质量评估**：重点跟踪行走距离、抓握力量、日常生活独立性（ADL评分）及跌倒史。使用SF-36或EQ-5D量化生活质量影响。
3. **化疗耐受性与方案调整**：密切评估神经毒性是否影响后续化疗剂量强度（Dose Intensity）。若出现3-4级毒性，需与肿瘤科协同决策是否减量、延长间隔或停用神经毒性药物。
4. **神经电生理与客观指标复查**：对于症状持续进展者，每6-12个月复查NCS/EMG或IENFD，客观评估神经纤维再生或退化趋势。
5. **药物安全性监测**：定期复查肝肾功能、电解质，监测普瑞巴林/加巴喷丁的头晕嗜睡副作用、度洛西汀的血压变化及阿米替林的心电图QT间期。

## 八、预警与转诊指征
出现以下情况需高度警惕，立即启动多学科会诊或紧急转诊：
1. **运动功能进行性恶化**：肌力持续下降、足下垂、吞咽困难或呼吸肌受累，需肿瘤科紧急评估化疗减量或停用，并排查副肿瘤综合征、吉兰-巴雷综合征或脊髓压迫。
2. **自主神经危象**：突发严重直立性低血压、尿潴留、肠梗阻或心血管节律异常，提示广泛自主神经受累，需急诊处理以防晕厥或心血管事件。
3. **症状分布不典型或快速蔓延**：突破“手套-袜套”分布，出现单侧不对称、节段性分布或上行性麻痹，需紧急行MRI/脑脊液检查排除肿瘤脑膜转移、感染或脱髓鞘疾病。
4. **难治性疼痛与严重心理危机**：NRS持续≥7分且常规药物无效，或伴随重度抑郁、自杀倾向，需转诊疼痛介入科调整方案，并联合精神心理科干预。
5. **药物不良反应预警**：出现严重皮疹、肝酶显著升高、意识模糊或撤药反应，需立即停药并对症支持。

## 九、患者教育与自我管理
1. **疾病认知与预期管理**：向患者通俗解释CIPN属“神经敏化与结构损伤并存”，强调其可防可控但修复需时间，破除“止痛药成瘾”误区。明确治疗目标是“带痛生存、功能优先”，而非追求绝对无痛。
2. **规范用药教育**：强调按时、规律服药以维持稳定血药浓度，切勿痛时才吃或自行骤停。记录用药后症状变化与副作用，复诊时供医师调整剂量参考。
3. **安全防护与跌倒预防**：居家环境消除地毯、杂物等绊倒隐患，浴室加装防滑垫与扶手。穿合脚、宽头、防滑鞋，夜间使用感应灯。行走不稳者务必使用助行器。
4. **足部护理与皮肤保护**：每日温水（≤37℃）洗脚，仔细检查足底有无破损、水泡、鸡眼或感染。避免赤脚行走、使用热水袋或电热毯（感觉减退易致烫伤）。修剪趾甲需平剪，避免损伤甲沟。
5. **生活方式与心理调适**：严格戒烟限酒（酒精加重神经毒性），保持均衡饮食（补充B族维生素、Omega-3）。鼓励参与患者支持团体，学习正念冥想、腹式呼吸等放松技巧，降低交感神经兴奋性。
6. **紧急就医指征**：若出现新发肢体无力、鞍区麻木、二便失禁、突发剧烈头痛伴呕吐、胸痛或呼吸困难，提示可能合并严重神经系统或心血管急症，须立即拨打急救电话或就近急诊就诊。

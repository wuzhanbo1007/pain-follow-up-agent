# 对话结束判断逻辑

## 自动回复患者（35人）

- 固定 **4 轮**追问后自动结束
- 第 5 轮发送结束语并统一评分

## 演示患者（手动输入，2人）

基于 **单条回复解析结果** 判断：

| 已获取信息 | 已有 | 护士行为 |
|-----------|------|---------|
| NRS（疼痛评分） | ✓ | 追问："昨晚睡眠怎么样？" |
| NRS + 睡眠 | ✓ | 追问："药按时吃了吗？" |
| NRS + 睡眠 + 用药 | ✓ | 追问："有无副作用（恶心/头晕/便秘）？" |
| NRS + 睡眠 + 用药 + 副作用 | ✓ | 发送结束语 → **自动评分** |
| 三项全空 | ✗ | 发送澄清追问："请具体描述疼痛/睡眠/用药" |

### 示例

**一句话完整回复 → 直接结束：**
> 7分，睡得很差，药没吃，还头晕恶心

**分段回复 → 多轮追问后结束：**
| 轮次 | 你输入 | 护士追问 |
|------|--------|---------|
| 1 | 7分 | 睡眠怎么样？ |
| 2 | 没睡着 | 药吃了吗？ |
| 3 | 没吃 | 有无副作用？ |
| 4 | 头晕 | → 结束语 + 评分 |

## 一、现状问题

### 1.1 核心病灶

当前 `engine/orchestrator.py` 是一个 **2200 行的 God Class**，承载了全部业务逻辑：

```

├── 13 个手动状态枚举 + transition_to() 硬切换
├── 30+ 个方法混在一个类里
├── while True + break 实现对话循环
├── time.sleep() 硬编码等待
├── threading.Thread 手动管理线程
├── 15+ 个实例变量散落管理状态
├── WebSocket emit 散落在各个方法中
```

## 四、核心设计决策

### 4.1 分层原则

| 层 | 可以依赖 | 不能做的事 |
|---|---|---|
| **API 层** | Service 层 | 不能直接操作数据库、不能调用 LLM |
| **Service 层** | Agent 层 + Engine 层 + Data 层 | 不能直接 emit WebSocket（通过 EventBus） |
| **Agent 层** | Engine 层 + Data 层 | 不能处理 HTTP/WebSocket（纯计算） |
| **Engine 层** | Data 层 | 不能有状态、不能处理业务编排 |
| **Data 层** | 无 | 纯数据访问 |

### 4.2 依赖注入（app.py 启动时一次性装配）

### 4.3 Agent 设计原则

每个 Agent 是一个**纯函数式的 LangGraph 子图**：

```python
# Agent = 输入 dict → 图执行 → 输出 dict
# 不持有 WebSocket 引用，不操作 UI，不管理线程

class ExecutionAgent:
    """随访执行 Agent：纯 LangGraph 图，无副作用"""

    def __init__(self, msg_gen, reply_parser, risk_engine, auto_reply):
        self.graph = build_execution_graph(
            msg_gen, reply_parser, risk_engine, auto_reply
        )

    def run(self, patient: dict, plan_id: str = None) -> dict:
        """执行一次随访，返回 {session_id, transcript, risk_result, summary}"""
        return self.graph.invoke({
            "patient": patient,
            "plan_id": plan_id,
            "transcript": [],
        })
```

### 4.4 EventBus：WebSocket 事件统一管理

```python
# services/event_bus.py
# 替代 orchestrator 中散落的 self.emit()

class EventBus:
    """WebSocket 事件总线——所有前端推送统一经由此处"""

    def __init__(self, sio: socketio.AsyncServer):
        self._sio = sio
        self._stats = {...}
        self._logs = [...]

    async def emit_state_change(self, from_state, to_state): ...
    async def emit_wechat_message(self, patient_id, name, message): ...
    async def emit_patient_reply(self, patient_id, name, text): ...
    async def emit_risk_result(self, patient_id, result): ...
    async def emit_filter_result(self, result): ...
    async def emit_final_stats(self, stats): ...
    async def emit_progress(self, current, total, phase): ...
    async def emit_log(self, message): ...
    async def emit_alert(self, alert): ...

    # 全局状态（替代 orchestrator 的实例变量）
    @property
    def stats(self): return self._stats
    @property
    def logs(self): return self._logs
```

### 4.5 对话循环：从 while True 到 LangGraph 条件边

```python
# 旧版（orchestrator.py）：手动 while True + break
while True:
    decision = self._react_reflect(...)
    if decision["should_end"]:
        self.emit(...)  # 发结束语
        break           # 手动退出
    self.emit(...)      # 发追问
    reply = engine.generate_reply(...)
    self.emit(...)      # 患者回复
    time.sleep(0.8)

# 新版（execution.py）：声明式条件边
g.add_conditional_edges(
    "react_reflect",
    _should_continue,
    {"continue": "collect_one_round", "end": "score_risk"}
)
# 由 LangGraph 引擎自动驱动循环，无需 sleep/break
```

## 五、Service 层详细设计

### 5.1 FollowupService（替代 orchestrator._run_flow）

```python
class FollowupService:
    """随访执行服务：编排"名单→过滤→执行→评分→审阅"完整流程"""

    def __init__(self, scheduler, exec_agent, review_agent, event_bus):
        self.scheduler = scheduler      # 判定引擎
        self.exec_agent = exec_agent    # Execution Agent
        self.review_agent = review_agent # Review Agent
        self.bus = event_bus

    async def start_daily_followup(self, patients: list):
        """启动今日随访流程（入口方法）"""

        # Step 1: 免随访过滤（C1~C4 判定）
        send_list, skip_list = self.scheduler.filter(patients)
        await self.bus.emit_filter_result(send_list, skip_list)

        # Step 2: 批量生成个性化消息（并行）
        messages = await self._generate_messages_parallel(send_list)

        # Step 3: 发送开场消息
        for msg in messages:
            await self.bus.emit_wechat_message(...)

        # Step 4: 对每位患者启动 ReACT 对话
        results = []
        for patient in send_list:
            result = self._run_react_loop(patient)
            results.append(result)

        # Step 5: 汇总统计
        await self.bus.emit_final_stats(results)

    async def handle_patient_reply(self, patient_id: str, reply_text: str):
        """处理患者手动回复（演示患者）"""
        patient = self.patient_repo.get(patient_id)
        transcript = self._get_transcript(patient_id)

        # 添加患者回复
        transcript.append({"role": "patient", "content": reply_text})

        # 模糊判断
        if self._is_ambiguous(reply_text, transcript):
            clarification = self._generate_clarification(reply_text, transcript)
            await self.bus.emit_wechat_message(patient_id, ..., clarification)
            return

        # ReACT 决策
        decision = self._react_reflect(patient, transcript)
        if decision["should_end"]:
            await self.bus.emit_wechat_message(patient_id, ..., decision["next_question"])
            result = self.exec_agent.score(patient, transcript)
            await self.bus.emit_risk_result(patient_id, result)
            return

        # 继续追问
        await self.bus.emit_wechat_message(patient_id, ..., decision["next_question"])
```

```python
class ReviewService:
    """审阅管理服务"""

    def __init__(self, review_agent, session_repo, event_bus):
        self.agent = review_agent
        self.repo = session_repo
        self.bus = event_bus
```

```python
FastAPI + WebSocket 主服务 — PainSmart 慢性疼痛随访智能体

import socketio
from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware

from core.config import config
from core.di import Container
from routes import plan_routes, review_routes

# ======== 创建应用 ========
app = FastAPI(title="PainSmart", version="2.0")
app.add_middleware(CORSMiddleware, allow_origins=["*"], ...)

sio = socketio.AsyncServer(async_mode="asgi", cors_allowed_origins="*")
socketio_app = socketio.ASGIApp(sio, other_asgi_app=app)

# ======== 依赖注入 ========
container = Container(config, sio)

# ======== 注册路由 ========
app.include_router(plan_routes.router)
app.include_router(review_routes.router)

# ======== WebSocket 事件 ========
@sio.event
async def connect(sid, environ):
    await container.event_bus.emit_connected(sid)

@sio.on("demo:start_followup")
async def handle_start_followup(sid, data):
    patients = container.patient_repo.get_all()
    await container.followup_service.start_daily_followup(patients)

@sio.on("demo:simulate_reply")
async def handle_simulate_reply(sid, data):
    await container.followup_service.handle_patient_reply(
        data["patient_id"], data["reply_text"]
    )

@sio.on("demo:reset")
async def handle_reset(sid):
    await container.followup_service.reset()

# ======== 启动 ========
if __name__ == "__main__":
    import uvicorn
    uvicorn.run(socketio_app, host=config.API_HOST, port=config.API_PORT)
```
